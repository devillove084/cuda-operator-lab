## 题目描述

你需要实现一个 SM90 风格的稀疏 INT8 GEMM 算子：

> **output = matmul(int32(a), int32(b))**

给定两个 `int8` 矩阵 `a` 和 `b`，你需要完成矩阵乘法，并以 `int32` 保存输出结果。

原始算子的背景是带结构化稀疏性的 GEMM，但从数学语义上看，最终结果等价于：

```text
output[i, j] = sum_k(int32(a[i, k]) * int32(b[k, j]))
```

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成该 GEMM 的计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const int8_t* a,
    const int8_t* b,
    int32_t* output,
    int64_t M,
    int64_t N,
    int64_t K
);
```

### 参数说明

* `a`：输入指针，shape `(M, K)`，类型为 int8
* `b`：输入指针，shape `(K, N)`，类型为 int8
* `output`：输出指针，shape `(M, N)`，类型为 int32
* `M`、`N`、`K`：矩阵乘法尺寸

`run_kernel` 内部需要完成以下工作：

* 根据张量尺寸计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成 INT8 × INT8 → INT32 GEMM

## PyTorch 参考实现

```python
def baseline(a, b, output, M, N, K):
    """
    PyTorch 参考实现：Sparse GEMM S8-S32
    """

```
