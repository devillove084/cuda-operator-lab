# Cosine Embedding Loss

## 题目描述

你需要实现一个 `Cosine Embedding Loss` 算子：

> **loss = mean(y == 1 ? 1 - cos(x1, x2) : max(0, cos(x1, x2) - margin))**

给定输入矩阵 `x1`、`x2`（shape 均为 $(N, D)$）、标签向量 `y`（shape 为 $(N,)$，元素取值为 `-1` 或 `1`）以及一个标量 `margin`，你需要先逐行计算 `x1` 和 `x2` 的余弦相似度，再根据标签选择对应的损失公式，最后对所有行取平均，得到一个标量输出 `loss`。

对于任意行 $i$，定义：

$$
cos_i = \frac{\sum_{j=0}^{D-1} x1_{i,j} \cdot x2_{i,j}}{\sqrt{\sum_{j=0}^{D-1} x1_{i,j}^2} \cdot \sqrt{\sum_{j=0}^{D-1} x2_{i,j}^2}}
$$

若 `y[i] = 1`，则该行损失为：

$$
l_i = 1 - cos_i
$$

若 `y[i] = -1`，则该行损失为：

$$
l_i = \max(0, cos_i - margin)
$$

最终输出为：

$$
loss = \frac{1}{N} \sum_{i=0}^{N-1} l_i
$$

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成逐行余弦相似度计算、逐行损失计算以及最终均值归约。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 计算过程说明

先计算逐行余弦相似度：

* 第 0 行：
  * $cos_0 = 0.0$
  * $y_0 = -1$
  * $l_0 = \max(0, 0.0 - 0.2) = 0.0$
* 第 1 行：
  * $cos_1 = 1.0$
  * $y_1 = 1$
  * $l_1 = 1 - 1.0 = 0.0$

最终取平均：

$$
loss = (0.0 + 0.0) / 2 = 0.0
$$

## PyTorch 参考实现

```python
def baseline(x1, x2, y, loss, margin, N, D):
    dot = torch.sum(x1 * x2, dim=-1)
    norm1 = torch.sqrt(torch.sum(x1 * x1, dim=-1))
    norm2 = torch.sqrt(torch.sum(x2 * x2, dim=-1))
    cos_sim = dot / (norm1 * norm2)
    pointwise = torch.where(y == 1, 1.0 - cos_sim, torch.clamp(cos_sim - margin, min=0.0))
    loss.copy_(pointwise.mean())
```
