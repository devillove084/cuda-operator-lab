## 题目描述

你需要实现一个带 groupwise scaling 的 FP8 GEMM：

> **output = dequant(A, scale_a) @ dequant(B, scale_b)^T**

给定 FP8 输入矩阵 `A`、`B` 以及对应的缩放因子 `scale_a`、`scale_b`，你需要先完成反量化，再执行矩阵乘法，最后把结果写入 `bfloat16` 输出矩阵。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成反量化与矩阵乘法的全部计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_fp8.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_fp8_e4m3* A,
```

### 参数说明

* `A`：输入指针，shape `(M, K)`，类型为 FP8 E4M3
* `A_scale`：输入指针，shape `(M, K_blocks)`，类型为 float32
* `B`：输入指针，shape `(N, K)`，类型为 FP8 E4M3
* `B_scale`：输入指针，shape `(N_blocks, K_blocks)`，类型为 float32
* `output`：输出指针，shape `(M, N)`，类型为 bfloat16
* `M`：输出矩阵行数
* `N`：输出矩阵列数
* `K`：归约维长度
* `BLOCK_SIZE`：groupwise scaling 的分块大小

其中：

```text
K_blocks = ceil_div(K, BLOCK_SIZE)
N_blocks = ceil_div(N, BLOCK_SIZE)
```

`run_kernel` 内部需要完成以下工作：

* 根据 `M / N / K / BLOCK_SIZE` 计算 scale 的索引方式
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成反量化与 GEMM 计算

## 输出格式

你需要将计算结果写入 `output`，满足：

```text
A_scaled[i, k] = float(A[i, k]) * A_scale[i, floor(k / BLOCK_SIZE)]
B_scaled[j, k] = float(B[j, k]) * B_scale[floor(j / BLOCK_SIZE), floor(k / BLOCK_SIZE)]

output[i, j] = bfloat16(
    sum_k(A_scaled[i, k] * B_scaled[j, k])
)
```

## 样例

## 输入

```text
M = 2
N = 2
K = 4
BLOCK_SIZE = 2
```

此时：

```text
K_blocks = ceil_div(4, 2) = 2
N_blocks = ceil_div(2, 2) = 1
```

所以：

* `A_scale` 的形状为 `(2, 2)`
* `B_scale` 的形状为 `(1, 2)`

此时 `A` 的每一行都会沿 `K` 维分成两个 block：

* 第 0 个 block 覆盖 `k in [0, 2)`
* 第 1 个 block 覆盖 `k in [2, 4)`

因此：

```text
A_scaled[i, 0] = float(A[i, 0]) * A_scale[i, 0]
A_scaled[i, 1] = float(A[i, 1]) * A_scale[i, 0]
A_scaled[i, 2] = float(A[i, 2]) * A_scale[i, 1]
A_scaled[i, 3] = float(A[i, 3]) * A_scale[i, 1]
```

对于 `B`，由于 `N_blocks = 1`，所有输出列都来自同一个 `N` 方向 block，因此 `B_scale` 只在 `K` 方向区分两个 block：

```text
B_scaled[j, 0] = float(B[j, 0]) * B_scale[0, 0]
B_scaled[j, 1] = float(B[j, 1]) * B_scale[0, 0]
B_scaled[j, 2] = float(B[j, 2]) * B_scale[0, 1]
B_scaled[j, 3] = float(B[j, 3]) * B_scale[0, 1]
```

最后输出矩阵按如下方式计算：

```text
output[0, 0] = bfloat16(sum_k(A_scaled[0, k] * B_scaled[0, k]))
output[0, 1] = bfloat16(sum_k(A_scaled[0, k] * B_scaled[1, k]))
output[1, 0] = bfloat16(sum_k(A_scaled[1, k] * B_scaled[0, k]))
output[1, 1] = bfloat16(sum_k(A_scaled[1, k] * B_scaled[1, k]))
```

## 提示

* `A` 的缩放方式是 **每行、按 K-block 缩放**
* `B` 的缩放方式是 **按 (N-block, K-block) 二维缩放**

* 当 `N` 或 `K` 不是 `BLOCK_SIZE` 的整数倍时，尾块需要正确处理边界

## PyTorch 参考实现

```python
def baseline(A, A_scale, B, B_scale, output, M, N, K, BLOCK_SIZE):
    K_blocks = (K + BLOCK_SIZE - 1) // BLOCK_SIZE
    N_blocks = (N + BLOCK_SIZE - 1) // BLOCK_SIZE
    A_scaled = A.float() * A_scale.repeat_interleave(BLOCK_SIZE, dim=1)[:, :K]
    B_scaled = B.float() * B_scale.repeat_interleave(BLOCK_SIZE, dim=0).repeat_interleave(BLOCK_SIZE, dim=1)[:N, :K]
    output.copy_(torch.matmul(A_scaled, B_scaled.t()).to(output.dtype))
```
