# Single Prefill with KV Cache Return LSE

原题 https://xpuoj.com/p/36

## 题目描述

你需要实现单序列 Prefill 阶段的因果注意力算子，并在输出注意力结果的同时返回每个 query 位置、每个 head 对应的 LogSumExp（LSE）值。

具体来说，输入张量的 shape 分别为：

$$
Q \in \mathbb{R}^{L_q \times H_q \times D}, \quad
K \in \mathbb{R}^{L_k \times H_{kv} \times D}, \quad
V \in \mathbb{R}^{L_k \times H_{kv} \times D}
$$

其中 $L_q$ 表示 query 序列长度，$L_k$ 表示 key/value 序列长度，$H_q$ 表示 query 头数，$H_{kv}$ 表示 key/value 头数，$D$ 表示每个头的维度。

当 $H_q \neq H_{kv}$ 时，本题按照 baseline 的语义采用 GQA 的处理方式：将 KV heads 沿 head 维复制，使其与 query heads 数量对齐。之后对每个 head 计算缩放点积注意力分数：

$$
S = \dfrac{QK^T}{\sqrt{D}}
$$

随后施加因果掩码。对不允许访问的未来位置，需要把分数视为 $-\infty$。记掩码后的分数矩阵为 $S + M$，则注意力权重为：

$$
P = \operatorname{softmax}(S + M)
$$

最终注意力输出为：

$$
O = PV
$$

除了输出 $O$ 之外，本题还要求返回每个 query 位置、每个 head 的对数归一化项。若某一行掩码后的分数为 $s_1, s_2, \dots, s_{L_k}$，则 baseline 实际写回的 LSE 为：

$$
\operatorname{LSE}_{\text{base-2}} = \dfrac{\log\left(\sum_j e^{s_j}\right)}{\log 2}
$$

也就是说，先按自然对数计算 LogSumExp，再除以 $\log 2$，把结果转换成以 2 为底的对数形式后写入 `lse` 输出张量。

因此，本题有两个必须同时正确写回的输出：注意力结果 `o` 和以 2 为底的 `lse`。实现时需要严格对齐 baseline 中的计算顺序：`QK^T -> scale -> causal mask -> softmax / logsumexp -> @V`。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 single prefill with kv cache return lse

    Args:
        q: BF16 tensor of shape (qo_len, num_qo_heads, head_dim) - query
        k: BF16 tensor of shape (kv_len, num_kv_heads, head_dim) - key
        v: BF16 tensor of shape (kv_len, num_kv_heads, head_dim) - value
        o: BF16 tensor of shape (qo_len, num_qo_heads, head_dim) - output (will be modified inplace)
        lse: float32 tensor of shape (qo_len, num_qo_heads) - log softmax denominator (will be modified inplace)
        qo_len: int - query sequence length
        kv_len: int - key/value sequence length
        num_qo_heads: int - number of query/output heads
        num_kv_heads: int - number of key/value heads
        head_dim: int - head dimension

    Returns:
        List containing modified o and lse tensors
    """
    q, k, v, o, lse, qo_len, kv_len, num_qo_heads, num_kv_heads, head_dim = inputs

    assert torch.is_tensor(q) and torch.is_tensor(k) and torch.is_tensor(v) and torch.is_tensor(o) and torch.is_tensor(lse)
    assert isinstance(qo_len, int) and isinstance(kv_len, int) and isinstance(num_qo_heads, int) and isinstance(num_kv_heads, int) and isinstance(head_dim, int)
    assert q.shape == (qo_len, num_qo_heads, head_dim)
    assert k.shape == (kv_len, num_kv_heads, head_dim)
    assert v.shape == (kv_len, num_kv_heads, head_dim)
    assert o.shape == (qo_len, num_qo_heads, head_dim)
    assert lse.shape == (qo_len, num_qo_heads)

    if num_kv_heads != num_qo_heads:
        head_group_size = num_qo_heads // num_kv_heads
        k = k.repeat_interleave(head_group_size, dim=1)
        v = v.repeat_interleave(head_group_size, dim=1)

    sm_scale = 1.0 / math.sqrt(head_dim)

    output = torch.zeros_like(o)
    lse_out = torch.zeros_like(lse)

    causal_mask = torch.triu(torch.ones(qo_len, kv_len, dtype=torch.bool, device=q.device),
                             diagonal=kv_len - qo_len + 1)

    for h in range(num_qo_heads):
        q_h = q[:, h, :]
        k_h = k[:, h, :]
        v_h = v[:, h, :]

        scores_h = torch.matmul(q_h, k_h.t()) * sm_scale
        scores_h = scores_h.float()

        scores_h = scores_h.masked_fill(causal_mask, float('-inf'))

        scores_max_h = scores_h.max(dim=-1, keepdim=True)[0]
        scores_stable_h = scores_h - scores_max_h
        exp_scores_h = torch.exp(scores_stable_h)

        sum_exp_h = torch.sum(exp_scores_h, dim=-1)
        lse_h = scores_max_h.squeeze(-1) + torch.log(sum_exp_h)

        sum_exp_h_expanded = sum_exp_h.unsqueeze(-1)
        attn_weights_h = exp_scores_h / sum_exp_h_expanded

        output_h = torch.matmul(attn_weights_h.to(v_h.dtype), v_h)

        output[:, h, :] = output_h
        lse_out[:, h] = lse_h

    o.copy_(output)
    lse.copy_(lse_out / math.log(2))

    return [q, k, v, o, lse, qo_len, kv_len, num_qo_heads, num_kv_heads, head_dim]```
