## 题目描述

你需要实现 Top-k Sigmoid。对每个 token 的专家打分 `gating_output`，先逐元素施加 sigmoid，得到归一化到 $(0, 1)$ 区间内的门控分数；然后在专家维上取出最大的 `topk` 个值及其对应下标，并分别写入 `topk_weights` 和 `topk_ids`。

设输入满足：

$$
G \in \mathbb{R}^{T \times E}
$$

其中 $T$ 是 token 数量，$E$ 是专家数量。对第 $i$ 个 token、第 $e$ 个专家，先计算 sigmoid 分数：

$$
S_{i,e} = \sigma(G_{i,e}) = \frac{1}{1 + e^{-G_{i,e}}}
$$

然后在专家维上选出前 `topk = K` 个最大值。记这 $K$ 个值对应的专家下标为

$$
j_{i,1}, j_{i,2}, \dots, j_{i,K}
$$

它们满足按分数从大到小排序：

$$
S_{i, j_{i,1}} \ge S_{i, j_{i,2}} \ge \dots \ge S_{i, j_{i,K}}
$$

并且它们是该 token 在所有专家上的前 $K$ 大 sigmoid 分数。于是输出定义为：

$$
\text{topk\_weights}[i, k] = S_{i, j_{i,k}}
$$

$$
\text{topk\_ids}[i, k] = j_{i,k}
$$

对每个 token 都独立执行上述过程，因此可以把整体输出写成：

$$
\text{topk\_weights}, \text{topk\_ids} = \operatorname{TopK}(\sigma(G), K)
$$

本题最关键的点是：排序和选择发生在 sigmoid 之后，而不是在原始 `gating_output` logits 上直接做 top-k。也就是说，真正参与比较的是 $S = \sigma(G)$，而输出的 `topk_weights` 也必须是 sigmoid 之后的值。

## PyTorch 参考实现

```python
def baseline(*inputs):
    gating_output, topk_weights, topk_ids, num_tokens, num_experts, topk = inputs
    assert gating_output.shape == (num_tokens, num_experts)
    assert gating_output.dtype == torch.float32
    sigmoid_output = torch.sigmoid(gating_output)
    ref_w, ref_i = torch.topk(sigmoid_output, topk, dim=-1)
    topk_weights.copy_(ref_w)
    topk_ids.copy_(ref_i.to(torch.int32))
    return [gating_output, topk_weights, topk_ids, num_tokens, num_experts, topk]
```
