## 题目描述

你需要实现一个 causal conv1d forward 算子。Causal 卷积意味着输出在时间步 $t$ 只依赖于当前及之前的输入，不依赖未来信息。

该算子执行以下计算：

$$
\text{output}[b, c, t] = \text{bias}[c] + \sum_{k=0}^{K-1} x_{\text{eff}}[b, c, t - (K-1) + k] \cdot \text{weight}[c, k]
$$

其中 $K$ 是卷积核大小，$x_{\text{eff}}$ 是有效输入，其取值规则为：

$$
x_{\text{eff}}[b, c, t'] = \begin{cases}
x[b, c, t'] & t' \ge 0 \\[4pt]
\text{conv_states}[b, c, t' + K - 1] & t' < 0 \text{ 且 } \text{has_initial_state} = 1 \\[4pt]
0 & t' < 0 \text{ 且 } \text{has_initial_state} = 0
\end{cases}
$$

可选地，若 $\text{silu_activation} = 1$，对卷积结果应用 SiLU 激活：

$$
\text{output}[b, c, t] = \text{SiLU}(\text{output}[b, c, t])
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成 causal conv1d forward 计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，得到一个 shape 为 $(\text{batch_size}, \text{dim}, \text{seq_len})$ 的 float32 张量。

对每个批次 $b$、通道 $c$、时间步 $t$，卷积结果计算如下：

设累加器初始值为偏置：

$$
\text{acc} = \text{bias}_c
$$

对卷积核位置 $k = 0, \ldots, K-1$（其中 $K = \text{kernel_size}$）：

令源时间步 $\text{src_t} = t - (K - 1) + k$

* 若 $\text{src_t} \ge 0$：

$$
\text{acc} \mathbin{+}= x_{b,c,\text{src_t}} \cdot \text{weight}_{c,k}
$$

* 若 $\text{src_t} < 0$ 且 $\text{has_initial_state} = 1$：

$$
\text{acc} \mathbin{+}= \text{conv_states}_{b,c,\text{src_t} + K - 1} \cdot \text{weight}_{c,k}
$$

* 若 $\text{src_t} < 0$ 且 $\text{has_initial_state} = 0$：该项按 0 处理

最后，若 $\text{silu_activation} = 1$：

$$
\text{output}_{b,c,t} = \text{SiLU}(\text{acc}) = \text{acc} \cdot \sigma(\text{acc})
$$

否则 $\text{output}_{b,c,t} = \text{acc}$

这等价于对每个通道做独立的 causal depthwise 1D convolution。

## 样例

## 输入

假设以下参数：
* $\text{batch_size} = 1$，$\text{dim} = 1$，$\text{seq_len} = 4$，$\text{kernel_size} = 3$
* $\text{has_initial_state} = 0$，$\text{silu_activation} = 0$

`x`（shape $(1, 1, 4)$）：

```
[[[1.0, 2.0, 3.0, 4.0]]]
```

`weight`（shape $(1, 3)$）：

```
[[0.1, 0.2, 0.3]]
```

`bias`（shape $(1,)$）：

```
[0.0]
```

## 输出

`output`（shape $(1, 1, 4)$）：

**计算过程**（Causal 卷积，只依赖当前及之前输入）：

对于 $t = 0$（第一个时间步）：
* $\text{src_t}$ 取值：$0 - 2 + 0 = -2$，$0 - 2 + 1 = -1$，$0 - 2 + 2 = 0$
* 只有 $\text{src_t} = 0 \ge 0$ 有效
* $\text{acc} = 0.0 + x[0,0,0] \cdot 0.3 = 1.0 \times 0.3 = 0.3$
* $\text{output}[0,0,0] = 0.3$

对于 $t = 1$：
* $\text{src_t}$ 取值：$-1$，$0$，$1$
* 有效输入：$x[0,0,0]$ 和 $x[0,0,1]$
* $\text{acc} = 0.0 + x[0,0,0] \cdot 0.2 + x[0,0,1] \cdot 0.3 = 1.0 \times 0.2 + 2.0 \times 0.3 = 0.2 + 0.6 = 0.8$
* $\text{output}[0,0,1] = 0.8$

对于 $t = 2$：
* $\text{src_t}$ 取值：$0$，$1$，$2$
* 全部有效
* $\text{acc} = 0.0 + 1.0 \times 0.1 + 2.0 \times 0.2 + 3.0 \times 0.3 = 0.1 + 0.4 + 0.9 = 1.4$
* $\text{output}[0,0,2] = 1.4$

对于 $t = 3$：
* $\text{acc} = 0.0 + 2.0 \times 0.1 + 3.0 \times 0.2 + 4.0 \times 0.3 = 0.2 + 0.6 + 1.2 = 2.0$
* $\text{output}[0,0,3] = 2.0$

**输出结果**：

```
[[[0.3, 0.8, 1.4, 2.0]]]
```

## PyTorch 参考实现

```python
import torch.nn.functional as F

def baseline(x, weight, bias, conv_states, output, batch_size, dim, seq_len, kernel_size, has_initial_state, silu_activation):
    """
    PyTorch 参考实现：Causal Conv1d Fwd

    参数说明：
    * x: 输入张量（float32），shape (batch_size, dim, seq_len)，只读
    * weight: 权重张量（float32），shape (dim, kernel_size)，只读
    * bias: 偏置张量（float32），shape (dim,)，只读
    * conv_states: 初始状态张量（float32），shape (batch_size, dim, kernel_size-1)，只读
    * output: 输出张量（float32），shape (batch_size, dim, seq_len)，需写入结果
    * batch_size: batch 大小（int64）
    * dim: 通道数（int64）
    * seq_len: 序列长度（int64）
    * kernel_size: 卷积核宽度（int64）
    * has_initial_state: 是否使用初始状态（0 或 1）
    * silu_activation: 是否应用 SiLU 激活（0 或 1）
    """
    weight_reshaped = weight.unsqueeze(1)
    if has_initial_state:
        x_with_states = torch.cat([conv_states, x], dim=-1)
        ref = F.conv1d(x_with_states, weight_reshaped, bias, groups=dim, padding=0)
        ref = ref[..., :seq_len]
    else:
        ref = F.conv1d(x, weight_reshaped, bias, groups=dim, padding=kernel_size - 1)
        ref = ref[..., :seq_len]

    if silu_activation:
        ref = F.silu(ref)

    output.copy_(ref)
```
