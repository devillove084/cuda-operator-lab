## 题目描述

你需要实现 `Query Bias Add + Relative Position Bias + Transpose` 的融合整理。输入 `qkv` 在最后一维打包了 `Q/K/V` 三段，其中只有 `Q` 段会参与本题计算。你需要从中取出原始 query，一方面对 `qkv` 中的 query 段原地加上 `query_bias`，另一方面基于原始 query 构造 `pos_query`，其值为 `q_raw + pos_bias`，并按照 `[B, H, T, D]` 的布局写回。

设输入满足：

$$
\text{qkv} \in \mathbb{R}^{B \times T \times 3HD}, \quad
\text{query\_bias} \in \mathbb{R}^{H \times D}, \quad
\text{pos\_bias} \in \mathbb{R}^{H \times D}
$$

其中 $B$ 是 batch size，$T$ 是序列长度，$H$ 是头数，$D$ 是单头维度。

先从 `qkv` 中取出 query 段：

$$
Q_{\text{raw}} = \text{qkv}[:, :, :HD] \in \mathbb{R}^{B \times T \times HD}
$$

注意 baseline 中这里会先把 `Q_raw` 拷贝出来，因此后续构造 `pos_query` 使用的是加 `query_bias` 之前的原始 query。

第一条支路是原地更新 `qkv` 中的 query 段。把 `query_bias` 展平为长度为 $HD$ 的向量后，对任意 $(b,t,h,d)$，有：

$$
\text{qkv}[b,t,hD+d]
\leftarrow
\text{qkv}[b,t,hD+d] + \text{query\_bias}[h,d]
$$

等价地，从整体上可以写成：

$$
\text{qkv}[:, :, :HD] \leftarrow Q_{\text{raw}} + \operatorname{reshape}(\text{query\_bias}, [1,1,HD])
$$

第二条支路是构造 `pos_query`。同样把 `pos_bias` 展平为长度为 $HD$ 的向量，则：

$$
Q_{\text{pos}} = Q_{\text{raw}} + \operatorname{reshape}(\text{pos\_bias}, [1,1,HD])
$$

然后把它从 $(B, T, HD)$ 重新整理成 $(B, T, H, D)$：

$$
Q_{\text{pos}}^{\text{view}} \in \mathbb{R}^{B \times T \times H \times D}
$$

最后交换第 `1` 维和第 `2` 维，得到：

$$
\text{pos\_query} \in \mathbb{R}^{B \times H \times T \times D}
$$

按坐标表示就是：

$$
\text{pos\_query}[b,h,t,d] = Q_{\text{raw}}[b,t,hD+d] + \text{pos\_bias}[h,d]
$$

因此，本题同时检查两个结果：

$$
\text{qkv}[:, :, :HD] = Q_{\text{raw}} + \text{query\_bias}
$$

以及

$$
\text{pos\_query}[b,h,t,d] = Q_{\text{raw}}[b,t,hD+d] + \text{pos\_bias}[h,d]
$$

特别注意，这两条支路都基于同一个原始 query 段 `Q_raw`，但 `pos_query` 不应使用已经加过 `query_bias` 的结果；它只和 `pos_bias` 相加。这一点必须与 baseline 完全一致。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## PyTorch 参考实现

```python
def baseline(*inputs):
    qkv, query_bias, pos_bias, pos_query, B, T, H, D, max_seqlen = inputs
    # Inline reference (no direct torch_ref import).
    # Matches torch_ref.Model.forward: in-place add query_bias to qkv query part,
    # and returns pos_query = (q_raw + pos_bias) reshaped to [B, H, T, D].
    _ = max_seqlen
    assert qkv.shape == (B, T, 3 * H * D)
    assert query_bias.shape == (H, D)
    assert pos_bias.shape == (H, D)
    assert pos_query.shape == (B, H, T, D)

    q_raw = qkv[:, :, : H * D].clone()
    pos_query_ref = q_raw + pos_bias.view(1, 1, H * D)

    # In-place update qkv
    qkv[:, :, : H * D] += query_bias.view(1, 1, H * D)

    pos_query_ref = pos_query_ref.view(B, T, H, D).permute(0, 2, 1, 3).contiguous()
    ref = pos_query_ref
    pos_query.copy_(ref)
    return [qkv, query_bias, pos_bias, pos_query, B, T, H, D, max_seqlen]
```
