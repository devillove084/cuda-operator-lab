## 题目描述

你需要实现一个融合算子：

> **c = softplus(a @ b + bias)**

给定输入矩阵 `a`（shape 为 `(M, K)`）、输入矩阵 `b`（shape 为 `(K, N)`）和偏置向量 `bias`（shape 为 `(N,)`），先计算矩阵乘法并对每一列加上对应偏置，然后对结果逐元素施加 Softplus 激活函数。

Softplus 定义为：

```text
softplus(x) = log(1 + exp(x))
```

具体计算方式为：

$$
x_{i,j} = \sum_{k=0}^{K-1} a_{i,k} \cdot b_{k,j} + bias_j
$$

$$
c_{i,j} = \log(1 + \exp(x_{i,j}))
$$

其中 $i \in [0, M)$，$j \in [0, N)$。

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 `GEMM + Bias + Softplus` 的融合计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 计算过程

本题计算 $c = \text{softplus}(a @ b + bias)$。首先计算矩阵乘法并加上 bias：

```
a @ b + bias =
[[3.6, -0.2, 3.3],
 [7.6, 0.8, 5.3]]
```

然后对每个元素应用 Softplus：

* $c_{0,0} = \log(1 + \exp(3.6)) \approx 3.62696$
* $c_{0,1} = \log(1 + \exp(-0.2)) \approx 0.59814$
* $c_{0,2} = \log(1 + \exp(3.3)) \approx 3.33622$
* $c_{1,0} = \log(1 + \exp(7.6)) \approx 7.60050$
* $c_{1,1} = \log(1 + \exp(0.8)) \approx 1.17110$
* $c_{1,2} = \log(1 + \exp(5.3)) \approx 5.30498$

## 数据范围与提示

## 数据范围

* $1 \le M, N, K \le 8192$
* $a$、$b$、$bias$、$c$ 的数据类型均为 `torch.float32`
* `a` 的 shape 为 $(M, K)$
* `b` 的 shape 为 $(K, N)$
* `bias` 的 shape 为 $(N,)$
* `c` 的 shape 为 $(M, N)$
* 所有 tensor 均为连续存储（contiguous）

## 正确性要求

* 必须将结果写入 $c$，使得每个元素满足 $c_{i,j} = \log(1 + \exp(\sum_{k=0}^{K-1} a_{i,k} \cdot b_{k,j} + bias_j))$
* 不允许修改 $a$、$b$ 和 $bias$

## 提示

* 本题不是单纯的矩阵乘法，不能漏掉按列广播的 $bias$ 或 Softplus 激活
* 为避免数值溢出，可以使用数学等价的稳定 Softplus 计算方式

## PyTorch 参考实现

```python
import torch
import torch.nn.functional as F

def baseline(a, b, bias, c, M, N, K):
    """
    PyTorch 参考实现：c = softplus(a @ b + bias)

    参数说明：
    * a: 输入张量（float32），shape (M, K)，行优先连续存储，只读
    * b: 输入张量（float32），shape (K, N)，行优先连续存储，只读
    * bias: 输入张量（float32），shape (N,)，只读
    * c: 输出张量（float32），shape (M, N)，行优先连续存储，需写入结果
    * M: a 的行数，也是 c 的行数（int64）
    * N: b 的列数，也是 c 的列数（int64）
    * K: a 的列数，也是 b 的行数（int64）
    """
    c_ref = F.softplus(torch.matmul(a, b) + bias)
    c.copy_(c_ref)
```
