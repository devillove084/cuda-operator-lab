## 题目描述

你需要实现带 KV Cache 的 Flash MLA 注意力。当前题目不仅要求输出注意力结果 `out`，还要求输出每个查询位置、每个 head 的 `softmax_lse`，也就是打分矩阵在最后一维上的 `logsumexp`。与普通 attention 不同，本题的 `K/V` 来自分页缓存 `k_cache`，并通过 `block_table` 给出每个样本所使用的块编号。

设输入 query 张量为：

$$
Q \in \mathbb{R}^{B \times S_q \times H_q \times D}
$$

其中 $B$ 是 batch size，$S_q$ 是 query 长度，$H_q$ 是 query 头数，$D$ 是单头维度。对第 $b$ 个样本，`cache_seqlens[b]` 给出它当前缓存中的历史长度，记为 $L_b$；`page_block_size` 记为 $P$，则该样本需要恢复的缓存块数为：

$$
N_b = \left\lceil \frac{L_b}{P} \right\rceil
$$

`block_table[b, p]` 给出第 $p$ 个块槽位对应的块编号。对于每个有效块

$$
\text{block\_id}_{b,p} = \text{block\_table}[b, p], \quad 0 \le p < N_b
$$

从 `k_cache` 中取出：

$$
K^{\text{block}}_{b,p} \in \mathbb{R}^{P \times H_k \times D}
$$

并沿时间维拼接：

$$
\widetilde{K}_b = \operatorname{concat}\!\left(K^{\text{block}}_{b,0}, \dots, K^{\text{block}}_{b,N_b-1}\right)
$$

然后截断到真实缓存长度 $L_b$：

$$
K_b = \widetilde{K}_b[:L_b] \in \mathbb{R}^{L_b \times H_k \times D}
$$

为了做按 head 的注意力，baseline 会把它重排成：

$$
K_b^{\top} \in \mathbb{R}^{H_k \times L_b \times D}
$$

如果 $H_k \neq H_q$，则按照 GQA 的语义在 head 维上重复 KV heads。令

$$
g = \frac{H_q}{H_k}
$$

则扩展后得到：

$$
\widehat{K}_b \in \mathbb{R}^{H_q \times L_b \times D}
$$

本题中的 value 向量直接取 `K` 的前 `dv` 个通道；由于本题测试里 `dv = D`，可以把它理解为：

$$
\widehat{V}_b = \widehat{K}_b \in \mathbb{R}^{H_q \times L_b \times D}
$$

对第 $b$ 个样本、第 $h$ 个 head、第 $u$ 个 query 位置，记 query 向量为 $Q[b, u, h, :]$。打分定义为：

$$
S_b^{(h)}[u, t] = \left\langle Q[b, u, h, :], \widehat{K}_b[h, t, :] \right\rangle
$$

若存在 mask，则需要先把不允许访问的位置加上 $-\infty$。本题中的 mask 可能来自两种来源：

$$
M_b[u, t] =
\begin{cases}
0, & \text{位置可见} \\
-\infty, & \text{位置不可见}
\end{cases}
$$

其中“可见”由 `causal` 约束或可选的 `indices` 稀疏索引约束决定。于是缩放后的分数矩阵为：

$$
\widetilde{S}_b^{(h)}[u, t] = \frac{S_b^{(h)}[u, t] + M_b[u, t]}{\sqrt{D}}
$$

接着计算 softmax 权重：

$$
P_b^{(h)}[u, t] = \frac{\exp(\widetilde{S}_b^{(h)}[u, t])}{\sum_{j=0}^{L_b-1} \exp(\widetilde{S}_b^{(h)}[u, j])}
$$

输出为：

$$
\text{out}[b, u, h, :] = \sum_{t=0}^{L_b-1} P_b^{(h)}[u, t] \, \widehat{V}_b[h, t, :]
$$

同时，本题还要求写回每个位置的对数归一化项：

$$
\text{softmax\_lse}[b, h, u] = \log \left( \sum_{t=0}^{L_b-1} \exp(\widetilde{S}_b^{(h)}[u, t]) \right)
$$

如果某个 query 位置在 mask 之后没有任何可见 key，则 baseline 会把该位置的输出置为全零，并把对应的 `softmax_lse` 设为 $+\infty$。

因此，本题需要同时正确处理四件事：从 `block_table` 恢复连续缓存、按 GQA 规则扩展 KV heads、按 mask 规则构造可见性、以及同时写回 `out` 与 `softmax_lse` 两个输出。

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 直接内联参考逻辑，不依赖 torch_ref.py。
    """
    q, k_cache, block_table, cache_seqlens, tile_scheduler_metadata, num_splits, \
        softmax_scale, causal, is_fp8_kvcache, indices, out, softmax_lse, \
        batch_size, seq_len_q, num_heads_q, head_dim, num_blocks, page_block_size, \
        num_heads_k, max_num_blocks_per_seq, indices_topk = inputs

    assert torch.is_tensor(q) and torch.is_tensor(k_cache)
    assert torch.is_tensor(block_table) and torch.is_tensor(cache_seqlens)
    assert torch.is_tensor(tile_scheduler_metadata) and torch.is_tensor(num_splits)
    assert torch.is_tensor(out) and torch.is_tensor(softmax_lse)
    assert isinstance(softmax_scale, float)
    assert isinstance(causal, int)
    assert isinstance(is_fp8_kvcache, int)
    assert torch.is_tensor(indices)
    assert isinstance(indices_topk, int)

    # Cross-check scalar args against tensor shapes.
    assert (batch_size, seq_len_q, num_heads_q, head_dim) == q.shape
    nb, pbs, hk, _ = k_cache.shape
    assert nb == num_blocks
    assert pbs == page_block_size
    assert hk == num_heads_k
    assert block_table.shape == (batch_size, max_num_blocks_per_seq)

    assert page_block_size == 64
    assert q.dtype == torch.bfloat16
    assert k_cache.dtype == torch.bfloat16
    assert block_table.dtype == torch.int32
    assert cache_seqlens.dtype == torch.int32
    assert is_fp8_kvcache == 0
    assert tile_scheduler_metadata.shape == (1, 1)
    assert num_splits.shape == (batch_size + 1,)

    cache_seqlens_cpu = cache_seqlens.cpu()
    out_ref = torch.empty(batch_size, seq_len_q, num_heads_q, head_dim, dtype=torch.float32, device=q.device)
    lse_ref = torch.empty(batch_size, num_heads_q, seq_len_q, dtype=torch.float32, device=q.device)

    indices_view: Optional[torch.Tensor] = None
    if indices_topk > 0:
        indices_view = indices.view(batch_size, seq_len_q, indices_topk)

    for i in range(batch_size):
        cur_len = cache_seqlens_cpu[i].item()
        cur_num_blocks = _cdiv(cur_len, page_block_size)
        cur_block_indices = block_table[i][0:cur_num_blocks]
        cur_kv = k_cache[cur_block_indices].view(-1, num_heads_k, head_dim)[:cur_len, ...]

        cur_out, cur_lse = _scaled_dot_product_attention(
            q[i].transpose(0, 1),
            cur_kv.transpose(0, 1),
            head_dim,
            causal,
            indices_view[i] if indices_view is not None else None,
        )
        out_ref[i] = cur_out.transpose(0, 1)
        lse_ref[i] = cur_lse

    out.copy_(out_ref.to(torch.bfloat16))
    softmax_lse.copy_(lse_ref)

    return [
        q,
        k_cache,
        block_table,
        cache_seqlens,
        tile_scheduler_metadata,
        num_splits,
        softmax_scale,
        causal,
        is_fp8_kvcache,
        indices,
        out,
        softmax_lse,
        batch_size,
        seq_len_q,
        num_heads_q,
        head_dim,
        num_blocks,
        page_block_size,
        num_heads_k,
        max_num_blocks_per_seq,
        indices_topk,
    ]
```
