# FP8 Mqa Logits

## 题目描述

你需要提交一份代码，实现一个 FP8 Multi-Query Attention logits 算子：

> **logits = fp8_mqa_logits(q, kv, kv_sf, weights, cu_seqlen_ks, cu_seqlen_ke)**

本题对应 SeedKernelBench `layer/035_fp8_mqa_logits`，其核心计算流程为：

1. `q` 和 `kv` 均为 `FP8 E4M3`
2. 将 `q` 转成 `float32`
3. 将 `kv` 转成 `float32`，并按行乘以 `kv_sf`
4. 对每个 head 计算 `score = q @ kv.T`
5. 对 `score` 做 `ReLU`
6. 按 `weights[m, h]` 加权并在 head 维求和
7. 对不在 `[cu_seqlen_ks[m], cu_seqlen_ke[m])` 范围内的位置写成 `-inf`

评测程序会将你的源码编译为 **动态链接库（.so）**，并在 GPU 上通过 FFI 调用你导出的函数：

* `run_kernel`：由你在函数内部计算合适的 launch 配置并完成 logits 计算

评测同时会进行：

* **性能计时**
* **正确性校验**

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输入格式

本题的“输入”由评测程序在 GPU 上构造并传入 `run_kernel`。

评测会生成以下参数并按顺序传入 `run_kernel`：

1. `q`：FP8 E4M3 CUDA tensor，shape `(M, num_heads, head_dim)`
2. `kv`：FP8 E4M3 CUDA tensor，shape `(seq_len_kv, head_dim)`
3. `kv_sf`：FP32 CUDA tensor，shape `(seq_len_kv,)`
4. `weights`：FP32 CUDA tensor，shape `(M, num_heads)`
5. `cu_seqlen_ks`：INT32 CUDA tensor，shape `(M,)`
6. `cu_seqlen_ke`：INT32 CUDA tensor，shape `(M,)`
7. `logits`：FP32 CUDA tensor，shape `(M, seq_len_kv)`，输出缓冲区
8. `M`：int64 标量
9. `seq_len_kv`：int64 标量
10. `num_heads`：int64 标量
11. `head_dim`：int64 标量

## 输出格式

输出 `logits` 为一个 `float32` 张量，shape `(M, seq_len_kv)`。

对每个 `m`、`n`：

```text
score[h, m, n] = sum_d(float(q[m, h, d]) * (float(kv[n, d]) * kv_sf[n]))
score[h, m, n] = relu(score[h, m, n])
logits[m, n] = sum_h(score[h, m, n] * weights[m, h])
```

然后应用 mask：

```text
if n < cu_seqlen_ks[m] or n >= cu_seqlen_ke[m]:
    logits[m, n] = -inf
```

## 样例

## 输入

设：

```text
M = 2
seq_len_kv = 4
num_heads = 2
head_dim = 2
```

则：

* `q` 的形状为 `(2, 2, 2)`
* `kv` 的形状为 `(4, 2)`
* `kv_sf` 的形状为 `(4,)`
* `weights` 的形状为 `(2, 2)`
* `cu_seqlen_ks` 与 `cu_seqlen_ke` 的形状均为 `(2,)`

例如可以有如下 attention window：

```text
cu_seqlen_ks = [0, 1]
cu_seqlen_ke = [4, 3]
```

这表示：

* 第 0 个 query 位置可访问 kv 的 `[0, 4)` 区间
* 第 1 个 query 位置可访问 kv 的 `[1, 3)` 区间

## 输出

输出 `logits` 的形状为 `(2, 4)`。

对于第 0 个 query 位置，会对全部 4 个 kv 位置计算：

```text
score[h, 0, n] = relu(sum_d(float(q[0, h, d]) * (float(kv[n, d]) * kv_sf[n])))
logits[0, n] = sum_h(score[h, 0, n] * weights[0, h])
```

对于第 1 个 query 位置，只有 `n in [1, 3)` 保留，其余位置写成 `-inf`：

```text
logits[1, 0] = -inf
logits[1, 1] = valid score
logits[1, 2] = valid score
logits[1, 3] = -inf
```

* `kv_sf.dtype == torch.float32`

* `cu_seqlen_ks.dtype == torch.int32`
* `cu_seqlen_ke.dtype == torch.int32`
* `logits.dtype == torch.float32`

## 正确性要求

* **必须正确处理 FP8 到 FP32 的转换**
* **必须正确应用 `kv_sf`**
* **必须正确做 ReLU、按 head 加权求和**
* **必须正确应用区间 mask，并写入 `-inf`**

## 提示

* `kv` 是所有 head 共享的，因此只需要沿 `seq_len_kv` 维与每个 head 的 `q` 做乘法
* 可以按 head 逐个累加，避免构造过大的中间张量
* 被 mask 掉的位置必须写成 `float('-inf')`

## PyTorch 参考实现

```python
def baseline(q, kv, kv_sf, weights, cu_seqlen_ks, cu_seqlen_ke, logits, M, seq_len_kv, num_heads, head_dim):
    """
    PyTorch 参考实现：FP8 MQA logits

    参数说明：
    * q: 输入张量，shape (M, num_heads, head_dim)，dtype 为 torch.float8_e4m3fn
    * kv: 输入张量，shape (seq_len_kv, head_dim)，dtype 为 torch.float8_e4m3fn
    * kv_sf: 输入张量，shape (seq_len_kv,)，dtype 为 torch.float32
    * weights: 输入张量，shape (M, num_heads)，dtype 为 torch.float32
    * cu_seqlen_ks: 输入张量，shape (M,)，dtype 为 torch.int32
    * cu_seqlen_ke: 输入张量，shape (M,)，dtype 为 torch.int32
    * logits: 输出张量，shape (M, seq_len_kv)，dtype 为 torch.float32
    """
    q_fp32 = q.float()
    kv_fp32 = kv.float() * kv_sf.unsqueeze(-1)
    out = torch.zeros(M, seq_len_kv, dtype=torch.float32, device=q.device)
    for h in range(num_heads):
        score_h = torch.matmul(q_fp32[:, h, :], kv_fp32.t()).relu()
        out = out + score_h * weights[:, h:h + 1]
    ar = torch.arange(0, seq_len_kv, device=q.device, dtype=torch.int32)[None, :]
    mask = (ar >= cu_seqlen_ks[:, None]) & (ar < cu_seqlen_ke[:, None])
    logits.copy_(out.masked_fill(~mask, float("-inf")))
```
