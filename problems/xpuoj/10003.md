# Native Sparse Attention

XPUOJ · #10003

[打开实现文件](../../practice/xpuoj/10003/solution.py) · [原始材料](../../references/XPUOJ/problem_10003/zh_CN/00_%E9%A2%98%E7%9B%AE%E6%8F%8F%E8%BF%B0.md)

## 题目描述

你需要实现 Native Sparse Attention 前向算子。

给定 query、key、value 以及每个 query token 选中的稀疏 block 下标，本题只对被选中的 KV block 做 causal attention：

```text
score = q @ k_selected^T / sqrt(D)
attention = softmax(score)
output = attention @ v_selected
```

其中 query heads 采用 GQA 布局：`HQ` 个 query heads 共享 `H` 个 KV heads，`G = HQ / H`。

评测程序会调用你提交代码中的 `run_kernel` 函数。你需要根据 `block_indices` 读取被选中的 KV block，并将结果写入 `output`。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

你必须在提交的 Python 代码中提供 `run_kernel` 函数，函数名、参数顺序、类型必须完全一致：

```python
def run_kernel(
    q,             # Tensor[float16], shape (B, seq_len, HQ, D)
    k,             # Tensor[float16], shape (B, seq_len, H, D)
    v,             # Tensor[float16], shape (B, seq_len, H, D)
    block_indices, # Tensor[int32], shape (B, seq_len, H, S)
    output,        # Tensor[float16], shape (B, seq_len, HQ, D)
    B,             # int64
    seq_len,       # int64
    H,             # int64
    HQ,            # int64
    D,             # int64
    S,             # int64
    block_size,    # int64
    is_causal,     # int64, 1 in tests
):
    ...
```

### 参数说明

* `q`：query tensor，shape `(B, seq_len, HQ, D)`
* `k`：key tensor，shape `(B, seq_len, H, D)`
* `v`：value tensor，shape `(B, seq_len, H, D)`
* `block_indices[b, t, h, s]`：第 `b` 个 batch、第 `t` 个 query、第 `h` 个 KV head 选中的第 `s` 个 KV block
* `output`：输出缓冲区，shape `(B, seq_len, HQ, D)`
* `block_size`：每个 sparse block 包含的 token 数
* `is_causal`：是否使用 causal mask，评测中固定为 1

无效 block 使用 `seq_len` 作为哨兵值。

## 输入格式

本题输入由评测程序在 GPU 上构造，并按接口约定中的顺序传入 `run_kernel`。

所有 `q/k/v/output` 均为连续 `float16` CUDA tensor，`block_indices` 为连续 `int32` CUDA tensor。

## 输出格式

输出写入 `output`，shape 为 `(B, seq_len, HQ, D)`，类型为 `float16`。

## 样例

若 `block_size = 16`，`block_indices[b, t, h, 0] = 3`，则该 query 会访问 KV token 区间 `[48, 64)`。

启用 causal mask 时，区间中位置大于当前 query token `t` 的 token 不参与 softmax。

## 数据范围与提示

测试点覆盖：

* `B`：1、2、4、8
* `seq_len`：64 到 8192
* `H`：1 或 2
* `HQ`：16 或 32
* `D`：32、64、128
* `S`：1、2、4、8
* `block_size`：16 或 32
* `is_causal`：1

注意：

* `G = HQ / H`，同一个 KV head 服务连续的 `G` 个 query heads。
* `block_indices` 中的无效 block 值为 `seq_len`，必须跳过。
* 输出参与 `torch.allclose` 校验，容差为 `rtol=1e-2, atol=1e-2`。
* 为保证计时准确，不建议在 `run_kernel` 内部调用显式同步。
