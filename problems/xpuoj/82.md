## 题目描述

你需要实现逐样本 Softmax Cross Entropy Loss。

输入 `logits` 的 shape 为 `(M, V)`，类型为 `float16`；输入 `labels` 的 shape 为 `(M,)`，类型为 `int64`；输出 `losses` 的 shape 为 `(M,)`，类型为 `float32`。

对第 `i` 个样本，先在词表维度计算 softmax cross entropy。baseline 等价于：

```python
F.cross_entropy(
    logits.float(),
    labels,
    ignore_index=padding_idx,
    reduction="none",
    label_smoothing=smoothing,
)
```

因此当 `labels[i] == padding_idx` 时，该样本的 loss 按 PyTorch `ignore_index` 语义处理；当 `smoothing > 0` 时，按 PyTorch `label_smoothing` 语义计算平滑交叉熵。你需要把每个样本的 loss 写入 `losses[i]`，不做 batch 维求和或平均。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## PyTorch 参考实现

```python
def baseline(*inputs):
    logits, labels, losses, M, V, smoothing, padding_idx = inputs
    assert logits.shape == (M, V)
    assert labels.shape == (M,)
    ref = F.cross_entropy(
        logits.float(),
        labels,
        ignore_index=int(padding_idx),
        reduction="none",
        label_smoothing=float(smoothing),
    )
    losses.copy_(ref)
    return [logits, labels, losses, M, V, smoothing, padding_idx]
```
