## 题目描述

你需要提交一份代码，实现一个 fp16 的原地加法算子：

> **A += B（inplace）**

评测程序调用程序中的 `run_kernel` 函数，由你在函数内部计算合适的 grid/block 并 launch kernel，完成 `A[i] += B[i]`（fp16）

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_fp16.h>

extern "C" void run_kernel(__half* A, const __half* B, int64_t numel);
```

### 参数说明

* `A`：输入/输出指针（fp16），必须原地写回
* `B`：输入指针（fp16），只读
* `numel`：元素总数（int64）

`run_kernel` 内部需要：

* 自行计算合适的 grid/block
* launch 你实现的 CUDA `__global__` kernel 完成 `A += B`

### tilelang

```python
import tilelang
import tilelang.language as T
from tilelang import jit

real_kernel = None

@jit
def add(*args):
    @T.prim_func
    def kernel(*args):
        ...
    return kernel

def run_kernel(
    A,  # Tensor[fp16]
    B,  # Tensor[fp16]
    numel,  # int64
):
    global real_kernel
    if real_kernel is None:
        real_kernel = add(...)
    real_kernel(A, B, numel)
```

### 参数说明

* `A`：输入/输出tensor（fp16），必须原地写回

* `numel`：元素总数

`run_kernel` 内部需要：

* 自行计算合适的 grid/block

## 输入格式

本题的“输入”由评测程序在 GPU 上构造并传入 `run_kernel`。

评测会生成以下参数并按顺序传入 `run_kernel`：

1. `A`：fp16 tensor（连续存储）
2. `B`：fp16 tensor（与 A 同 shape，同 dtype，连续存储）
3. `numel`：int64 标量，等于 `A.numel()`（元素总数）

## 输出格式

一个修改后的 fp16 tensor `A`， 满足
$$
A_{\text{out}} = A_{\text{in}} + B
$$

## 样例

## 输入
```
A: [1, 2, 3, 4]
B: [2, 3, 4, 5]
numel: 4
```

## 输出
```
A: [3, 5, 7, 9]
```

## 数据范围与提示

## 数据范围

* `A` 与 `B` 为 `torch.float16`（fp16）
* `A.shape == B.shape`
* `A`、`B` 为连续存储（contiguous）
* `numel = A.numel()`

## 正确性要求

* **必须原地修改 A**：执行后 A 的每个元素应满足
  `A_out[i] = A_in[i] + B_in[i]`
* 不允许修改 B
