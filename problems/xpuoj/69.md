## 题目描述

你需要实现一个复数双精度矩阵乘法算子：

> **C = A @ B**

给定输入矩阵 $A$（shape 为 $(M, K)$）和 $B$（shape 为 $(K, N)$），计算输出矩阵 $C = A \times B$，其中 $C$ 的 shape 为 $(M, N)$。具体计算方式为：

$$
C_{i,j} = \sum_{k=0}^{K-1} A_{i,k} \cdot B_{k,j}
$$

其中 $i \in [0, M)$，$j \in [0, N)$，乘法和加法都在复数域上进行。

本题名称中的 Gaussian 表示实现时可以采用 Gaussian complex multiplication 等方式减少实数乘法次数；但评测只检查最终复数结果是否正确，不要求必须使用特定算法。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel，或调用等价的 GPU 复数矩阵乘法实现来完成上述计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 计算过程说明

本题计算 $C = A @ B$。

* $C_{0,0} = (1 + 2i)(2 + 0i) + (3 - 1i)(-1 + 2i) = 1 + 11i$
* $C_{0,1} = (1 + 2i)(1 - 1i) + (3 - 1i)(0 + 3i) = 6 + 10i$
* $C_{1,0} = (0 + 1i)(2 + 0i) + (2 + 0i)(-1 + 2i) = -2 + 6i$
* $C_{1,1} = (0 + 1i)(1 - 1i) + (2 + 0i)(0 + 3i) = 1 + 7i$
