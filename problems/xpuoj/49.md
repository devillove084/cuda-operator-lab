## 题目描述

你需要实现一个 3D 转置卷积（deconvolution）前向传播算子：

> **output = conv_transpose3d(x, weight, bias, stride, padding, output_padding)**

给定输入张量 `x`、卷积核 `weight`、偏置 `bias`、步长 `stride`、填充 `padding` 和 `output_padding`，你需要计算一个标准的 `conv_transpose3d`。

为了适配 OJ，本题固定要求传入 `bias`，并使用 PyTorch 的 `torch.nn.functional.conv_transpose3d` 作为参考语义：

* 输入、权重、偏置都按 `float32` 参与计算
* 输出写入 `float32` 张量
* 结果按 `allclose` 容差校验，不要求逐 bit 完全一致

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 3D 转置卷积前向传播。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输入格式

评测程序在 GPU 上构造并传入以下参数：

* `x`：shape `(N, C_in, D, H, W)`
* `weight`：shape `(C_in, C_out, T, R, S)`
* `bias`：shape `(C_out,)`
* `output`：shape `(N, C_out, D_out, H_out, W_out)`
* `N, C_in, C_out, D, H, W, T, R, S, stride, padding, output_padding`

## 输出格式

```text
D_out = (D - 1) * stride - 2 * padding + T + output_padding
H_out = (H - 1) * stride - 2 * padding + R + output_padding
W_out = (W - 1) * stride - 2 * padding + S + output_padding

output[n, c_out, d, h, w] =
    bias[c_out] +
    sum_{c_in, d_in, h_in, w_in, k_d, k_h, k_w}
        x[n, c_in, d_in, h_in, w_in] * weight[c_in, c_out, k_d, k_h, k_w]
```

仅当以下关系成立时，对应项才参与累加：

```text
d = d_in * stride - padding + k_d
h = h_in * stride - padding + k_h
w = w_in * stride - padding + k_w
```

* 必须正确累加全部输入通道与卷积核空间维度

## 提示

* 可以按输出坐标反推输入坐标，只在整除且未越界时参与累加
* `output_padding` 只影响输出形状，不会改变映射公式
* 评测使用 `torch.nn.functional.conv_transpose3d` 作为参考实现
