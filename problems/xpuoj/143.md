# GEMM Softmax Cross Entropy

XPUOJ · #143

原题 https://xpuoj.com/p/143

## 题目描述

你需要实现一个 GEMM + Softmax + Cross Entropy 融合算子。给定输入矩阵 `hidden`、权重矩阵 `weight` 和标签向量 `labels`，先计算分类 logits：

$$
logits = hidden \times weight^T
$$

然后对每一行 logits 计算 softmax cross entropy，并对所有 $M$ 行取平均，得到标量 `loss`。

逐元素写为：

$$
logits_{i,j} = \sum_{k=0}^{K-1} hidden_{i,k} \cdot weight_{j,k}
$$

$$
loss = \frac{1}{M}\sum_{i=0}^{M-1}\left(\log\sum_{j=0}^{N-1}\exp(logits_{i,j}) - logits_{i,labels_i}\right)
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* hidden,
    const __nv_bfloat16* weight,
    const int64_t* labels,
    float* loss,
    int64_t M,
    int64_t K,
    int64_t N
);
```

### 参数说明

* `hidden`：输入指针（bfloat16），shape $(M, K)$，行优先连续存储，只读
* `weight`：输入指针（bfloat16），shape $(N, K)$，行优先连续存储，只读
* `labels`：输入指针（int64），shape $(M,)$，每个元素满足 $0 \le labels_i < N$，只读
* `loss`：输出指针（float32），shape $()$，需写入平均 cross entropy loss
* `M`：batch 大小，也是 `hidden` 的行数和 `labels` 的长度（int64）
* `K`：隐藏维度，也是 `hidden` 和 `weight` 的列数（int64）
* `N`：类别数，也是 `weight` 的行数（int64）

`run_kernel` 内部需要完成以下工作：

* 计算 `hidden @ weight.T` 对应的 logits
* 使用数值稳定的方式计算每行 softmax cross entropy
* 对所有行求平均，并将标量结果写入 `loss`

## 正确性要求

* 必须正确实现矩阵乘法 `hidden @ weight.T`
* 必须正确使用 `labels` 选择目标类别
* 必须正确计算 mean softmax cross entropy
* 必须将最终结果写入 `loss`

## 提示

* 推荐使用 log-sum-exp 技巧提高 softmax 的数值稳定性
* `weight` 的布局是 $(N, K)$，本题计算的是 `hidden @ weight.T`
* 本题 loss 采用 PyTorch `F.cross_entropy` 的默认 mean reduction

## PyTorch 参考实现

```python
def baseline(hidden, weight, labels, loss, M, K, N):
    logits = torch.matmul(hidden.float(), weight.float().t())
    value = F.cross_entropy(logits, labels, reduction='mean')
    loss.copy_(value.reshape(()))
```
