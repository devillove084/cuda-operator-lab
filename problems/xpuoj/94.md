## 题目描述

你需要实现一个 Im2col Remove Padding 算子。给定输入张量 `X`（shape 为 `(sum_t, w_in, channels)`）以及前缀和张量 `cu_seqlens`（shape 为 `(batch_size + 1,)`），你需要把每个 batch 内的二维特征块按卷积窗口展开成列，并去掉不同 batch 之间的 padding。

这里 `cu_seqlens[b]` 和 `cu_seqlens[b+1]` 给出了第 `b` 个样本在 `X` 第 0 维上的起止位置，因此：

$$
seqlen_b = cu\_seqlens[b+1] - cu\_seqlens[b]
$$

设：

$$
w\_out = \frac{w\_in - kernel\_size + 2 \cdot padding}{stride} + 1
$$

对每个 batch `b`，输出高度为：

$$
seqlen\_{out,b} = \frac{seqlen_b - kernel\_size + 2 \cdot padding}{stride} + 1
$$

然后定义输出前缀和：

$$
cu\_seqlens\_out[0] = 0
$$

$$
cu\_seqlens\_out[b+1] = cu\_seqlens\_out[b] + seqlen\_{out,b}
$$

最终输出张量 `Y` 的 shape 为：

$$
(sum\_t\_out,\; w\_out,\; channels \cdot kernel\_size \cdot kernel\_size)
$$

其中：

$$
sum\_t\_out = cu\_seqlens\_out[batch\_size]
$$

对于每个 batch `b`、输出位置 `(h_out, w_out_pos)`、卷积核位置 `(k_h, k_w)` 以及通道 `c`，有：

$$
h\_in = h\_out \cdot stride - padding + k_h
$$

$$
w\_{in,pos} = w\_{out,pos} \cdot stride - padding + k_w
$$

若 `h_in` 与 `w_in_pos` 在输入范围内，则：

$$
Y[out\_token,\; w\_{out,pos},\; c \cdot kernel\_size \cdot kernel\_size + k_h \cdot kernel\_size + k_w]
=
X[in\_token,\; w\_{in,pos},\; c]
$$

否则该位置填 `0`。

其中：

$$
in\_token = cu\_seqlens[b] + h\_in
$$

$$
out\_token = cu\_seqlens\_out[b] + h\_out
$$

同时还需要输出：

$$
max\_t\_out = \max_b seqlen\_{out,b}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要完成上述 im2col remove padding 计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 计算过程说明

由 `cu_seqlens = [0, 3, 5]` 可知：

* 第 `0` 个 batch 的高度为 `3`
* 第 `1` 个 batch 的高度为 `2`

因为：

$$
w\_out = (3 - 2 + 0) // 1 + 1 = 2
$$

所以每个输出 token 都会生成 `2` 个横向位置。

对第 `0` 个 batch：

* `seqlen_out = (3 - 2 + 0) // 1 + 1 = 2`
* 因此会产生两个输出 token

第一个输出 token 对应输入高度窗口 `[0, 1]`：

* `w_out_pos = 0` 时，取到的 `2x2` patch 为

```text
[[1, 2],
 [4, 5]]
```

  展平后得到 `[1, 2, 4, 5]`

* `w_out_pos = 1` 时，取到的 `2x2` patch 为

```text
[[2, 3],
 [5, 6]]
```

  展平后得到 `[2, 3, 5, 6]`

第二个输出 token 对应输入高度窗口 `[1, 2]`，同理得到：

* `[4, 5, 7, 8]`
* `[5, 6, 8, 9]`

对第 `1` 个 batch：

* `seqlen_out = (2 - 2 + 0) // 1 + 1 = 1`
* 只产生一个输出 token，对应窗口 `[0, 1]`
* 两个横向位置分别得到：
  * `[10, 11, 13, 14]`
  * `[11, 12, 14, 15]`

因此：

* `cu_seqlens_out = [0, 2, 3]`
* `max_t_out = max(2, 1) = 2`

## PyTorch 参考实现

```python
import torch.nn.functional as F

def baseline(X, cu_seqlens, Y, cu_seqlens_out, max_t_out,
             batch_size, w_in, channels, kernel_size, stride, padding):
    seqlens_out = []
    Y_list = []
    out_w = (w_in - kernel_size + padding * 2) // stride + 1
    cu_out = [0]
    for b in range(batch_size):
        seq_start = cu_seqlens[b].item()
        seq_end = cu_seqlens[b + 1].item()
        seqlen = seq_end - seq_start
        seqlen_out = (seqlen - kernel_size + padding * 2) // stride + 1
        seqlens_out.append(seqlen_out)
        X_b = X[seq_start:seq_end].permute(2, 0, 1).unsqueeze(0)
        Y_b = F.unfold(
            X_b,
            kernel_size=(kernel_size, kernel_size),
            dilation=1,
            stride=(stride, stride),
            padding=(padding, padding),
        )
        Y_b = Y_b.view(1, channels * kernel_size * kernel_size, seqlen_out, out_w)
        Y_b = Y_b.permute(0, 2, 3, 1).contiguous().squeeze(0)
        Y_list.append(Y_b)
        cu_out.append(cu_out[-1] + seqlen_out)

    Y.copy_(torch.cat(Y_list, dim=0))
    cu_seqlens_out.copy_(torch.tensor(cu_out, dtype=torch.int32, device=cu_seqlens.device))
    max_t_out.copy_(torch.tensor(max(seqlens_out), dtype=torch.int32, device=cu_seqlens.device))
```
