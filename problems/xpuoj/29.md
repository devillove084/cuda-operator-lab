## 题目描述

你需要实现一个 FP64 三角矩阵乘法算子：

> **output = alpha * (triangular(a) @ b)**

给定一个方阵 `a`、一个矩阵 `b`、一个标量 `alpha` 和一个布尔值 `upper`，你需要先从 `a` 中取出上三角或下三角部分，再与 `b` 做矩阵乘法，最后乘以 `alpha`。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 TRMM 的计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## PyTorch 参考实现

```python
def baseline(a, b, output, alpha, upper, M, N):
    if upper:
        a_tri = torch.triu(a.double())
    else:
        a_tri = torch.tril(a.double())
    output.copy_(alpha * torch.matmul(a_tri, b.double()))
```
