# Awq Marlin Repack

## 题目描述

你需要实现一个 AWQ Marlin Repack 算子。

给定按 AWQ 方式打包后的量化权重 `b_q_weight`，你需要将它重排为 Marlin kernel 使用的 packed 格式，并写入输出张量 `repacked_weight`。

设每个量化值占用的 bit 数为 `num_bits`，则：

$$
pack\_factor = \frac{32}{num\_bits}
$$

其中 `num_bits` 只能取 `4` 或 `8`。

输入张量 `b_q_weight` 的 shape 为 $(size_k, size_n / pack\_factor)$，输出张量 `repacked_weight` 的 shape 为 $(size_k / 16, size_n \cdot (num\_bits / 2))$。本题要求你严格按照参考规则完成以下过程：

1. 将 AWQ packed 权重按位解包成未打包矩阵
2. 按 Marlin 所需的 tile 和固定置换规则重排
3. 将重排后的结果重新打包为 `int32`

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述重排。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `b_q_weight`：`int32` tensor，shape $(size_k, size_n / pack\_factor)$，行优先连续存储
* `repacked_weight`：`int32` tensor，shape $(size_k / 16, size_n \cdot (num\_bits / 2))$，作为输出缓冲区，初始值未定义
* `size_k`：`int64` 标量
* `size_n`：`int64` 标量
* `num_bits`：`int64` 标量，取值为 `4` 或 `8`

其中：

$$
pack\_factor = \frac{32}{num\_bits}
$$

并且所有测试点都满足：

* `size_k % 16 == 0`
* `size_n % 64 == 0`

## 输出格式

你需要将计算结果写入 `repacked_weight` 指向的缓冲区，得到一个 shape 为 $(size_k / 16, size_n \cdot (num\_bits / 2))$ 的 `int32` 张量。

正确结果应与下面的参考计算完全一致。

首先，对输入 `b_q_weight` 做 AWQ 解包。对于每个 `int32` 元素，提取其中的 `pack_factor` 个量化值：

$$
raw[t] = \left(\text{uint32}(b\_q\_weight[r, c]) \gg (t \cdot num\_bits)\right) \mathbin{\&} \left((1 \ll num\_bits) - 1\right)
$$

提取后的顺序仍然是 AWQ 的交错顺序，需要做一次反交错：

* 当 `num_bits = 4` 时，`interleave = [0, 2, 4, 6, 1, 3, 5, 7]`
* 当 `num_bits = 8` 时，`interleave = [0, 2, 1, 3]`

令 `inv_interleave = argsort(interleave)`，则每个解包块满足：

```text
q_w_chunk = raw[inv_interleave]
```

将全部结果拼接后，得到未打包矩阵 `q_w`，shape 为 $(size_k, size_n)$。

然后按 Marlin 规则重排：

```text
q_w -> reshape(size_k / 16, 16, size_n / 16, 16)
     -> permute(0, 2, 1, 3)
     -> reshape(size_k / 16, size_n * 16)
```

接着，在每一行内部按长度 `1024` 的块应用固定置换 `perm`。`perm` 的生成规则如下：

```python
perm_list = []
for i in range(32):
    perm1 = []
    col = i // 4
    for block in [0, 1]:
        for row in [
            2 * (i % 4),
            2 * (i % 4) + 1,
            2 * (i % 4 + 4),
            2 * (i % 4 + 4) + 1,
        ]:
            perm1.append(16 * row + col + 8 * block)
    for j in range(4):
        perm_list.extend([p + 256 * j for p in perm1])

if num_bits == 4:
    interleave = [0, 2, 4, 6, 1, 3, 5, 7]
else:
    interleave = [0, 2, 1, 3]

perm = reshape(perm_list, -1, len(interleave))[:, interleave].reshape(-1)
```

最后，将重排后的每行结果按 `pack_factor` 个元素重新打包成 `int32`，得到 `repacked_weight`。

## 样例

## 输入

为便于展示，考虑一个满足最小 tile 约束的示意场景：

```text
size_k = 16
size_n = 64
num_bits = 4
pack_factor = 8
```

此时：

* `b_q_weight.shape = (16, 8)`
* `repacked_weight.shape = (1, 128)`

假设在某个位置上，解包后得到的 8 个量化值依次为：

```text
[3, 12, 5, 1, 7, 0, 9, 4]
```

## 输出

重新打包后的一个 `int32` 元素会把这 8 个 4-bit 值按低位到高位依次写入：

```text
packed =
    3 << 0  |
   12 << 4  |
    5 << 8  |
    1 << 12 |
    7 << 16 |
    0 << 20 |
    9 << 24 |
    4 << 28
```

## 计算过程说明

完整算子并不是简单逐行打包，而是先经历以下步骤：

1. 从 `b_q_weight` 中按 `num_bits` 解包出 `q_w`
2. 以 `16 x 16` tile 为单位，把 `q_w` 重排为 `(size_k // 16, size_n * 16)` 的中间布局
3. 对每个长度为 `1024` 的块应用固定 `perm`
4. 再按照 `pack_factor = 32 // num_bits` 重新打包成 `int32`

上面的 `packed` 只是第 4 步中单个输出元素的具体打包方式示例。

## PyTorch 参考实现

```python
import torch
from functools import lru_cache


def get_pack_factor(num_bits):
    return 32 // num_bits


@lru_cache(maxsize=None)
def get_weight_perm(num_bits: int):
    perm_list = []
    for i in range(32):
        perm1 = []
        col = i // 4
        for block in [0, 1]:
            for row in [
                2 * (i % 4),
                2 * (i % 4) + 1,
                2 * (i % 4 + 4),
                2 * (i % 4 + 4) + 1,
            ]:
                perm1.append(16 * row + col + 8 * block)
        for j in range(4):
            perm_list.extend([p + 256 * j for p in perm1])

    if num_bits == 4:
        interleave = torch.tensor([0, 2, 4, 6, 1, 3, 5, 7], dtype=torch.long)
    else:
        interleave = torch.tensor([0, 2, 1, 3], dtype=torch.long)

    perm = torch.tensor(perm_list, dtype=torch.long)
    return perm.view(-1, interleave.numel())[:, interleave].reshape(-1)


def awq_unpack(q_w_awq, num_bits, size_k, size_n):
    pack_factor = get_pack_factor(num_bits)
    mask = (1 << num_bits) - 1
    shifts = (torch.arange(pack_factor, device=q_w_awq.device, dtype=torch.int64) * num_bits).view(1, 1, pack_factor)
    q_w = q_w_awq.to(torch.int64).unsqueeze(-1)
    q_w = torch.bitwise_right_shift(q_w, shifts)
    q_w = torch.bitwise_and(q_w, mask).reshape(size_k, size_n)

    if num_bits == 4:
        interleave = torch.tensor([0, 2, 4, 6, 1, 3, 5, 7], device=q_w_awq.device, dtype=torch.long)
    else:
        interleave = torch.tensor([0, 2, 1, 3], device=q_w_awq.device, dtype=torch.long)

    inv_interleave = torch.argsort(interleave)
    return q_w.view(-1, interleave.numel())[:, inv_interleave].reshape(size_k, size_n).to(torch.int32)


def marlin_weights(q_w, size_k, size_n, num_bits, perm):
    q_w = q_w.reshape((size_k // 16, 16, size_n // 16, 16))
    q_w = q_w.permute((0, 2, 1, 3))
    q_w = q_w.reshape((size_k // 16, size_n * 16))
    q_w = q_w.reshape((-1, perm.numel()))[:, perm].reshape(q_w.shape)

    pack_factor = get_pack_factor(num_bits)
    shifts = (torch.arange(pack_factor, device=q_w.device, dtype=torch.int64) * num_bits).view(1, 1, pack_factor)
    q_w = q_w.to(torch.int64).view(q_w.shape[0], -1, pack_factor)
    return torch.bitwise_left_shift(q_w, shifts).sum(dim=-1).to(torch.int32)


def baseline(b_q_weight, repacked_weight, size_k, size_n, num_bits):
    q_w = awq_unpack(b_q_weight, num_bits, size_k, size_n)
    perm = get_weight_perm(num_bits).to(b_q_weight.device)
    repacked_weight.copy_(marlin_weights(q_w, size_k, size_n, num_bits, perm))
```
