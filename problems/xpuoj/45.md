## 题目描述

你需要实现一个二维转置卷积（deconvolution）前向传播算子：

> **output = conv_transpose2d(x, weight, bias, stride, padding, output_padding)**

给定输入张量 `x`、卷积核 `weight`、偏置 `bias`、步长 `stride`、填充 `padding` 和 `output_padding`，你需要计算与 PyTorch `torch.nn.functional.conv_transpose2d` 等价的结果。

本题中输入、权重、偏置和输出均为 `float32`。转置卷积按照 FP32 进行乘加累加，结果写入 `output`。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成二维转置卷积前向传播。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：float32 tensor，shape `(N, C_in, H, W)`
* `weight`：float32 tensor，shape `(C_in, C_out, R, S)`
* `bias`：float32 tensor，shape `(C_out,)`
* `output`：float32 tensor，shape `(N, C_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, H, W, R, S, stride, padding, output_padding`：int64 标量

## 输出格式

输出张量满足：

```text
H_out = (H - 1) * stride - 2 * padding + R + output_padding
W_out = (W - 1) * stride - 2 * padding + S + output_padding

output[n, c_out, h, w] =
    bias[c_out] +
    sum_{c_in, h_in, w_in, k_h, k_w}
        x[n, c_in, h_in, w_in] * weight[c_in, c_out, k_h, k_w]
```

其中只有满足以下条件的项才会对 `output[n, c_out, h, w]` 产生贡献：

```text
h = h_in * stride - padding + k_h
w = w_in * stride - padding + k_w
```

此时输出空间尺寸为：

$$
H_{out} = (2 - 1) \times 2 - 2 \times 1 + 3 + 1 = 4
$$

$$
W_{out} = (2 - 1) \times 2 - 2 \times 1 + 3 + 1 = 4
$$

## 输出

```
output.shape = (1, 1, 4, 4)
```

## 计算过程说明

对于输入中的每个元素 $x[n, c_{in}, h, w]$，它会按照卷积核位置 $(r, s)$ 写入到输出位置：

$$
h_{out} = h \times stride - padding + r
$$

$$
w_{out} = w \times stride - padding + s
$$

若输出位置落在有效范围内，则累加 $x[n, c_{in}, h, w] \cdot weight[c_{in}, c_{out}, r, s]$。最后对每个输出通道加上对应的 $bias[c_{out}]$。

## 数据范围与提示

## 数据范围

* `x`、`weight`、`bias`、`output` 的数据类型均为 `torch.float32`
* `x` 的 shape 为 $(N, C_{in}, H, W)$
* `weight` 的 shape 为 $(C_{in}, C_{out}, R, S)$
* `bias` 的 shape 为 $(C_{out},)$
* `output` 的 shape 为 $(N, C_{out}, H_{out}, W_{out})$
* 所有 tensor 均为连续存储（contiguous）
* $8 \le N \le 16$
* $16 \le C_{in} \le 80$
* $16 \le C_{out} \le 96$
* $80 \le H \le 144$
* $80 \le W \le 128$
* $1 \le R,S \le 5$
* $stride \in \{1, 2, 3\}$
* $0 \le padding \le 2$
* $0 \le output\_padding < stride$

## 正确性要求

* 必须正确计算 $H_{out}$ 和 $W_{out}$
* 必须正确处理 `stride`、`padding` 和 `output_padding`
* 必须正确累加全部输入通道和卷积核空间维度
* 必须正确加上 `bias`
* 必须将结果写入 `output`
* 不允许修改 `x`、`weight` 和 `bias`

## 提示

* 注意 `weight` 的 shape 是 $(C_{in}, C_{out}, R, S)$，不同于普通 `conv2d` 中常见的 $(C_{out}, C_{in}, R, S)$
* `output_padding` 只影响输出形状，不会改变单个输入元素映射到输出位置的公式
