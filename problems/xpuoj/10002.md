# DeepSeek MLA Decode

XPUOJ · #10002

[打开实现文件](../../practice/xpuoj/10002/solution.py) · [原始材料](../../references/XPUOJ/problem_10002/zh_CN/00_%E9%A2%98%E7%9B%AE%E6%8F%8F%E8%BF%B0.md)

## 题目描述

你需要实现 DeepSeek V3/R1 解码阶段使用的 Multi-Head Latent Attention 变体。

本题固定：

* query/key 的非 RoPE 维度 `dim = 512`
* RoPE 维度 `pe_dim = 64`
* QK 总维度为 `576`
* V/O 维度为 `512`
* `kv_heads = 1`，所有 query heads 共享同一组 latent KV

给定 `q`、`q_pe`、`kv`、`k_pe`，需要计算：

```text
score = (q @ kv^T + q_pe @ k_pe^T) / sqrt(576)
attention = softmax(score, dim=-1)
output = attention @ kv
```

评测程序会调用你提交代码中的 `run_kernel` 函数。你需要在函数内部完成 attention 计算，并将结果写入 `output`。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

你必须在提交的 Python 代码中提供 `run_kernel` 函数，函数名、参数顺序、类型必须完全一致：

```python
def run_kernel(
    q,        # Tensor[float16], shape (batch, heads, dim)
    q_pe,     # Tensor[float16], shape (batch, heads, pe_dim)
    kv,       # Tensor[float16], shape (batch, kv_ctx, kv_heads, dim)
    k_pe,     # Tensor[float16], shape (batch, kv_ctx, kv_heads, pe_dim)
    output,   # Tensor[float16], shape (batch, heads, dim)
    batch,    # int64
    heads,    # int64
    kv_heads, # int64
    kv_ctx,   # int64
    dim,      # int64, fixed to 512
    pe_dim,   # int64, fixed to 64
):
    ...
```

### 参数说明

* `q`：非 RoPE query，shape `(batch, heads, 512)`
* `q_pe`：RoPE query，shape `(batch, heads, 64)`
* `kv`：latent key/value cache，shape `(batch, kv_ctx, kv_heads, 512)`
* `k_pe`：RoPE key cache，shape `(batch, kv_ctx, kv_heads, 64)`
* `output`：输出缓冲区，shape `(batch, heads, 512)`

`run_kernel` 内部应自行计算 launch 配置，并调用 TileLang kernel 或等价 GPU tensor 算子完成计算。

## 输入格式

本题输入由评测程序在 GPU 上构造，并按接口约定中的顺序传入 `run_kernel`。

评测覆盖不同 `batch` 与 `kv_ctx`。所有张量均为连续 `float16` CUDA tensor。

## 输出格式

输出写入 `output`，shape 为 `(batch, heads, 512)`，类型为 `float16`。

## 样例

当 `batch = 1`、`heads = 16`、`kv_ctx = 2048` 时：

* `q` 的 shape 为 `(1, 16, 512)`
* `q_pe` 的 shape 为 `(1, 16, 64)`
* `kv` 的 shape 为 `(1, 2048, 1, 512)`
* `k_pe` 的 shape 为 `(1, 2048, 1, 64)`
* `output` 的 shape 为 `(1, 16, 512)`

每个 head 都需要对完整 `kv_ctx` 做 softmax attention。

## 数据范围与提示

测试点覆盖：

* `batch`：1、2、4、8、16、32
* `heads`：16
* `kv_heads`：1
* `kv_ctx`：2048 到 65536
* `dim`：512
* `pe_dim`：64

注意：

* QK 总维度为 `dim + pe_dim = 576`。
* softmax scale 为 `1 / sqrt(576)`。
* 输出参与 `torch.allclose` 校验，容差为 `rtol=2e-3, atol=2e-3`。
* 大上下文测试点显存占用较高，评测配置已经降低 warmup/iters。
