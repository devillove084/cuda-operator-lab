# Flash Rotary Embedding Module

## 题目描述

你需要实现带 `seqlen_offset` 的 Rotary Position Embedding (RoPE) 算子。

输入 `q` 和 `k` 的 shape 分别为：

$$
q \in \mathbb{R}^{B \times S \times H \times D}, \quad
k \in \mathbb{R}^{B \times S \times H \times D}
$$

评测程序会传入 `cos_cache`、`sin_cache` 以及标量 `seqlen_offset`。与普通 RoPE 不同，本题第 `t` 个 token 使用缓存中的位置 `seqlen_offset + t`：

$$
cos_t = cos\_cache[seqlen\_offset + t], \quad
sin_t = sin\_cache[seqlen\_offset + t]
$$

定义：

$$
rotate\_half(x) = [-x_{D/2:D}, x_{0:D/2}]
$$

则输出满足：

$$
q\_out[:, t, :, :] = q[:, t, :, :] \cdot cos_t + rotate\_half(q[:, t, :, :]) \cdot sin_t
$$

$$
k\_out[:, t, :, :] = k[:, t, :, :] \cdot cos_t + rotate\_half(k[:, t, :, :]) \cdot sin_t
$$

你需要把结果分别写入 `q_out` 和 `k_out`，不得修改只读输入。如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 参数说明

* `q_ptr`：输入 query 指针（bfloat16），shape $(\text{batch_size}, \text{seq_len}, \text{num_heads}, \text{head_dim})$，行优先连续存储，只读
* `k_ptr`：输入 key 指针（bfloat16），shape $(\text{batch_size}, \text{seq_len}, \text{num_kv_heads}, \text{head_dim})$，行优先连续存储，只读
* `cos_cache_ptr`：cos 缓存指针（bfloat16），shape $(\text{max_seq_len}, \text{head_dim})$，行优先连续存储，只读
* `sin_cache_ptr`：sin 缓存指针（bfloat16），shape $(\text{max_seq_len}, \text{head_dim})$，行优先连续存储，只读
* `q_out_ptr`：输出 query 指针（bfloat16），shape $(\text{batch_size}, \text{seq_len}, \text{num_heads}, \text{head_dim})$，行优先连续存储，需写入计算结果
* `k_out_ptr`：输出 key 指针（bfloat16），shape $(\text{batch_size}, \text{seq_len}, \text{num_kv_heads}, \text{head_dim})$，行优先连续存储，需写入计算结果
* `batch_size`：batch 大小（int64）
* `seq_len`：序列长度（int64）
* `num_heads`：query 注意力头数（int64）
* `num_kv_heads`：key 注意力头数（int64）
* `head_dim`：每个头的维度（int64），必须是偶数
* `seqlen_offset`：序列起始偏移量（int64），位置编码从该偏移位置开始计算

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成带偏移的旋转位置编码计算

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 rotary embedding 计算

    Args:
        q: BF16 tensor of shape (batch_size, seq_len, num_q_heads, head_dim) - query
        k: BF16 tensor of shape (batch_size, seq_len, num_k_heads, head_dim) - key
        cos_cache: BF16 tensor of shape (max_seq_len, head_dim) - cosine cache
        sin_cache: BF16 tensor of shape (max_seq_len, head_dim) - sine cache
        q_out: BF16 tensor of shape (batch_size, seq_len, num_q_heads, head_dim) - query output (will be modified inplace)
        k_out: BF16 tensor of shape (batch_size, seq_len, num_k_heads, head_dim) - key output (will be modified inplace)
        batch_size: int - batch size
        seq_len: int - sequence length
        num_q_heads: int - number of query heads
        num_k_heads: int - number of key heads
        head_dim: int - head dimension
        seqlen_offset: int - sequence length offset

    Returns:
        List containing modified q_out and k_out tensors
    """
    q, k, cos_cache, sin_cache, q_out, k_out, batch_size, seq_len, num_q_heads, num_k_heads, head_dim, seqlen_offset = inputs

    assert torch.is_tensor(q) and torch.is_tensor(k) and torch.is_tensor(cos_cache) and torch.is_tensor(sin_cache) and torch.is_tensor(q_out) and torch.is_tensor(k_out)
    assert isinstance(batch_size, int) and isinstance(seq_len, int) and isinstance(num_q_heads, int) and isinstance(num_k_heads, int) and isinstance(head_dim, int) and isinstance(seqlen_offset, int)
    assert q.shape == (batch_size, seq_len, num_q_heads, head_dim)
    assert k.shape == (batch_size, seq_len, num_k_heads, head_dim)
    assert cos_cache.shape[1] == head_dim and sin_cache.shape[1] == head_dim
    assert q_out.shape == q.shape
    assert k_out.shape == k.shape

    cos = cos_cache[seqlen_offset:seqlen_offset + seq_len].to(q.dtype)
    sin = sin_cache[seqlen_offset:seqlen_offset + seq_len].to(q.dtype)

    cos = cos.unsqueeze(0).unsqueeze(2)
    sin = sin.unsqueeze(0).unsqueeze(2)

    def rotate_half(x):
        x1 = x[..., :x.shape[-1] // 2]
        x2 = x[..., x.shape[-1] // 2:]
        return torch.cat((-x2, x1), dim=-1)

    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)

    q_out.copy_(q_embed)
    k_out.copy_(k_embed)

    return list(inputs)```
