## 题目描述

你需要实现带预加项的 GEMM。给定矩阵 $A$、矩阵 $B$ 和一个与输出同 shape 的预加项 `PreAct`，你需要先完成矩阵乘法 $AB^T$，再把结果与 `PreAct` 逐元素相加，并把最终结果写回 `PostAct`。

具体来说，输入满足：

$$
A \in \mathbb{R}^{M \times K}, \quad
B \in \mathbb{R}^{N \times K}, \quad
\text{PreAct} \in \mathbb{R}^{M \times N}
$$

其中 $M$ 是输出矩阵的行数，$N$ 是输出矩阵的列数，$K$ 是归约维度。由于 `B` 的 shape 是 $(N, K)$，因此本题实际参与计算的是它的转置 $B^T \in \mathbb{R}^{K \times N}$。

首先计算矩阵乘法：

$$
C = AB^T \in \mathbb{R}^{M \times N}
$$

按元素展开后，对任意 $0 \le i < M$、$0 \le j < N$，有：

$$
C_{i,j} = \sum_{t=0}^{K-1} A_{i,t} B_{j,t}
$$

然后把 `PreAct` 逐元素加到乘法结果上：

$$
\text{PostAct}_{i,j} = C_{i,j} + \text{PreAct}_{i,j}
$$

也就是：

$$
\text{PostAct}_{i,j} = \sum_{t=0}^{K-1} A_{i,t} B_{j,t} + \text{PreAct}_{i,j}
$$

从整体矩阵角度看，最终输出满足：

$$
\text{PostAct} = AB^T + \text{PreAct}
$$

本题虽然目录名里带有 `act`，但按照 `baseline()` 的真实语义，这里并没有额外激活函数；评测只关心最终写回的线性结果，也就是 GEMM 与逐元素加法融合后的输出。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    A, B, PreAct, postact_out, M, K, N = inputs

    assert torch.is_tensor(A) and torch.is_tensor(B) and torch.is_tensor(PreAct)
    assert A.shape == (M, K)
    assert B.shape == (N, K)
    assert PreAct.shape == (M, N)

    preact = A @ B.t() + PreAct
    postact = preact

    if postact_out is not None and torch.is_tensor(postact_out):
        postact_out.copy_(postact)

    return [A, B, PreAct, postact_out, M, K, N]
```
