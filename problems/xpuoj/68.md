## 题目描述

你需要实现一个单精度的对称 rank-k 更新算子：

> **output = alpha * (A @ A.T) + beta * C**

给定输入矩阵 `A` 和 `C`，其中：

* `A` 的 shape 为 `(N, K)`
* `C` 的 shape 为 `(N, N)`
* `output` 的 shape 为 `(N, N)`

具体计算方式为：

$$
output_{i,j} = \alpha \cdot \sum_{t=0}^{K-1} A_{i,t} \cdot A_{j,t} + \beta \cdot C_{i,j}
$$

其中 $i, j \in [0, N)$。

本题对应 BLAS 中的 `syrk`（Symmetric Rank-K Update）计算形式。虽然 `A @ A.T` 本身是对称矩阵，但评测只关心最终完整输出矩阵是否正确，参考语义可以直接理解为：

$$
output = \alpha \cdot (A @ A^T) + \beta \cdot C
$$

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const float* A,
    const float* C,
    float* output,
    float alpha,
    float beta,
    int64_t N,
    int64_t K
);
```

### 参数说明

* `A`：输入指针（float32），shape `(N, K)`，行优先连续存储，只读

* 根据矩阵尺寸计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 `output = alpha * (A @ A.T) + beta * C`

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，得到一个 shape 为 `(N, N)` 的 float32 矩阵，满足：

$$
output_{i,j} = \alpha \cdot \sum_{t=0}^{K-1} A_{i,t} \cdot A_{j,t} + \beta \cdot C_{i,j}
$$

即：

$$
output = \alpha \cdot (A @ A^T) + \beta \cdot C
$$

## 样例

## 输入

```text
N = 4
K = 3
alpha = 1.5
beta = -0.5
```

此时：

```text
A.shape = (4, 3)
C.shape = (4, 4)
output.shape = (4, 4)
```

## 输出

```text
output = 1.5 * (A @ A.T) - 0.5 * C
```

## 数据范围与提示

## 数据范围

* `A`、`C`、`output` 的数据类型均为 `torch.float32`
* `A` 的 shape 为 `(N, K)`
* `C`、`output` 的 shape 为 `(N, N)`
* 所有矩阵均为连续存储（contiguous）
* 评测中 `N` 最大可达 `12288`
* 评测中 `K` 最大可达 `5120`

## 提示

* `A @ A.T` 的结果是 shape `(N, N)`，而 `A.T @ A` 的结果是 shape `(K, K)`，两者不是同一个运算
* 当 `beta = 0` 时，`C` 仍会传入，但结果中不应包含它的贡献
* 虽然算子名中包含 `tf32`，但评测输入输出类型是 `float32`，参考实现按 `float32` 语义理解即可
* 评测使用 `alpha * torch.matmul(A, A.T) + beta * C` 作为参考实现

## PyTorch 参考实现

```python
def baseline(A, C, output, alpha, beta, N, K):
    """
    PyTorch 参考实现：output = alpha * (A @ A.T) + beta * C

    参数说明：
    * A: 输入张量（float32），shape (N, K)
    * C: 输入张量（float32），shape (N, N)
    * output: 输出张量（float32），shape (N, N)
    * alpha: float 标量
    * beta: float 标量
    * N: 输出矩阵维度（int64）
    * K: 约简维度（int64）
    """
    output.copy_(alpha * torch.matmul(A, A.transpose(0, 1)) + beta * C)
```
