## 题目描述

你需要实现一个 bfloat16 精度的批量外积算子，对应 einsum 表达式：

> **out = torch.einsum('bi,bj->bij', a, b)**

给定输入张量 `a`（shape 为 $(B, I)$）和 `b`（shape 为 $(B, J)$），对每个 batch 独立计算两个向量的外积，得到输出张量 `out`（shape 为 $(B, I, J)$）。具体计算方式为：

$$
out_{batch,i,j} = a_{batch,i} \cdot b_{batch,j}
$$

其中 $batch \in [0, B)$，$i \in [0, I)$，$j \in [0, J)$，$\cdot$ 表示乘法。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述批量外积计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* a,
    const __nv_bfloat16* b,
    __nv_bfloat16* out,
    int64_t B,
    int64_t I,
    int64_t J
);
```

### 参数说明

* `a`：输入指针（bfloat16），shape $(B, I)$，连续存储，只读
* `b`：输入指针（bfloat16），shape $(B, J)$，连续存储，只读
* `out`：输出指针（bfloat16），shape $(B, I, J)$，连续存储，需写入计算结果
* `B`：batch 数量（int64）
* `I`：`a` 的第 2 维，也是 `out` 的第 2 维（int64）
* `J`：`b` 的第 2 维，也是 `out` 的第 3 维（int64）

`run_kernel` 内部需要完成以下工作：

* 根据张量尺寸计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 `bi,bj->bij` 的计算

## 计算过程说明

对每个 batch 独立执行向量外积：

```text
out[batch] = a[batch].view(I, 1) * b[batch].view(1, J)
```

## 数据范围与提示

## 数据范围

* `a`、`b`、`out` 的数据类型均为 `torch.bfloat16`
* `a` 的 shape 为 $(B, I)$
* `b` 的 shape 为 $(B, J)$
* `out` 的 shape 为 $(B, I, J)$
* 所有 tensor 均为连续存储（contiguous）
* $1 \le B \le 16$
* $1 \le I \le 12288$
* $1 \le J \le 12289$

## 正确性要求

* 必须对每个 batch 独立计算外积
* 必须将最终结果写入 `out`
* 不允许修改 `a` 和 `b`

## 提示

* `a` 的布局是 $(B, I)$，`b` 的布局是 $(B, J)$
* 每个 batch 的计算互相独立
* 本题等价于 `torch.einsum('bi,bj->bij', a, b)`

## PyTorch 参考实现

```python
def baseline(a, b, out, B, I, J):
    chunk_i = max(1, min(I, 512))
    b_f = b.float()
    for start in range(0, I, chunk_i):
        end = min(start + chunk_i, I)
        y = a[:, start:end].float().view(B, end - start, 1) * b_f.view(B, 1, J)
        out[:, start:end, :].copy_(y.to(torch.bfloat16))
        del y
```
