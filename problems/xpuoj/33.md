## 题目描述

你需要实现一个带 broadcast 残差加法的二维卷积前向传播算子：

> **output = conv2d(x, weight, bias, stride, padding) + broadcast**

其中 `broadcast` 与卷积输出形状相同，若存在则逐元素相加；若不存在则仅返回卷积结果。

为了适配 OJ，本题固定要求传入 `broadcast`，并始终执行加法。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成二维卷积前向传播与 broadcast 加法。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：bfloat16 tensor，shape `(N, C_in, H, W)`
* `weight`：bfloat16 tensor，shape `(C_out, C_in, R, S)`
* `bias`：bfloat16 tensor，shape `(C_out,)`
* `broadcast`：bfloat16 tensor，shape `(N, C_out, H_out, W_out)`
* `output`：bfloat16 tensor，shape `(N, C_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, H, W, R, S, stride, padding`：int64 标量

## 输出格式

你需要将计算结果写入 `output`，满足：

```text
H_out = floor((H + 2 * padding - R) / stride + 1)
W_out = floor((W + 2 * padding - S) / stride + 1)

temp = conv2d(x, weight, bias, stride, padding)
output = temp + broadcast
```

## 样例

## 输入

```text
N = 1
C_in = 1
C_out = 1
H = W = 3
R = S = 3
stride = 1
padding = 0
```

此时：

```text
H_out = (3 + 0 - 3) / 1 + 1 = 1
W_out = (3 + 0 - 3) / 1 + 1 = 1
```

所以：

```text
temp.shape = (1, 1, 1, 1)
output.shape = (1, 1, 1, 1)
```

卷积先生成一个 `(1, 1, 1, 1)` 的中间结果，然后再与同形状的 `broadcast` 逐元素相加，得到最终输出。

## 数据范围与提示

## 数据范围

* `x.dtype == torch.bfloat16`
* `weight.dtype == torch.bfloat16`
* `bias.dtype == torch.bfloat16`
* `broadcast.dtype == torch.bfloat16`
* `output.dtype == torch.bfloat16`

## 正确性要求

* 必须正确处理 `stride`
* 必须正确处理 `padding`
* 必须正确累加全部输入通道与卷积核空间维度
* 必须正确加上 `bias`
* 必须正确执行与 `broadcast` 的逐元素加法
* 必须将结果写入 `output`

## 提示

* 可以先计算卷积结果，再单独完成与 `broadcast` 的逐元素相加
* `broadcast` 的形状会与卷积输出严格一致，无需额外做 shape 推导
* 若你先在更高精度中累加，最终写回时要保持输出类型为 `bfloat16`

## PyTorch 参考实现

```python
def baseline(x, weight, bias, broadcast, output, N, C_in, C_out, H, W, R, S, stride, padding):
    temp = torch.nn.functional.conv2d(x, weight, bias, stride, padding)
    output.copy_(temp + broadcast)
```
