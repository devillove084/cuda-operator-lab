# M Grouped Fp8 Gemm Nt Masked

XPUOJ · #14

[打开实现文件](../../practice/xpuoj/14/solution.cu) · [原始材料](../../references/XPUOJ-public/14.md)

原题 https://xpuoj.com/p/14

## 题目描述

你需要实现一个 M-grouped FP8 GEMM NT（带掩码 M 维度）算子。该算子执行分组 FP8 矩阵乘法，其中每个组有独立的实际处理行数（由 `masked_m` 指定），未使用的行输出为零。A、B 使用 FP8E4M3 存储，按 128 为块配备 FP32 scale 反量化后参与计算。

**NT 布局**表示：
* `a_data` 形状为 $(num\_groups, max\_m, k)$，搭配 `a_sf` 形状为 $(num\_groups, max\_m, \lceil K/128 \rceil)$（per-token 缩放）
* `b_data` 形状为 $(num\_groups, n, k)$，搭配 `b_sf` 形状为 $(num\_groups, \lceil N/128 \rceil, \lceil K/128 \rceil)$（per-block 缩放），计算时视为转置参与矩阵乘法

**掩码逻辑**：
* `masked_m[g]` 指示组 $g$ 实际处理的行数
* 对于组 $g$，只处理前 $masked\_m[g]$ 行：先按 scale 反量化后计算 $d[g, :masked\_m[g], :] = a\_fp32[g, :masked\_m[g], :] \times b\_fp32[g]^T$
* $d[g, masked\_m[g]:, :] = 0$

**反量化约定**（与 DeepGEMM 一致）：
* A：$a\_sf[g, i, k\_block]$ 对应 $a\_data[g, i, k]$ 在 $k\_block = \lfloor k/128 \rfloor$ 的 scale，$\text{value_fp32} = \text{value_fp8} \times \text{scale}$
* B：$b\_sf[g, n\_block, k\_block]$ 对应 $b\_data[g, n, k]$ 在对应 128×128 块的 scale

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输出格式

你需要将计算结果写入 $d$ 指向的缓冲区，得到一个 shape 为 $(\text{num_groups}, \text{max_m}, n)$ 的 bfloat16 张量。

定义块大小 $B = 128$。对组 $g$、行 $i$、列 $j$：

* 若 $i < \text{masked_m}[g]$：

$$
d_{g,i,j} = \sum_{t=0}^{k-1} \bigl(a^{(g)}_{i,t} \cdot a^{\text{sf},(g)}_{i, \lfloor t/B \rfloor}\bigr) \cdot \bigl(b^{(g)}_{j,t} \cdot b^{\text{sf},(g)}_{\lfloor j/B \rfloor, \lfloor t/B \rfloor}\bigr)
$$

以 FP32 计算后四舍五入到 BF16 写入。这里 $a^{(g)}$ 表示第 $g$ 组的 $a_\text{data}$，$a^{\text{sf},(g)}$ 表示第 $g$ 组的 $a_\text{sf}$，$b^{(g)}$ 表示第 $g$ 组的 $b_\text{data}$，$b^{\text{sf},(g)}$ 表示第 $g$ 组的 $b_\text{sf}$。

* 若 $i \ge \text{masked_m}[g]$：

$$
d_{g,i,j} = 0, \quad \forall j \in [0, n)
$$

## 输出

`d`（bfloat16，shape $(2, 3, 2)$）：

输出结果为一个形状为 $(2, 3, 2)$ 的 bfloat16 张量，其中：

具体数值省略。

## 计算过程说明

由于所有 scale 因子均为 1.0，反量化后的值与原值相同。

**组 0**（$masked\_m[0] = 2$，只算前 2 行）：

* 行 0 和行 1：执行矩阵乘法 $d[0, i, :] = a[0, i, :] \times B[0]^T$，其中 $B[0]$ 为组 0 的 B 矩阵（形状 $2 \times 3$）
* 行 2：由于 $i = 2 \ge masked\_m[0] = 2$，该行被掩码置零

**组 1**（$masked\_m[1] = 3$，三行都算）：

* 行 0、行 1、行 2：分别执行矩阵乘法 $d[1, i, :] = a[1, i, :] \times B[1]^T$，其中 $B[1]$ 为组 1 的 B 矩阵（形状 $2 \times 3$）

**计算逻辑总结**：

1. 对每个组 $g$，根据 `masked_m[g]` 确定实际计算的行数
2. 对于实际计算的行，执行：$d[g, i, :] = a[g, i, :] \times B[g]^T$
3. 对于被掩码的行（$i \ge masked\_m[g]$），输出为零

## PyTorch 参考实现

```python
BLOCK_SIZE = 128

def _expand_a_sf(a_sf, k):
    """将 a_sf [..., k_blocks] 沿最后一维扩展到 k。"""
    ex = a_sf.repeat_interleave(BLOCK_SIZE, dim=-1)
    if ex.shape[-1] >= k:
        return ex[..., :k].contiguous()
    return torch.cat([ex, ex[..., -1:].expand(*ex.shape[:-1], k - ex.shape[-1])], dim=-1)

def baseline(a_data, a_sf, b_data, b_sf, masked_m, d, num_groups, max_m, n, k):
    """
    PyTorch 参考实现：M-grouped FP8 GEMM NT masked

    参数说明：
    * a_data: 输入张量（FP8E4M3），shape (num_groups, max_m, k)，行优先连续存储，只读
    * a_sf: 输入张量（float32），shape (num_groups, max_m, ceil(K/128))，per-token 缩放因子，只读
    * b_data: 输入张量（FP8E4M3），shape (num_groups, n, k)，每个组的 FP8 权重矩阵，只读
    * b_sf: 输入张量（float32），shape (num_groups, ceil(N/128), ceil(K/128))，per-block 缩放因子，只读
    * masked_m: 输入张量（int32），shape (num_groups,)，每个组的实际处理行数，只读
    * d: 输出张量（bfloat16），shape (num_groups, max_m, n)，行优先连续存储，需写入结果
    * num_groups: 分组数量（int64）
    * max_m: 每个组的最大行数（int64）
    * n: b 的第二维大小，d 的第三维大小（int64）
    * k: a 和 b 的最后一维大小（int64）
    """
    # a 反量化
    a_sf_exp = _expand_a_sf(a_sf, k)  # (num_groups, max_m, k)
    a_fp32 = a_data.float() * a_sf_exp

    # b 反量化
    b_sf_exp = b_sf.repeat_interleave(BLOCK_SIZE, dim=1).repeat_interleave(BLOCK_SIZE, dim=2)
    b_sf_exp = b_sf_exp[:, :n, :k]
    b_fp32 = b_data.float() * b_sf_exp

    d.zero_()

    # res = a @ b.T
    res = torch.matmul(a_fp32, b_fp32.transpose(1, 2))

    # Masking
    m_indices = torch.arange(max_m, device=a_data.device).unsqueeze(0)  # (1, M)
    mask = m_indices < masked_m.unsqueeze(1)  # (G, M)

    res = res * mask.unsqueeze(2).float()
    d.copy_(res.to(torch.bfloat16))
```
