## 题目描述

你需要实现一个 Hopper 风格的 INT4-FP8 grouped GEMM 算子：

> **output[g] = matmul(float(a[g]), float(b[g]))**

原始算子的数学语义是对一组 `(a, b)` 矩阵对分别做矩阵乘法。本题为了适配 OJ，采用固定 batch 维度的简化接口：

* `a` 的形状为 `(G, M, K)`，类型为 `int8`
* `b` 的形状为 `(G, K, N)`，类型为 `FP8 E4M3`
* `output` 的形状为 `(G, M, N)`，类型为 `float32`

其中 `a` 的取值范围会限制在 `[-8, 7]`，用来模拟 INT4 数值范围。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 grouped GEMM 的计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_fp8.h>

extern "C" void run_kernel(
    const int8_t* a,
    const __nv_fp8_e4m3* b,
    float* output,
    int64_t G,
    int64_t M,
    int64_t N,
    int64_t K
);
```

### 参数说明

* `a`：输入指针，shape `(G, M, K)`，类型为 int8，数值范围位于 `[-8, 7]`
* `b`：输入指针，shape `(G, K, N)`，类型为 FP8 E4M3
* `output`：输出指针，shape `(G, M, N)`，类型为 float32
* `G`：group 数量
* `M`、`N`、`K`：矩阵乘法尺寸

`run_kernel` 内部需要完成以下工作：

* 根据张量尺寸计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成每个 group 的 GEMM 计算

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `a`：int8 tensor，shape `(G, M, K)`
* `b`：FP8 E4M3 tensor，shape `(G, K, N)`
* `output`：float32 tensor，shape `(G, M, N)`，作为输出缓冲区
* `G`、`M`、`N`、`K`：int64 标量

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，满足：

```text
output[g, i, j] = sum_k(float(a[g, i, k]) * float(b[g, k, j]))
```

def baseline(a, b, output, G, M, N, K):
