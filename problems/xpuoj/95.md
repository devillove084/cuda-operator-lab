# Index Mul 2d

原题 https://xpuoj.com/p/95

## 题目描述

你需要实现一个 2D Index Multiply 算子：

> **out = in1[idx1] * in2**

给定输入矩阵 `in1`（shape 为 `(M, N)`）、输入矩阵 `in2`（shape 为 `(K, N)`）和一维索引张量 `idx1`（shape 为 `(K,)`），你需要先按照 `idx1` 从 `in1` 的第 0 维取出 `K` 行，得到一个形状为 `(K, N)` 的中间结果，再与 `in2` 做逐元素乘法，得到输出矩阵 `out`（shape 为 `(K, N)`）。

对于每个位置 `(k, j)`，输出满足：

$$
out_{k,j} = in1_{idx1[k], j} \cdot in2_{k,j}
$$

其中 `k \in [0, K)`，`j \in [0, N)`。如果 `idx1` 中存在重复值，则 `in1` 中对应的行会被重复取出并分别参与乘法。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

## 样例

## 输入

```text
M = 4
K = 3
N = 2

in1 =
[
  [1, 2],
  [3, 4],
  [5, 6],
  [7, 8]
]

in2 =
[
  [10, 20],
  [30, 40],
  [50, 60]
]

idx1 = [2, 0, 2]
```

## 输出

```text
out =
[
  [50, 120],
  [30, 80],
  [250, 360]
]
```

## 计算过程说明

先按 `idx1` 从 `in1` 中取行：

* `idx1[0] = 2`，因此取到 `in1[2] = [5, 6]`
* `idx1[1] = 0`，因此取到 `in1[0] = [1, 2]`
* `idx1[2] = 2`，因此再次取到 `in1[2] = [5, 6]`

于是中间结果为：

```text
[
  [5, 6],
  [1, 2],
  [5, 6]
]
```

再与 `in2` 逐元素相乘：

* 第 `0` 行：`[5, 6] * [10, 20] = [50, 120]`
* 第 `1` 行：`[1, 2] * [30, 40] = [30, 80]`
* 第 `2` 行：`[5, 6] * [50, 60] = [250, 360]`

因此得到最终输出：

```text
[
  [50, 120],
  [30, 80],
  [250, 360]
]
```

## 数据范围

* `in1.dtype == torch.float32`
* `in2.dtype == torch.float32`
* `idx1.dtype == torch.int32`
* `out.dtype == torch.float32`
* `in1.shape == (M, N)`
* `in2.shape == (K, N)`
* `idx1.shape == (K,)`
* `out.shape == (K, N)`
* 对所有 `k`，都有 `0 <= idx1[k] < M`

## 正确性要求

* 必须严格按 `idx1` 从 `in1` 中取行
* 必须与 `in2` 做逐元素乘法
* `idx1` 中存在重复值时，必须保留这些重复取行的语义
* 不允许修改输入张量 `in1`、`in2` 和 `idx1`
