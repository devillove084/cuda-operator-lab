## 题目描述

你需要提交一份代码，实现一个融合的 BF16 GeLU Tanh 和乘法算子：

> **out[batch, h] = gelu_tanh(input[batch, h]) × input[batch, h + hidden_size]**

其中：
- 输入 `input` 的形状为 `(batch_size, 2×hidden_size)`，BF16 类型
- GeLU 函数使用 tanh 近似：
  - gelu(x) = 0.5 × x × (1 + tanh(√(2/π) × (x + 0.044715 × x³)))
- 输出 `out` 的形状为 `(batch_size, hidden_size)`，BF16 类型

评测程序会将你的源码编译为 **动态链接库（.so）**，并在 GPU 上通过 FFI 调用你导出的函数：
- `run_kernel`：由你在函数内部计算合适的 grid/block 并 launch kernel

## 接口约定

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(const __nv_bfloat16* input, __nv_bfloat16* out, int64_t batch_size, int64_t hidden_size);
```

## 输入格式

本题的"输入"由评测程序在 GPU 上构造并传入 `run_kernel`。

评测会生成以下参数并按顺序传入 `run_kernel`：
1. `input`：BF16 CUDA tensor（连续存储），形状为 `(batch_size, 2×hidden_size)`
2. `out`：BF16 CUDA tensor（连续存储），形状为 `(batch_size, hidden_size)`，初始值会被覆盖
3. `batch_size`：int64 标量，第一维大小
4. `hidden_size`：int64 标量，第二维大小的一半

## 输出格式

一个 BF16 CUDA tensor `out`，形状为 `(batch_size, hidden_size)`，满足

```
out[batch, h] = gelu_tanh(input[batch, h]) × input[batch, h + hidden_size]
```

其中 GeLU 函数使用 tanh 近似定义：

```
cdf = 0.5 × (1.0 + tanh(√(2/π) × (x + 0.044715 × x³)))
gelu_tanh(x) = x × cdf
```

## 数据范围与提示

### 数据范围
- `input` 与 `out` 为 `torch.bfloat16`（BF16）
- `input.shape == (batch_size, 2×hidden_size)`
- `out.shape == (batch_size, hidden_size)`
- `input`、`out` 为连续存储（contiguous）
- `batch_size >= 1`，`hidden_size >= 1`

### 正确性要求
- **必须正确实现融合 GeLU Tanh 和乘法**：out[batch, h] = gelu_tanh(input[batch, h]) × input[batch, h + hidden_size]
- GeLU 函数必须使用 tanh 近似
- 允许使用任意并行策略，但必须覆盖全部输出元素
- 数值精度要求：使用 `torch.allclose` 进行验证，`rtol=1e-2`，`atol=1e-2`（BF16 精度限制）
