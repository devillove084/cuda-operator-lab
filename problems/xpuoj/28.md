## 题目描述

你需要实现一个 Hopper 风格的 GETT（Generalized Tensor-Tensor Contraction）算子。

GETT 可以理解为一种比普通矩阵乘法更一般的张量收缩运算。给定两个多维张量 `a` 和 `b`，你需要按照指定的维度匹配关系，对某个约简维度做乘加，并生成输出张量 `output`。这类运算通常可以用 Einstein Summation，也就是 `einsum` 表达式来描述。

原始算子支持任意 Einstein Summation 表达式，例如：

```text
einsum('...,...->...', a, b)
```

但为了适配 OJ，本题不要求你实现任意字符串解析，也不开放完全自由的张量表达式，而是固定支持以下 `3` 个常见的 GETT pattern，并通过 `pattern_id` 进行选择：

```text
pattern_id = 1: output = einsum('bmk,bkn->bmn', a, b)
pattern_id = 2: output = einsum('bkm,bkn->bmn', a, b)
pattern_id = 3: output = einsum('bmk,bnk->bmn', a, b)
```

从计算形式上看：

* `pattern_id = 1` 为最常见的 batch GEMM
* `pattern_id = 2` 可以看成左输入做了转置语义变化后的 GETT
* `pattern_id = 3` 可以看成右输入做了转置语义变化后的 GETT


本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据 `pattern_id` 完成对应的张量收缩计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* a,
    const __nv_bfloat16* b,
    __nv_bfloat16* output,
    int64_t pattern_id,
    int64_t B,
    int64_t M,
    int64_t N,
    int64_t K
);
```

### 参数说明

* `a`：输入指针，shape 由 `pattern_id` 决定，类型为 bfloat16
* `b`：输入指针，shape 由 `pattern_id` 决定，类型为 bfloat16
* `output`：输出指针，shape 固定为 `(B, M, N)`，类型为 bfloat16
* `pattern_id`：模式编号，仅允许取 `1`、`2`、`3`
* `B`、`M`、`N`、`K`：张量收缩尺寸

不同 `pattern_id` 下的张量形状如下：

```text
pattern_id = 1:
  a.shape = (B, M, K)
  b.shape = (B, K, N)
  output.shape = (B, M, N)

pattern_id = 2:
  a.shape = (B, K, M)
  b.shape = (B, K, N)
  output.shape = (B, M, N)

pattern_id = 3:
  a.shape = (B, M, K)
  b.shape = (B, N, K)
  output.shape = (B, M, N)
```

`run_kernel` 内部需要完成以下工作：

* 根据 `pattern_id` 选择正确的索引方式
* 根据张量尺寸计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成对应的张量收缩
