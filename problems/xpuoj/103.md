## 题目描述

你需要实现一个二维张量的 `L2 normalization` 算子。

给定输入矩阵 `input`，其 shape 为 `(M, N)`，类型为 `float32`。你需要沿第 `0` 维对每一列分别做 L2 归一化，得到输出矩阵 `output`，其 shape 与输入相同，也为 `(M, N)`。

对任意列下标 `j`，先计算该列的 L2 范数：

$$
norm[j] = \sqrt{\sum_{i=0}^{M-1} input[i, j]^2}
$$

然后对每个元素执行：

$$
output[i, j] =
rac{input[i, j]}{\max(norm[j],
arepsilon)}
$$

其中本题约定 `
arepsilon = 1e-12`，这与 `torch.nn.functional.normalize(input, p=2, dim=0)` 的默认行为一致。若某一列全为零，则该列输出也全为零。

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据数据规模计算合适的 launch 配置，并完成按列 L2 归一化。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输出格式

你需要将结果写入 `output` 指向的缓冲区，满足：

```text
for each column j:
    norm[j] = sqrt(sum_i(input[i, j] * input[i, j]))
    denom = max(norm[j], 1e-12)
    for each row i:
        output[i, j] = input[i, j] / denom
```

## 样例

## 输入

```text
M = 3
N = 2

input =
[
  [3.0, 0.0],
  [4.0, 5.0],
  [0.0, 12.0]
]
```

## 输出

```text
output =
[
  [0.6, 0.0],
  [0.8, 0.3846154],
  [0.0, 0.9230769]
]
```

## 计算过程说明

第 0 列：

$$
norm[0] = \sqrt{3^2 + 4^2 + 0^2} = 5
$$

因此：

* `output[0, 0] = 3 / 5 = 0.6`
* `output[1, 0] = 4 / 5 = 0.8`
* `output[2, 0] = 0 / 5 = 0.0`

第 1 列：

$$
norm[1] = \sqrt{0^2 + 5^2 + 12^2} = 13
$$

因此：

* `output[0, 1] = 0 / 13 = 0.0`
* `output[1, 1] = 5 / 13 pprox 0.3846154`
* `output[2, 1] = 12 / 13 pprox 0.9230769`
