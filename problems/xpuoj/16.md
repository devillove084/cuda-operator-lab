# Grouped Linear Variadic Weights

原题 https://xpuoj.com/p/16

## 题目描述

你需要实现一个分组变长线性层（双权矩阵）算子。给定输入和两组权重，每组使用对应的权重进行线性变换，两个权重在输出维度上拼接。

具体来说，给定输入 $X$（形状为 $(\text{total_tokens}, \text{in_features})$）以及两组权重 $W^{(1)}$、$W^{(3)}$（形状均为 $(\text{num_groups}, \text{out_features}, \text{in_features})$）。$\text{group_sizes}$（形状为 $(\text{num_groups},)$）表示每个组内的 token 数量，满足 $\sum_g \text{group_sizes}[g] = \text{total_tokens}$。tokens 按顺序归属组：前 $\text{group_sizes}[0]$ 个 token 属于组 0，接下来 $\text{group_sizes}[1]$ 个属于组 1，以此类推。

对每个组 $g$：

令 $W^{\text{concat}}_{g}$ 为 $W^{(1)}_{g}$ 和 $W^{(3)}_{g}$ 在输出维度上的拼接：

$$
W^{\text{concat}}_{g} = \begin{bmatrix} W^{(1)}_{g} \\ W^{(3)}_{g} \end{bmatrix}
$$

$W^{\text{concat}}_{g}$ 的形状为 $(2 \cdot \text{out_features}, \text{in_features})$。

令 $s_g = \sum_{t=0}^{g-1} \text{group_sizes}[t]$，$e_g = s_g + \text{group_sizes}[g]$。

则输出：

$$
\text{out}\left[s_g : e_g, \, :\right] = X\left[s_g : e_g, \, :\right] \cdot \bigl(W^{\text{concat}}_{g}\bigr)^T
$$

输出 $\text{out}$ 的形状为 $(\text{total_tokens}, 2 \cdot \text{out_features})$。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](https://xpuoj.com/d/2)。

## 输出格式

你需要将计算结果写入 $\text{out}$ 指向的缓冲区，得到一个 shape 为 $(\text{total_tokens}, 2 \cdot \text{out_features})$ 的 bfloat16 矩阵。

记 $s_g = \sum_{t=0}^{g-1} \text{group_sizes}[t]$（$s_0 = 0$），$e_g = s_g + \text{group_sizes}[g]$。对每个组 $g$：

$$
\text{out}\left[s_g : e_g, \, :\right] = X\left[s_g : e_g, \, :\right] \cdot \begin{bmatrix} W^{(1)}_{g} \\ W^{(3)}_{g} \end{bmatrix}^T
$$

其中 $X[s_g : e_g, :]$ 是第 $g$ 组的输入子块，$W^{(1)}_{g}$ 和 $W^{(3)}_{g}$ 分别是 $w1[g]$ 和 $w3[g]$。纵向拼接后的权重形状为 $(2 \cdot \text{out_features}, \text{in_features})$，其转置形状为 $(\text{in_features}, 2 \cdot \text{out_features})$，与输入相乘得到形状 $(\text{group_sizes}[g], 2 \cdot \text{out_features})$ 的输出。

[[1.0, 2.0, 3.0],

 [7.0, 8.0, 9.0],

```
[[0.7, 0.8, 0.9],

$w\_concat[0]$（将 $w1[0]$ 和 $w3[0]$ 拼接，shape $(4, 3)$）：

[[0.1, 0.2, 0.3],

最终输出：

```

 [3.2, 7.7, 12.2, 16.7],   # 组 0
 [..., ..., ..., ...],
 [..., ..., ..., ...]]      # 组 1

## PyTorch 参考实现

```python
def baseline(x, w1, w3, group_sizes, out, total_tokens, in_features, out_features, num_groups):
    """
    PyTorch 参考实现：Grouped Linear Variadic Weights

    参数说明：
    * x: 输入张量（bfloat16），shape (total_tokens, in_features)，行优先连续存储，只读
    * w1: 输入张量（bfloat16），shape (num_groups, out_features, in_features)，只读
    * w3: 输入张量（bfloat16），shape (num_groups, out_features, in_features)，只读
    * group_sizes: 输入张量（int32），shape (num_groups,)，每组 token 数，只读
    * out: 输出张量（bfloat16），shape (total_tokens, out_features * 2)，行优先连续存储，需写入结果
    * total_tokens: 总 token 数（int64）
    * in_features: 输入特征数（int64）
    * out_features: 单权输出的特征数（int64）
    * num_groups: 组数（int64）
    """
    # Create group indices for each token
    group_indices = torch.repeat_interleave(
        torch.arange(num_groups, device=x.device),
        group_sizes.long()
    )  # (total_tokens,)

    # Concatenate weights
    w_concat = torch.cat([w1, w3], dim=1)  # (G, 2*Out, In)

    # Gather weights for each token
    w_expanded = w_concat[group_indices]  # (total_tokens, 2*Out, In)

    # Compute out = x @ w.T
    res = torch.matmul(x.unsqueeze(1).float(), w_expanded.transpose(1, 2).float()).squeeze(1)
    out.copy_(res.to(torch.bfloat16))
```
