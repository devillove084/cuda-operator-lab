## 题目描述

你需要实现带分页 KV Cache 的批量解码注意力算子。对于 batch 中的每个请求，输入只包含当前时刻的单步查询 `q`，而历史 `K/V` 并不是按连续时间维直接给出的，而是被分散存放在若干 cache page 中。你需要先根据页表把每个请求真实可见的历史 `K`、`V` 恢复出来，再完成一次单步 decode attention。

具体来说，输入 query 的 shape 为：

$$
Q \in \mathbb{R}^{B \times H_q \times D}
$$

其中 $B$ 是 batch size，$H_q$ 是 query 头数，$D$ 是单头维度。对第 $b$ 个请求，记它的单步 query 为：

$$
q_b \in \mathbb{R}^{H_q \times D}
$$

同时，`actual_seq_lens_kv[b]` 给出该请求真实可用的历史长度，记为 $L_b$；`block_tables[b, p]` 给出第 $p$ 个 page 槽位对应的 page 编号。设 page 大小为 $P$，则该请求理论上需要的 page 数为：

$$
N_b = \left\lceil \frac{L_b}{P} \right\rceil
$$

对于每个有效的 page 编号

$$
\text{page\_id}_{b,p} = \text{block\_tables}[b, p], \quad 0 \le p < N_b
$$

你需要从 `k_cache` 和 `v_cache` 中取出对应页面，并沿时间维依次拼接。若单个 key page 记为

$$
K^{\text{page}}_{b,p} \in \mathbb{R}^{H_{kv} \times P \times D}, \quad
V^{\text{page}}_{b,p} \in \mathbb{R}^{H_{kv} \times P \times D}
$$

则恢复出的完整历史张量为：

$$
\widetilde{K}_b = \operatorname{concat}\!\left(K^{\text{page}}_{b,0}, K^{\text{page}}_{b,1}, \dots, K^{\text{page}}_{b,N_b-1}\right),
$$

$$
\widetilde{V}_b = \operatorname{concat}\!\left(V^{\text{page}}_{b,0}, V^{\text{page}}_{b,1}, \dots, V^{\text{page}}_{b,N_b-1}\right)
$$

然后在时间维上截断到真实长度 $L_b$，得到：

$$
K_b = \widetilde{K}_b[:, :L_b, :] \in \mathbb{R}^{H_{kv} \times L_b \times D},
$$

$$
V_b = \widetilde{V}_b[:, :L_b, :] \in \mathbb{R}^{H_{kv} \times L_b \times D}
$$

当 $H_q \neq H_{kv}$ 时，本题按照 baseline 的语义采用 GQA 的方式处理。令

$$
g = \frac{H_q}{H_{kv}}
$$

则每个 KV head 会在 head 维上重复 $g$ 次，使其与 query 头数对齐。记扩展后的张量为 $K_b^{\uparrow}, V_b^{\uparrow} \in \mathbb{R}^{H_q \times L_b \times D}$。

接下来，对每个请求、每个 query head 计算缩放点积注意力分数：

$$
S_b[h, t] = \left\langle q_b[h, :], K_b^{\uparrow}[h, t, :] \right\rangle \cdot \text{scale}
$$

其中测试中的缩放因子为：

$$
\text{scale} = \frac{1}{\sqrt{D}}
$$

对历史长度维做 softmax，得到注意力权重：

$$
P_b[h, t] = \frac{\exp(S_b[h, t])}{\sum_{j=0}^{L_b-1} \exp(S_b[h, j])}
$$

最后计算输出：

$$
o_b[h, :] = \sum_{t=0}^{L_b-1} P_b[h, t] \, V_b^{\uparrow}[h, t, :]
$$

因此，本题的关键有三步：先按 `block_tables` 恢复 paged KV cache，再按 GQA 规则扩展 KV heads，最后严格按照 `score -> softmax -> weighted sum` 的公式完成单步 decode attention，并把结果写回输出张量。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## 参数说明

* `q_ptr`：输入 query 指针（bfloat16），shape $(\text{batch_size}, \text{num_qo_heads}, \text{head_dim})$，行优先连续存储，只读
* `k_cache_ptr`：K 缓存指针（bfloat16），shape $(\text{total_num_pages}, \text{num_kv_heads}, \text{page_size}, \text{head_dim})$，行优先连续存储，只读
* `v_cache_ptr`：V 缓存指针（bfloat16），shape $(\text{total_num_pages}, \text{num_kv_heads}, \text{page_size}, \text{head_dim})$，行优先连续存储，只读
* `out_ptr`：输出指针（bfloat16），shape $(\text{batch_size}, \text{num_qo_heads}, \text{head_dim})$，行优先连续存储，需写入计算结果
* `scale`：注意力分数缩放因子（float），通常为 $1/\sqrt{\text{head_dim}}$
* `workspace_buffer_ptr`：工作空间指针，预留参数，当前未使用
* `max_sequence_kv`：KV 序列最大长度（int64）
* `actual_seq_lens_kv_ptr`：实际 KV 序列长度指针（int32），shape $(\text{batch_size}, 1, 1, 1)$，CPU 内存，只读
* `block_tables_ptr`：页表指针（int32），shape $(\text{batch_size}, \text{max_pages_per_seq})$，GPU 内存，只读，存储每个序列使用的 page id
* `batch_size`：batch 大小（int64）
* `num_qo_heads`：query/output 注意力头数（int64）
* `num_kv_heads`：KV 注意力头数（int64）
* `head_dim`：每个头的维度（int64）
* `page_size`：KV 缓存页大小（int64）
* `max_pages_per_seq`：每个序列最大页数（int64）

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成批量解码注意力计算

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 cudnn batch decode with kv cache

    Args:
        q: BF16 tensor of shape (batch_size, num_heads_qo, head_dim) - query
        k_cache: BF16 tensor of shape (total_num_pages, num_heads_kv, page_size, head_dim) - key cache
        v_cache: BF16 tensor of shape (total_num_pages, num_heads_kv, page_size, head_dim) - value cache
        o: BF16 tensor of shape (batch_size, num_heads_qo, head_dim) - output (will be modified inplace)
        scale: float - softmax scale factor
        workspace_buffer: uint8 tensor of shape (128000,) - workspace buffer
        max_sequence_kv: int - max sequence length for key/value
        actual_seq_lens_kv: int32 tensor of shape (batch_size, 1, 1, 1) - actual sequence lengths
        block_tables: int32 tensor of shape (batch_size, max_pages_per_seq) - block tables
        batch_size: int - batch size
        num_heads_qo: int - number of query/output heads
        num_heads_kv: int - number of key/value heads
        head_dim: int - head dimension
        page_size: int - page size
        max_pages_per_seq: int - max pages per sequence

    Returns:
        List containing modified o tensor
    """
    q, k_cache, v_cache, o, scale, workspace_buffer, max_sequence_kv, actual_seq_lens_kv, block_tables, batch_size, num_heads_qo, num_heads_kv, head_dim, page_size, max_pages_per_seq = inputs

    assert torch.is_tensor(q) and torch.is_tensor(k_cache) and torch.is_tensor(v_cache) and torch.is_tensor(o) and torch.is_tensor(workspace_buffer) and torch.is_tensor(actual_seq_lens_kv) and torch.is_tensor(block_tables)
    assert isinstance(scale, float) and isinstance(max_sequence_kv, int) and isinstance(batch_size, int) and isinstance(num_heads_qo, int) and isinstance(num_heads_kv, int) and isinstance(head_dim, int) and isinstance(page_size, int) and isinstance(max_pages_per_seq, int)
    assert q.shape == (batch_size, num_heads_qo, head_dim)
    assert k_cache.shape[1:] == (num_heads_kv, page_size, head_dim)
    assert v_cache.shape == k_cache.shape
    assert o.shape == q.shape
    assert workspace_buffer.shape == (128000,)
    assert actual_seq_lens_kv.shape == (batch_size, 1, 1, 1)
    assert block_tables.shape == (batch_size, max_pages_per_seq)

    device = q.device
    actual_seq_lens_kv_device = actual_seq_lens_kv.view(-1)

    output_list = []

    for batch_idx in range(batch_size):
        q_batch = q[batch_idx:batch_idx + 1]
        seq_len_kv = actual_seq_lens_kv_device[batch_idx].item()

        num_pages = (seq_len_kv + page_size - 1) // page_size
        k_list = []
        v_list = []

        for page_idx in range(num_pages):
            if page_idx < block_tables.shape[1] and block_tables[batch_idx, page_idx] >= 0:
                page_id = block_tables[batch_idx, page_idx].item()
                page_k = k_cache[page_id]
                page_v = v_cache[page_id]
                k_list.append(page_k)
                v_list.append(page_v)

        if k_list:
            k_batch = torch.cat(k_list, dim=1)
            v_batch = torch.cat(v_list, dim=1)
            k_batch = k_batch[:, :seq_len_kv, :]
            v_batch = v_batch[:, :seq_len_kv, :]

            if num_heads_kv != num_heads_qo:
                head_group_size = num_heads_qo // num_heads_kv
                k_batch = k_batch.repeat_interleave(head_group_size, dim=0)
                v_batch = v_batch.repeat_interleave(head_group_size, dim=0)

            scores = torch.einsum('bhd,hkd->bhk', q_batch, k_batch) * scale
            attn_weights = F.softmax(scores.float(), dim=-1).to(scores.dtype)
            output_batch = torch.einsum('bhk,hkd->bhd', attn_weights, v_batch)
            output_list.append(output_batch.squeeze(0))
        else:
            output_batch = torch.zeros(num_heads_qo, head_dim, device=device, dtype=q.dtype)
            output_list.append(output_batch)

    output = torch.stack(output_list, dim=0)
    o.copy_(output)

    return list(inputs)```
