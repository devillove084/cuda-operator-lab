# ReLU

LeetGPU · #21

[打开实现文件](../../practice/leetgpu/21/solution.cu) · [原始材料](../../references/LeetGPU/challenges/easy/21_relu/challenge.html)

Implement a program that performs the Rectified Linear Unit (ReLU) activation function on a vector of 32-bit floating point numbers. The ReLU function sets all negative values to zero and leaves positive values unchanged: \[\text{ReLU}(x) = \max(0, x)\]

## Implementation Requirements


- External libraries are not permitted

- The `solve` function signature must remain unchanged

- The final result must be stored in `output`



## Example 1:

~~~text

Input:  input = [-2.0, -1.0, 0.0, 1.0, 2.0]
Output: output = [0.0, 0.0, 0.0, 1.0, 2.0]

~~~

## Example 2:

~~~text

Input:  input = [-3.5, 0.0, 4.2]
Output: output = [0.0, 0.0, 4.2]

~~~

## Constraints


- 1 ≤ `N` ≤ 100,000,000

- Performance is measured with `N` = 25,000,000

## 本地接口

~~~cpp
extern "C" void solve(const float* input, float* output, int N);
~~~
