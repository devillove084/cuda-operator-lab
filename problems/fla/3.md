# Packed 变长 Gated Delta Rule

FLA · #3 · 综合 · 批处理与状态隔离

[打开实现文件](../../practice/fla/3/solution.cu) · [上游源码](../../references/FLA/fla/ops/gated_delta_rule/chunk.py)

## 任务

执行 [FLA #2](2.md) 的递推，但同一批次的序列有不同长度并被拼在一起。每个序列从自己的初始状态出发，写回自己的最终状态。

- 输入输出使用 `q/k[T_total,H,K]`、`v/out[T_total,H,V]`、`g/beta[T_total,H]`、`initial/final[B,H,K,V]`。int32 `offsets[B+1]` 指定第 `b` 条序列的半开区间 `[offsets[b],offsets[b+1])`；`tokens=T_total`。其余均为 FP32。
- 相邻 offset 可以相等。空序列的 final 与 initial 相同。输出顺序保持 packed 顺序，任何序列都不能读写相邻序列的状态。
- 对 `offsets=[0,0,2,3]`，第一条只有状态复制，第二条计算 token 0、1，第三条计算 token 2。每条序列的 key 已归一化。

先用逐序列递推实现语义，再以 32 或 64 token 为块，验证跨块状态接续。长序列、全空批次和短长混合是必要回归项。
