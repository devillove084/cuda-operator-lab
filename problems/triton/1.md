## 任务

使用 K 方向分组的独立 FP32 scale，将两组 FP8 E4M3 有限值反量化并做 `A×Bᵀ`。这是面向 CUDA C++ 的练习，便于核对格式、布局和尾块。

- `A[M,K]`、`B[N,K]` 为 E4M3FN，`a_scale[M,G]`、`b_scale[N,G]` 为 FP32，其中 `G=ceil(K/block_k)`，输出 `C[M,N]` 为 FP32。
- 对 K 轴的 `i`，`g=i/block_k`。累加 `(float(A[m,i])*a_scale[m,g])*(float(B[n,i])*b_scale[n,g])`。最后一组可能不足 `block_k`，只读真实的 K。
- scale 可以为 0。输入包含 E4M3FN 最大有限值 ±448 和很小的 scale。每行的 scale 独立，A 与 B 的行数和 layout 独立。

先写通用 CUDA 版，与显式反量化后的 FP64 GEMM 对拍。然后尝试分块复用数据，并比较在匹配的 scale 格式和架构上如何用 Tensor Core。
