## 任务

实现右下对齐的因果 attention，并支持向过去延伸的滑动窗口。要求计算输出与自然对数 LSE。

- `q[B,Q,H,D]`、`k/v[B,K,H,D]` 为 FP16，`out[B,Q,H,D]` 与 `out_lse[B,Q,H]` 为 FP32。
- Query `i` 映射到 KV 位置 `center=i+K-Q`。允许的位置 `j` 必须满足 `0≤j<K` 且 `j≤center`。当 `window_left≥0`，另要求 `j≥center-window_left`。等于 `-1` 时使用整个因果历史。
- 对允许的 j 计算 `score_j=dot(q_i,k_j)*scale`，输出 stable softmax 对 V 的加权和及 `ln(Σ exp(score_j))`。整行被掩码时写 0 和 `-inf`。
- `Q=5,K=2,window_left=-1` 时，前 3 行为空，第 4 行看 KV 位置 0，第 5 行看 0 与 1。

先验证小掩码矩阵，再对 Q/K 分块做在线归约。比较稀疏窗口与长序列全因果版本的实际带宽。
