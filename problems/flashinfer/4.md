## 任务

每条序列给出一个 query token，直接从分页 KV Cache 计算 grouped-query attention。练完本题可把第三题的合并用于 split-KV 实现。

- `q[B,Hq,D]` 与 NHD 格式 `cache_k/cache_v[P,W,Hkv,D]` 为 FP16，`out[B,Hq,D]` 和 `out_lse[B,Hq]` 为 FP32。int32 `lengths[B]` 给出有效 KV 长度。前缀和 `indptr[B+1]` 指向每条序列在 `indices` 中的页表。
- `Hq` 是 `Hkv` 的整数倍，query head `h` 对应 KV head `h/(Hq/Hkv)`。对该序列有效 KV token，求 `score_j=dot(q,k_j)*scale`，用稳定 softmax 加权 `v_j`。写出 `log2(Σ exp(score_j))`。空行写 0 与 `-inf`。
- 页号可乱序，首个满页可被多个序列共享。长度为 0 时跳过页表，真实长度外的槽位都不参与归约。单 token 的输出应等于对应的 V。

先实现每个 query head 的单 CTA 版本；跑通共享页、空序列和大 logits。然后用在线 softmax 或分片合并处理长序列，分开计量小 batch 单步延迟和大 batch 吞吐。
