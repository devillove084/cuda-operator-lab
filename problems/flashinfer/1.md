# 分页 KV Cache Gather

FlashInfer · #1 · 入门 · 地址计算

[打开实现文件](../../practice/flashinfer/1/solution.cu) · [上游源码](../../references/FlashInfer/include/flashinfer/page.cuh)

## 任务

把 NHD 格式的分页 K/V 读取成两个 token-major 的连续张量。这个读路径是 Paged GQA Decode 的前置练习。

- 输入 `cache_k/cache_v[P,W,H,D]`、页表指针 `indptr[B+1]`、物理页号 `indices`、输出前缀和 `out_indptr[B+1]`。缓存和输出为 FP16，表为 int32。
- 对序列 `b` 的位置 `t`，读物理页 `indices[indptr[b]+t/W]` 的第 `t%W` 个 token。写到 `out_indptr[b]+t`，保留 head 和 channel 位置。
- `out_indptr[b+1]-out_indptr[b]` 给出该序列真实长度。物理页可乱序或被多条序列共享。空序列不读页表，最后一页只读有效 token。
- 例子是 `W=2`、`indptr=[0,2,3]`、`indices=[4,1,7]`、`out_indptr=[0,3,4]`，输出依次来自 `(4,0),(4,1),(1,0),(7,0)`。

先用标量索引过单页与跨页，再比较每线程搬一项与每 warp 搬一个连续片段。检查跨页末尾和非对齐 `D`。性能可以用有效搬运字节除以时间。
