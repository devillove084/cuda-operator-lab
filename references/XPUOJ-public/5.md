# SwiGLU

原题 https://xpuoj.com/p/5

## 题目描述

你需要实现一个 SwiGLU 激活函数算子。SwiGLU 是 Swish 门控线性单元的简称，常用于大语言模型的 FFN 层。

给定输入矩阵 $x$（shape 为 $(T, 2H)$），将其在最后一维上平均分成两半：

$$
x_1 = x[:, :H], \quad x_2 = x[:, H:]
$$

然后计算输出：

$$
y = \text{SiLU}(x_1) \odot x_2
$$

其中 $\odot$ 表示逐元素乘法，SiLU（Sigmoid Linear Unit）激活函数定义为：

$$
\text{SiLU}(z) = z \cdot \sigma(z) = \frac{z}{1 + e^{-z}}
$$

这里 $\sigma(\cdot)$ 是 sigmoid 函数。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成 SwiGLU 计算。

如何提交代码详见[评测指南](/d/2)。

## 输出格式

你需要将计算结果写入 $y$ 指向的缓冲区，得到一个 shape 为 $(T, H)$ 的 bfloat16 矩阵。对于每个位置 $(t, h)$，输出应满足：

$$
y_{t,h} = \text{SiLU}(x_{t,h}) \cdot x_{t,h+H}
$$

其中 $x_{t,h}$ 来自输入矩阵前半部分，$x_{t,h+H}$ 来自后半部分，SiLU 函数定义为：

$$
\text{SiLU}(z) = \frac{z}{1 + e^{-z}}
$$

## 样例

## 输入

`x`（shape 为 $(2, 4)$，其中 $T=2, H=2$）：


该输入将在最后一维被分为两部分：
* $x_1$（前半部分）：`[[1.0, 2.0], [0.5, 1.5]]`
* $x_2$（后半部分）：`[[3.0, 4.0], [2.5, 3.5]]`

## 输出

`y`（shape 为 $(2, 2)$）：

```
[[SiLU(1.0)*3.0, SiLU(2.0)*4.0],

```

## 计算过程说明

首先计算 SiLU 值：
* $\text{SiLU}(1.0) = 1.0 / (1 + e^{-1.0}) \approx 0.731$
* $\text{SiLU}(2.0) = 2.0 / (1 + e^{-2.0}) \approx 1.762$
* $\text{SiLU}(0.5) = 0.5 / (1 + e^{-0.5}) \approx 0.311$
* $\text{SiLU}(1.5) = 1.5 / (1 + e^{-1.5}) \approx 1.154$

然后计算输出：
* $y_{0,0} = 0.731 \times 3.0 \approx 2.193$
* $y_{0,1} = 1.762 \times 4.0 \approx 7.048$
* $y_{1,0} = 0.311 \times 2.5 \approx 0.778$
* $y_{1,1} = 1.154 \times 3.5 \approx 4.039$

## PyTorch 参考实现

```python
import torch.nn.functional as F

def baseline(x, y, T, H):
    """
    PyTorch 参考实现：SwiGLU
    
    参数说明：
    * x: 输入张量（bfloat16），shape (T, 2H)，行优先连续存储，只读
    * y: 输出张量（bfloat16），shape (T, H)，行优先连续存储，需写入结果
    * T: 序列长度（int64）
    * H: 隐藏层维度（int64）
    """
    x_1 = x[:, :H]
    x_2 = x[:, H:]
    silu_x1 = F.silu(x_1)
    y_ref = silu_x1 * x_2
    y.copy_(y_ref)
```
