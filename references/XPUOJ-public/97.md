# Marlin W4a16 GeMM

原题 https://xpuoj.com/p/97

## 题目描述

你需要实现一个 Marlin 风格的对称量化 `W4A16 GEMM` 算子。

给定输入激活矩阵 `a`、按 4-bit 打包存储的权重矩阵 `b_quant`，以及按 `K` 维分组的缩放矩阵 `b_scales`，你需要先将权重解包并反量化，再完成矩阵乘法，得到输出矩阵 `out`。

各张量的 shape 与 dtype 如下：

* `a`：shape `(M, K)`，dtype `float16`
* `b_quant`：shape `(K, N / 2)`，dtype `int8`
* `b_scales`：shape `(K / group_size, N)`，dtype `float16`
* `out`：shape `(M, N)`，dtype `float16`

其中 `b_quant[k, p]` 的一个 `int8` 元素中打包了两个 4-bit 无符号权重值：

* 低 4 位对应第 `2p` 列
* 高 4 位对应第 `2p + 1` 列

记：

$$
q^{(lo)}_{k,p} = b\_quant_{k,p} \mathbin{\&} 15
$$

$$
q^{(hi)}_{k,p} = (b\_quant_{k,p} \gg 4) \mathbin{\&} 15
$$

则解包后的 4-bit 权重 `q` 满足：

$$
q_{k, 2p} = q^{(lo)}_{k,p}, \quad q_{k, 2p+1} = q^{(hi)}_{k,p}
$$

对每个位置 `(k, n)`，其所属缩放组为：

$$
g = \left\lfloor \frac{k}{group\_size} \right\rfloor
$$

按题意使用对称反量化公式：

$$
B_{k,n} = b\_scales_{g,n} \cdot (q_{k,n} - 8)
$$

最终输出矩阵满足：

$$
out_{m,n} = \sum_{k=0}^{K-1} a_{m,k} \cdot B_{k,n}
$$

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据数据规模计算合适的 launch 配置，并完成权重解包、反量化和矩阵乘法。

如何提交代码详见[评测指南](/d/2)。

## 计算过程说明

先按 `group_size = 2` 分组反量化：

* `k = 0, 1` 使用 `b_scales[0]`
* `k = 2, 3` 使用 `b_scales[1]`

反量化后得到：

```text
B =
[
  [ 0.00, -0.50,  0.0, -2.0],
  [ 0.50, -0.50, -2.0, -3.0],
  [ 0.00, -1.00,  1.0, -3.0],
  [-0.25, -1.75,  0.5, -4.0]
]
```

于是第 0 行输出为：

$$
out_{0,0} = 1 \cdot 0 + 2 \cdot 0.5 + 0 \cdot 0 + (-1) \cdot (-0.25) = 1.25
$$

$$
out_{0,2} = 1 \cdot 0 + 2 \cdot (-2) + 0 \cdot 1 + (-1) \cdot 0.5 = -4.5
$$

第 1 行第 1 列输出为：

$$
out_{1,1} = 0 \cdot (-0.5) + 1 \cdot (-0.5) + 3 \cdot (-1.0) + 2 \cdot (-1.75) = -7.0
$$

其余位置同理可得最终输出矩阵。

## PyTorch 参考实现

```python
import torch


def unpack_and_dequantize(b_quant, b_scales, K, N, group_size):
    packed = torch.bitwise_and(b_quant.to(torch.int16), 0xFF)
    lo = torch.bitwise_and(packed, 0x0F).to(torch.float16)
    hi = torch.bitwise_and(torch.bitwise_right_shift(packed, 4), 0x0F).to(torch.float16)
    q = torch.stack((lo, hi), dim=2).reshape(K, N)
    scales = b_scales.repeat_interleave(group_size, dim=0)
    return scales * (q - 8.0)


def baseline(a, b_quant, b_scales, out, M, N, K, group_size):
    B = unpack_and_dequantize(b_quant, b_scales, K, N, group_size)
    out.copy_(torch.matmul(a, B))
```
