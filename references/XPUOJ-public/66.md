# Conv2d Bias Selu

原题 https://xpuoj.com/p/66

## 题目描述

你需要实现一个融合算子：

> **output = selu(conv2d(x, weight, bias, stride, padding))**

给定输入张量 `x`、卷积核 `weight` 和偏置 `bias`，其中：

* `x` 的 shape 为 `(N, C_in, H, W)`
* `weight` 的 shape 为 `(C_out, C_in, R, S)`
* `bias` 的 shape 为 `(C_out,)`
* `output` 的 shape 为 `(N, C_out, H_out, W_out)`

首先执行标准二维卷积并加上偏置：

$$
tmp = \text{conv2d}(x, weight, bias, stride, padding)
$$

然后对卷积输出的每个元素施加 `SELU` 激活函数：

$$
output_{n,c,h,w} = \text{SELU}(tmp_{n,c,h,w})
$$

在本题中采用 PyTorch 的默认 `SELU` 定义：

$$
\mathrm{SELU}(x) = \lambda \cdot x, \quad x > 0
$$

$$
\mathrm{SELU}(x) = \lambda \cdot \alpha \cdot (e^x - 1), \quad x \le 0
$$

其中常数为：

```text
alpha = 1.6732632423543772
scale = 1.0507009873554805
```

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述融合计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp

extern "C" void run_kernel(
    const float* x,
    const float* weight,
    const float* bias,
    float* output,

    int64_t C_out,
```

### 参数说明

* `x`：输入指针（float32），shape `(N, C_in, H, W)`，行优先连续存储，只读
* `weight`：输入指针（float32），shape `(C_out, C_in, R, S)`，行优先连续存储，只读
* `bias`：输入指针（float32），shape `(C_out,)`，只读
* `output`：输出指针（float32），shape `(N, C_out, H_out, W_out)`，行优先连续存储，需写入计算结果
* `N`：batch size（int64）
* `C_in`：输入通道数（int64）
* `C_out`：输出通道数（int64）
* `H`、`W`：输入空间大小（int64）
* `R`、`S`：卷积核空间大小（int64）
* `stride`：卷积步长（int64）
* `padding`：零填充大小（int64）

`run_kernel` 内部需要完成以下工作：

* 根据卷积参数计算输出形状
* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 `output = selu(conv2d(x, weight, bias, stride, padding))`

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：shape `(N, C_in, H, W)` 的 float32 张量
* `weight`：shape `(C_out, C_in, R, S)` 的 float32 张量
* `bias`：shape `(C_out,)` 的 float32 张量
* `output`：shape `(N, C_out, H_out, W_out)` 的 float32 输出缓冲区，初始值未定义
* `N`、`C_in`、`C_out`、`H`、`W`、`R`、`S`、`stride`、`padding`：int64 标量

其中输出空间大小满足：

$$
H_{out} = \left\lfloor \frac{H + 2 \times padding - R}{stride} \right\rfloor + 1
$$

$$
W_{out} = \left\lfloor \frac{W + 2 \times padding - S}{stride} \right\rfloor + 1
$$

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区。对于每个位置 `(n, c_out, h, w)`，输出应满足：

$$
tmp_{n,c_{out},h,w} = bias_{c_{out}} + 
\sum_{c_{in}=0}^{C_{in}-1} \sum_{k_h=0}^{R-1} \sum_{k_w=0}^{S-1}
 x_{n,c_{in},h \times stride - padding + k_h,\ w \times stride - padding + k_w}
 \cdot weight_{c_{out},c_{in},k_h,k_w}
$$

$$
output_{n,c_{out},h,w} = \mathrm{SELU}(tmp_{n,c_{out},h,w})
$$

## 样例

## 输入

```text
N = 1
C_in = 3
C_out = 4
H = W = 8
R = S = 3
stride = 1
padding = 1
```

此时：

```text
H_out = (8 + 2 * 1 - 3) / 1 + 1 = 8
W_out = (8 + 2 * 1 - 3) / 1 + 1 = 8
```

所以：

```text
x.shape = (1, 3, 8, 8)
weight.shape = (4, 3, 3, 3)
bias.shape = (4,)
output.shape = (1, 4, 8, 8)
```

## 输出

```text
output = selu(conv2d(x, weight, bias, stride, padding))
```

## 数据范围与提示

## 数据范围

* `x`、`weight`、`bias`、`output` 的数据类型均为 `torch.float32`
* `x` 的 shape 为 `(N, C_in, H, W)`
* `weight` 的 shape 为 `(C_out, C_in, R, S)`
* `bias` 的 shape 为 `(C_out,)`
* `output` 的 shape 为 `(N, C_out, H_out, W_out)`
* 所有 tensor 均为连续存储（contiguous）
* 评测中 `N` 最大可达 `4`
* 评测中 `C_in` 最大可达 `384`
* 评测中 `C_out` 最大可达 `320`
* 评测中 `H` 最大可达 `384`，`W` 最大可达 `320`
* 评测中 `R`、`S` 最大可达 `5`，`stride` 最大可达 `3`
* `padding` 的取值覆盖 `0`、`1`、`2`

## 提示

* 本题不是单纯的 `conv2d`，不能漏掉 `bias` 或 `SELU`
* 评测使用 `torch.nn.functional.selu(torch.nn.functional.conv2d(...))` 作为参考实现
* `SELU` 在正数区间是线性变换，在非正区间是指数形式，注意两段定义都要正确实现

## PyTorch 参考实现

```python
import torch.nn.functional as F

def baseline(x, weight, bias, output, N, C_in, C_out, H, W, R, S, stride, padding):
    """
    PyTorch 参考实现：output = selu(conv2d(x, weight, bias, stride, padding))

    参数说明：
    * x: 输入张量（float32），shape (N, C_in, H, W)
    * weight: 输入张量（float32），shape (C_out, C_in, R, S)
    * bias: 输入张量（float32），shape (C_out,)
    * output: 输出张量（float32），shape (N, C_out, H_out, W_out)
    * 其余参数为卷积与输出形状所需的 int64 标量
    """
    tmp = F.conv2d(x, weight, bias, stride, padding)
    output.copy_(F.selu(tmp))
```
