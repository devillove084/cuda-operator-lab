# GEMM LogSoftmax

原题 https://xpuoj.com/p/144

## 题目描述

你需要实现一个 GEMM + LogSoftmax 融合算子。给定输入矩阵 `a`、权重矩阵 `b` 和偏置向量 `bias`，先计算矩阵乘法并加上偏置：

$$
C = a \times b + bias
$$

然后对 `C` 的每一行沿最后一维计算 log-softmax，得到输出矩阵 `out`：

$$
out_{i,j} = C_{i,j} - \log\left(\sum_{t=0}^{N-1}\exp(C_{i,t})\right)
$$

其中 `a` 的 shape 为 $(M, K)$，`b` 的 shape 为 $(K, N)$，`bias` 的 shape 为 $(N,)$，会按列广播到输出矩阵，`out` 的 shape 为 $(M, N)$。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* a,
    const __nv_bfloat16* b,
    const __nv_bfloat16* bias,
    __nv_bfloat16* out,
    int64_t M,
    int64_t K,
    int64_t N
);
```

### 参数说明

* `a`：输入指针（bfloat16），shape $(M, K)$，行优先连续存储，只读
* `b`：输入指针（bfloat16），shape $(K, N)$，行优先连续存储，只读
* `bias`：输入指针（bfloat16），shape $(N,)$，逐列偏置向量，只读
* `out`：输出指针（bfloat16），shape $(M, N)$，行优先连续存储，需写入计算结果
* `M`：输入矩阵 `a` 的行数，也是 `out` 的行数（int64）
* `K`：输入矩阵 `a` 的列数，也是 `b` 的行数（int64）
* `N`：权重矩阵 `b` 的列数，也是 `out` 的列数和 `bias` 的长度（int64）

`run_kernel` 内部需要完成以下工作：

* 计算 `a @ b + bias`
* 使用数值稳定的方式对每一行计算 log-softmax
* 将结果写入 `out`

## 输出格式

你需要将计算结果写入 `out` 指向的缓冲区，得到一个 shape 为 $(M, N)$ 的 bfloat16 矩阵，满足：

$$
C_{i,j} = \sum_{k=0}^{K-1} a_{i,k} \cdot b_{k,j} + bias_j
$$

$$
out_{i,j} = C_{i,j} - \log\left(\sum_{t=0}^{N-1}\exp(C_{i,t})\right)
$$

## 数据范围与提示

## 数据范围

* `a`、`b`、`bias`、`out` 的数据类型均为 `torch.bfloat16`
* `a` 的 shape 为 $(M, K)$
* `b` 的 shape 为 $(K, N)$
* `bias` 的 shape 为 $(N,)$
* `out` 的 shape 为 $(M, N)$
* 所有 tensor 均为连续存储（contiguous）
* $1 \le M \le 3072$
* $1 \le K \le 4097$
* $1 \le N \le 4096$

## 正确性要求

* 必须正确实现矩阵乘法 `a @ b`
* 必须正确按列广播 `bias`
* 必须正确计算每一行的 log-softmax
* 必须将最终结果写入 `out`
* 不允许修改 `a`、`b` 和 `bias`

## 提示

* 推荐使用 log-sum-exp 技巧提高 log-softmax 的数值稳定性
* `bias` 是长度为 $N$ 的一维向量，需要对所有 $M$ 行复用
* `b` 的布局是 $(K, N)$，本题计算的是标准矩阵乘法 `a @ b`

## PyTorch 参考实现

```python
def baseline(a, b, bias, out, M, K, N):
    c = torch.matmul(a.float(), b.float()) + bias.float().view(1, N)
    out.copy_(F.log_softmax(c, dim=-1).to(torch.bfloat16))
```
