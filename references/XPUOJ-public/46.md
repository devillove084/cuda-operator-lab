# Deconv2d Broadcast

原题 https://xpuoj.com/p/46

## 题目描述

你需要实现一个带 broadcast 逐元素加法的二维转置卷积（deconvolution）前向传播算子：

> **output = conv_transpose2d(x, weight, bias, stride, padding, output_padding) + broadcast**

给定输入张量 `x`、卷积核 `weight`、偏置 `bias`、额外输入 `broadcast`、步长 `stride`、填充 `padding` 和 `output_padding`，你需要计算一个标准的 `conv_transpose2d`，再与 `broadcast` 做逐元素相加。

为了适配 OJ，本题固定要求传入 `bias` 和 `broadcast`，并使用 PyTorch 的 `torch.nn.functional.conv_transpose2d` 作为参考语义：

* 输入、权重、偏置、broadcast 都使用 `torch.bfloat16`
* 转置卷积内部按 `float32` 语义参考实现
* 输出写入 `torch.bfloat16` 张量
* 结果按 `allclose` 容差校验，不要求逐 bit 完全一致

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成二维转置卷积前向传播与 broadcast 加法。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### 参数说明

* `x`：输入指针，shape `(N, C_in, H, W)`，类型为 bfloat16
* `weight`：输入指针，shape `(C_in, C_out, R, S)`，类型为 bfloat16
* `bias`：输入指针，shape `(C_out,)`，类型为 bfloat16

`run_kernel` 内部需要完成以下工作：

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：bfloat16 tensor，shape `(N, C_in, H, W)`
* `weight`：bfloat16 tensor，shape `(C_in, C_out, R, S)`
* `bias`：bfloat16 tensor，shape `(C_out,)`
* `broadcast`：bfloat16 tensor，shape `(N, C_out, H_out, W_out)`
* `output`：bfloat16 tensor，shape `(N, C_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, H, W, R, S, stride, padding, output_padding`：int64 标量

## 输出格式

输出张量满足：

```text
H_out = (H - 1) * stride - 2 * padding + R + output_padding
W_out = (W - 1) * stride - 2 * padding + S + output_padding

temp[n, c_out, h, w] =
    bias[c_out] +
    sum_{c_in, h_in, w_in, k_h, k_w}
        x[n, c_in, h_in, w_in] * weight[c_in, c_out, k_h, k_w]

output[n, c_out, h, w] = temp[n, c_out, h, w] + broadcast[n, c_out, h, w]
```

其中只有满足以下条件的项才会对 `temp[n, c_out, h, w]` 产生贡献：

```text
h = h_in * stride - padding + k_h
w = w_in * stride - padding + k_w
```

## 样例

## 输入

```text
N = 1
C_in = 1
C_out = 1
H = W = 2
R = S = 3
stride = 2
padding = 1
output_padding = 1
```

此时：

```text
H_out = (2 - 1) * 2 - 2 * 1 + 3 + 1 = 4
W_out = (2 - 1) * 2 - 2 * 1 + 3 + 1 = 4
```

所以：

```text
temp.shape = (1, 1, 4, 4)
broadcast.shape = (1, 1, 4, 4)
output.shape = (1, 1, 4, 4)
```

转置卷积先生成一个 `(1, 1, 4, 4)` 的中间结果，然后再与同形状的 `broadcast` 逐元素相加，得到最终输出。

## 正确性要求

* 必须正确处理 `stride`
* 必须正确处理 `padding`
* 必须正确处理 `output_padding`
* 必须正确累加全部输入通道与卷积核空间维度
* 必须正确加上 `bias`
* 必须正确执行与 `broadcast` 的逐元素加法
* 必须将结果写入 `output`

## 提示

* `weight` 的形状是 `(C_in, C_out, R, S)`，与普通 `conv2d` 的 `(C_out, C_in, R, S)` 不同
* 可以先计算转置卷积，再单独完成与 `broadcast` 的逐元素相加
* `output_padding` 只影响输出形状，不会改变单个输入像素映射到输出的位置公式
* 若你先在更高精度中累加，最终写回时要保持输出类型为 `bfloat16`
* 评测使用 `torch.nn.functional.conv_transpose2d` 作为参考实现

## PyTorch 参考实现

```python
def baseline(x, weight, bias, broadcast, output, N, C_in, C_out, H, W, R, S, stride, padding, output_padding):
    temp = torch.nn.functional.conv_transpose2d(
        x.float(),
        weight.float(),
        bias.float(),
        stride,
        padding,
        output_padding,
    ).to(output.dtype)
    output.copy_(temp + broadcast)
```
