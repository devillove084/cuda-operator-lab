# Int8 Scale Amax

原题 https://xpuoj.com/p/101

## 题目描述

你需要实现一个融合算子 `int8_scale_amax`。

给定输入矩阵 `input` 和按列缩放向量 `scale`，你需要同时完成以下两项计算：

1. 逐元素缩放并转换为 `int8` 输出 `output`
2. 沿第 0 维计算输入绝对值的逐列最大值 `amax`

各张量的 shape 与 dtype 如下：

* `input`：shape `(M, N)`，dtype `float32`
* `scale`：shape `(N,)`，dtype `float32`
* `output`：shape `(M, N)`，dtype `int8`
* `amax`：shape `(N,)`，dtype `float32`

对任意 `0 <= i < M`、`0 <= j < N`，定义：

$$
output[i, j] = \operatorname{int8}(input[i, j] \cdot scale[j])
$$

其中 `int8(...)` 表示先按实数乘法得到 `float32` 结果，再执行与 `PyTorch` 中 `.to(torch.int8)` 一致的转换。在本题测试数据范围内，缩放后的数值都会落在 `[-127, 127]` 内，因此可以按“朝零截断后转为 `int8`”理解。

同时，对每个列下标 `j`，还需计算：

$$
amax[j] = \max_{0 \le i < M} |input[i, j]|
$$

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据数据规模计算合适的 launch 配置，并完成逐元素缩放、类型转换与逐列归约。

如何提交代码详见[评测指南](/d/2)。

## 样例

## 输入

```text
M = 3
N = 4

input =
[
  [ 1.20, -2.60,  0.50, -1.50],
  [-3.10,  0.25, -4.80,  2.20],
  [ 0.70,  1.75,  3.40, -0.10]
]

```

## 输出

```text
output =
[
  [  2,   7,   2,  -7],
  [ -6,   0, -19,  11],
  [  1,  -5,  13,   0]
]

amax = [3.10, 2.60, 4.80, 2.20]
```

## 计算过程说明

逐元素缩放并转成 `int8`：

* 第 0 行：
  * `1.20 * 2.0 = 2.40 -> 2`
  * `-2.60 * (-3.0) = 7.80 -> 7`
  * `0.50 * 4.0 = 2.00 -> 2`
  * `-1.50 * 5.0 = -7.50 -> -7`
* 第 1 行：
  * `-3.10 * 2.0 = -6.20 -> -6`
  * `0.25 * (-3.0) = -0.75 -> 0`
  * `-4.80 * 4.0 = -19.20 -> -19`
  * `2.20 * 5.0 = 11.00 -> 11`
* 第 2 行：
  * `0.70 * 2.0 = 1.40 -> 1`
  * `1.75 * (-3.0) = -5.25 -> -5`
  * `3.40 * 4.0 = 13.60 -> 13`
  * `-0.10 * 5.0 = -0.50 -> 0`

逐列绝对值最大值：

* 第 0 列：`max(|1.20|, |-3.10|, |0.70|) = 3.10`
* 第 1 列：`max(|-2.60|, |0.25|, |1.75|) = 2.60`
* 第 2 列：`max(|0.50|, |-4.80|, |3.40|) = 4.80`
* 第 3 列：`max(|-1.50|, |2.20|, |-0.10|) = 2.20`

## PyTorch 参考实现

```python
import torch


def baseline(input, scale, output, amax, M, N):
    output.copy_((input * scale).to(torch.int8))
    amax.copy_(torch.amax(torch.abs(input), dim=0))
```
