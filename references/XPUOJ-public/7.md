# ReLU

原题 https://xpuoj.com/p/7

## 题目描述

你需要实现一个 ReLU（Rectified Linear Unit）激活函数算子。ReLU 是深度学习中最常用的激活函数之一，其定义非常简单：对于每个输入元素，如果大于零则保持不变，否则输出零。

数学表达式为：

$$
y_{i,j} = \max(x_{i,j}, 0)
$$

或等价地写为：

$$
y_{i,j} = \begin{cases}
x_{i,j} & \text{若 } x_{i,j} > 0 \\[4pt]
0 & \text{否则}
\end{cases}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成 ReLU 计算。

如何提交代码详见[评测指南](/d/2)。

## 输出格式

你需要将计算结果写入 $y$ 指向的缓冲区，得到一个 shape 为 $(T, H)$ 的 bfloat16 矩阵。对于每个位置 $(i, j)$，输出应满足：

$$
y_{i,j} = \max(x_{i,j}, 0)
$$

即负值被裁剪为零，非负值保持不变。

## 样例

## 输入

`x`（shape 为 $(2, 3)$，其中 $T=2, H=3$）：

```

 [-1.0, 0.0, 2.0]]
```

## 输出

`y`（shape 为 $(2, 3)$）：

```
[[1.0, 0.0, 3.0],
 [0.0, 0.0, 2.0]]
```

## 计算过程说明

ReLU 函数对输入矩阵的每个元素独立进行计算：

* $x_{0,0} = 1.0$（正值）→ $y_{0,0} = 1.0$
* $x_{0,1} = -2.0$（负值）→ $y_{0,1} = 0.0$
* $x_{0,2} = 3.0$（正值）→ $y_{0,2} = 3.0$
* $x_{1,0} = -1.0$（负值）→ $y_{1,0} = 0.0$
* $x_{1,1} = 0.0$（零值）→ $y_{1,1} = 0.0$
* $x_{1,2} = 2.0$（正值）→ $y_{1,2} = 2.0$
