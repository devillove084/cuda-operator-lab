# Top p Renorm Probs

原题 https://xpuoj.com/p/3

## 题目描述

你需要实现一个 Top-p（Nucleus）重归一化算子。该算子对概率分布的每一行进行处理，按以下规则筛选并重归一化概率：

首先将每行的概率值按降序排序，然后计算前缀累积和，保留累积概率不超过给定阈值 $\text{top_p}$ 的那些概率值，将其余概率置零，最后对保留下来的概率进行重归一化，使其总和为 1。

具体来说，对于每一行 $i$，设该行原始概率为 $\mathbf{p} = (p_1, p_2, \ldots, p_N)$，处理流程如下：

1. 将概率按值降序排序，得到 $\mathbf{p}^{\text{sorted}}$
2. 计算排序后概率的前缀累积和：$S_j = \sum_{t=1}^{j} p_t^{\text{sorted}}$
3. 找到满足 $S_j \le \text{top_p}[i]$ 的最大索引 $j^*$
4. 若 $j^* \ge 1$，保留前 $j^*$ 个概率；否则至少保留第一个最大概率
5. 对保留的概率值重新归一化，使其总和为 1，然后写回原始索引位置

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述 Top-p 重归一化操作。

## 输入格式

* `top_p`：float32 tensor，shape $(batch\_size,)$，连续存储，每个元素表示对应样本的 top-p 阈值，取值范围在 $(0, 1)$ 之间
* `renorm_probs`：float32 tensor，shape $(batch\_size, num\_classes)$，行优先连续存储，作为输出缓冲区，初始值未定义
* `batch_size`：int64 标量，表示批次中的样本数量
* `num_classes`：int64 标量，表示类别总数

## 输出格式

你需要将计算结果写入 $\text{renorm_probs}$ 指向的缓冲区，得到一个 shape 为 $(\text{batch_size}, \text{num_classes})$ 的 float32 矩阵。

对于每一行 $i$，设排序后的概率为 $p_{(1)} \ge p_{(2)} \ge \ldots \ge p_{(N)}$，前缀和为 $S_j = \sum_{t=1}^{j} p_{(t)}$。令 $j^* = \max\{j \mid S_j \le \text{top_p}[i]\}$（若不存在则 $j^* = 1$），则输出应满足：

$$
\text{renorm_probs}[i, c] = 
\begin{cases}
\displaystyle \frac{p_c}{\sum_{t=1}^{j^*} p_{(t)}} & \text{若 } p_c \in \{p_{(1)}, \ldots, p_{(j^*)}\} \\[8pt]
0 & \text{否则}
\end{cases}
$$

即保留累积概率不超过 $\text{top_p}[i]$ 的最大前缀集合，对其进行重归一化，其余位置置零。

## 样例

## 输入

`probs`（shape 为 $(2, 4)$）：

```
[[0.4, 0.2, 0.3, 0.1],
 [0.3, 0.3, 0.1, 0.3]]
```

`top_p`（shape 为 $(2,)$）：

```
[0.8, 0.9]
```

## 输出

```
[[0.5714, 0.0, 0.4286, 0.0], 
 [0.333, 0.333, 0.0, 0.333]]
```

## 计算过程说明

**第 1 行**（`top_p = 0.8`）：

首先将概率降序排序得到 `[0.4, 0.3, 0.2, 0.1]`，计算前缀累积和为 `[0.4, 0.7, 0.9, 1.0]`。由于累积和 `0.7 <= 0.8` 但 `0.9 > 0.8`，因此保留概率值 `0.4` 和 `0.3`，丢弃 `0.2` 和 `0.1`。保留的概率之和为 `0.7`，重归一化后得到 `0.4/0.7 ≈ 0.5714` 和 `0.3/0.7 ≈ 0.4286`，写回原始索引位置后结果为 `[0.5714, 0.0, 0.4286, 0.0]`。

**第 2 行**（`top_p = 0.9`）：

将概率降序排序得到 `[0.3, 0.3, 0.3, 0.1]`，前缀累积和为 `[0.3, 0.6, 0.9, 1.0]`。前三个 `0.3` 的累积和正好等于 `0.9`，因此保留这三项，丢弃 `0.1`。保留的概率之和为 `0.9`，重归一化后每个保留的概率变为 `0.3/0.9 ≈ 0.3333`，写回原始索引位置后结果为 `[0.3333, 0.3333, 0.0, 0.3333]`。

## PyTorch 参考实现

```python
def baseline(probs, top_p, renorm_probs, batch_size, num_classes):
    """
    PyTorch 参考实现：Top-p 重归一化
    
    参数说明：
    * probs: 输入张量（float32），shape (batch_size, num_classes)，行优先连续存储，只读
    * top_p: 输入张量（float32），shape (batch_size,)，连续存储，每个样本的 top-p 阈值
    * renorm_probs: 输出张量（float32），shape (batch_size, num_classes)，行优先连续存储，需写入结果
    * batch_size: 批次大小（int64）
    * num_classes: 类别数量（int64）
    """
    B, C = probs.shape
    p = top_p.reshape(B, 1).to(dtype=probs.dtype, device=probs.device)
    
    # 每行降序排序
    sorted_probs, sorted_idx = torch.sort(probs, dim=-1, descending=True)
    
    # 累积和
    cumsum = torch.cumsum(sorted_probs, dim=-1)
    
    # nucleus mask: cumulative <= top_p
    mask = cumsum <= p
    
    # 保证每行至少保留 1 个
    mask[:, 0] = True
    
    # 过滤：不在 top-p 里的置零
    filtered_sorted = sorted_probs * mask.to(sorted_probs.dtype)
    
    # 计算每行归一化系数
    denom = filtered_sorted.sum(dim=-1, keepdim=True)
    
    # 避免除 0
    renorm_sorted = torch.where(
        denom > 0,
        filtered_sorted / denom,
        torch.zeros_like(filtered_sorted)
    )
    
    # scatter 回原顺序
    renorm_probs.zero_()
    renorm_probs.scatter_(dim=-1, index=sorted_idx, src=renorm_sorted)
```
