# Iou Loss

原题 https://xpuoj.com/p/109

## 题目描述

你需要实现一个 `IoU Loss` 算子：

> **loss = 1 - (intersection + smooth) / (union + smooth)**

给定输入张量 `logits`、`target`（shape 均为 $(N, C, H, W)$）以及一个标量 `smooth`，你需要先对 `logits` 逐元素做 `sigmoid` 得到概率张量 `prob`，然后计算 Intersection over Union，对应的损失定义为 `1 - IoU`。

定义：

$$
prob = \sigma(logits)
$$

$$
intersection = \sum prob \cdot target
$$

$$
union = \sum prob + \sum target - intersection
$$

则最终输出为：

$$
loss = 1 - \frac{intersection + smooth}{union + smooth}
$$

其中所有求和都在整个张量范围 $(N, C, H, W)$ 上进行。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成逐元素 sigmoid、全局求和以及最终标量损失计算。

如何提交代码详见[评测指南](/d/2)。

## 计算过程说明

先计算概率：

```text
prob = sigmoid(logits) = [[[[0.5, 0.5]]]]
```

因此：

```text
intersection = 0.5 * 1.0 + 0.5 * 0.0 = 0.5
sum(prob) = 1.0
sum(target) = 1.0
union = 1.0 + 1.0 - 0.5 = 1.5
```

代入公式：

$$
loss = 1 - \frac{0.5 + 1.0}{1.5 + 1.0} = 1 - 0.6 = 0.4
$$

## PyTorch 参考实现

```python
def baseline(logits, target, loss, smooth, N, C, H, W):
    prob = torch.sigmoid(logits)
    intersection = torch.sum(prob * target)
    union = torch.sum(prob) + torch.sum(target) - intersection
    loss.copy_(1.0 - (intersection + smooth) / (union + smooth))
```
