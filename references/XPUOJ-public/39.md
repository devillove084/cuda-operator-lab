# TRTLLM Batch Decode with KV Cache

原题 https://xpuoj.com/p/39

## 题目描述

你需要实现 TRT-LLM 风格的 batch decode attention，并且历史 key/value 不是连续存放，而是以 paged KV cache 的方式离散存储。对 batch 中的每个请求，输入只提供“当前时刻的一个 query 向量组”，输出则是这个 query 对该请求全部历史 token 做一次注意力之后得到的结果。

设输入 query 为

$$
Q \in \mathbb{R}^{B \times H_q \times D},
$$

其中：

$$
B = \mathrm{batch\_size}, \qquad
H_q = \mathrm{num\_qo\_heads}, \qquad
D = \mathrm{head\_dim}.
$$

因此第 `b` 个请求当前步的 query 可以记为

$$
q_b \in \mathbb{R}^{H_q \times D}.
$$

要特别注意，本题是 decode 场景，所以每个请求在当前步只有一个 query 位置，而不是一整段 query 序列。也就是说，本题不是

$$
\text{many-query-to-history attention},
$$

而是

$$
\text{one-query-step-to-history attention}.
$$

对第 `b` 个请求，`seq_lens[b]` 给出它在当前时刻可见的历史长度：

$$
L_b = \mathrm{seq\_lens}[b].
$$

KV cache 的页大小为

$$
P = \mathrm{page\_size},
$$

于是该请求需要访问的逻辑页数为

$$
N_b = \left\lceil \frac{L_b}{P} \right\rceil.
$$

在 baseline 中，分页缓存张量 `kv_cache` 的 shape 为

$$
\mathrm{kv\_cache}
\in
\mathbb{R}^{\mathrm{total\_pages} \times 2 \times H_{kv} \times P \times D},
$$

其中

$$
H_{kv} = \mathrm{num\_kv\_heads}.
$$

第二维大小为 `2`，其语义是：

$$
\mathrm{kv\_cache}[p,0] \text{ 是第 } p \text{ 个物理页中的 key block},
$$

$$
\mathrm{kv\_cache}[p,1] \text{ 是第 } p \text{ 个物理页中的 value block}.
$$

`block_tables[b,p]` 给出了第 `b` 个请求第 `p` 个逻辑页对应的物理页编号。记这个映射为

$$
\pi_b(p) = \mathrm{block\_tables}[b,p], \qquad 0 \le p < N_b.
$$

对于该请求历史中的任意时间步 `t`，它所在的逻辑页号和页内偏移分别是

$$
p(t) = \left\lfloor \frac{t}{P} \right\rfloor,
\qquad
o(t) = t \bmod P.
$$

于是连续历史中的 key/value 可以写成

$$
K_b[t,h,:]
=
\mathrm{kv\_cache}[\pi_b(p(t)), 0, h, o(t), :],
$$

$$
V_b[t,h,:]
=
\mathrm{kv\_cache}[\pi_b(p(t)), 1, h, o(t), :],
$$

其中

$$
0 \le t < L_b,\qquad 0 \le h < H_{kv}.
$$

这只是数学上的直接定义。baseline 的实际写法是等价的“先逐页取出，再拼接，再截断”：

1. 对 `p_idx = 0, 1, ..., N_b-1`，取出物理页 `block_idx = block_tables[b, p_idx]`；
2. 令 `block = kv_cache[block_idx]`；
3. `block[0]` 和 `block[1]` 分别是当前页的 key/value，shape 都是 `(H_{kv}, P, D)`；
4. baseline 对它们做 `permute(1, 0, 2)`，得到

$$
k\_block,\ v\_block \in \mathbb{R}^{P \times H_{kv} \times D},
$$

使时间维排在最前面；
5. 把各页沿时间维拼接，得到

$$
k\_full,\ v\_full \in \mathbb{R}^{(N_b P) \times H_{kv} \times D};
$$

6. 再截断到真实历史长度 `L_b`：

$$
k\_full = k\_full[:L_b], \qquad v\_full = v\_full[:L_b].
$$

这一步之后，`k_full[t,h,:]` 与上面定义的 `K_b[t,h,:]` 完全一致，`v_full` 同理。

接下来，baseline 为了做矩阵乘法，又把它们转回“按 head 分组”的形式：

$$
k\_{\mathrm{curr}} = \mathrm{Permute}(k\_full)
\in
\mathbb{R}^{1 \times H_{kv} \times L_b \times D},
$$

$$
v\_{\mathrm{curr}} = \mathrm{Permute}(v\_full)
\in
\mathbb{R}^{1 \times H_{kv} \times L_b \times D}.
$$

这里最前面的维度 `1` 只是为了配合 `torch.matmul` 的 batch 维。

同样地，当前请求的 query `q_b` 会被改写成

$$
q\_{\mathrm{curr}}
\in
\mathbb{R}^{1 \times H_q \times 1 \times D}.
$$

这里中间那个长度为 `1` 的维度，正表示“当前只有一个 query 时间位置”。

如果 `H_q = H_{kv}`，那么每个 query head 直接和同编号的 KV head 做注意力即可。  
如果 `H_q \ne H_{kv}`，baseline 采用 GQA/MQA 语义，把每个 KV head 沿 head 维重复：

$$
g = \frac{H_q}{H_{kv}}.
$$

经过 `repeat_interleave(g, dim=1)` 后，有

$$
\widetilde{k}_{\mathrm{curr}},
\widetilde{v}_{\mathrm{curr}}
\in
\mathbb{R}^{1 \times H_q \times L_b \times D}.
$$

此时第 `h` 个 query head 实际使用的是第

$$
\phi(h) = \left\lfloor \frac{h}{g} \right\rfloor
$$

个 KV head 的历史信息。换句话说，

$$
\widetilde{K}_b[h,t,:] = K_b[t,\phi(h),:],
\qquad
\widetilde{V}_b[h,t,:] = V_b[t,\phi(h),:].
$$

随后开始真正的 decode attention 计算。baseline 先把 `q_curr`、`k_curr` 转成 `float32`，再计算分数矩阵：

$$
S_b[h,0,t]
=
\frac{\left\langle q_b[h,:], \widetilde{K}_b[h,t,:] \right\rangle}{\sqrt{D}},
\qquad
0 \le t < L_b.
$$

这里结果 shape 是

$$
S_b \in \mathbb{R}^{H_q \times 1 \times L_b},
$$

表示每个 query head 都只有一个 query 位置，但要对全部 `L_b` 个历史位置打分。

然后在最后一维，也就是历史长度维度上做 softmax：

$$
A_b[h,0,t]
=
\frac{\exp(S_b[h,0,t])}{\sum_{j=0}^{L_b-1} \exp(S_b[h,0,j])}.
$$

最终输出是对历史 value 的加权求和：

$$
O_b[h,0,:]
=
\sum_{t=0}^{L_b-1} A_b[h,0,t] \, \widetilde{V}_b[h,t,:].
$$

去掉那个长度为 `1` 的 query 维之后，就得到第 `b` 个请求的输出

$$
o_b \in \mathbb{R}^{H_q \times D}.
$$

把所有请求的结果按 batch 维堆叠，就得到最终输出

$$
\mathrm{out} \in \mathbb{R}^{B \times H_q \times D}.
$$

因此，本题不是简单地“从 cache 里读点数据然后做 attention”，而是要求你完整实现下面这条链路：

$$
\text{single-step query}
\to
\text{block table lookup}
\to
\text{paged KV reconstruction}
\to
\text{GQA head expansion}
\to
\text{softmax over all history}
\to
\text{decode output}.
$$

实现时最容易出错的地方有五个：

- `seq_lens[b]` 决定真实历史长度，拼接出的页内容必须截断到 `L_b`；
- `block_tables[b,p]` 决定逻辑页到物理页的映射，不能把页号当成连续时间下标直接用；
- `block[0]` / `block[1]` 分别对应 key 和 value，二者不能混；
- baseline 的 head 扩展方式是 `repeat_interleave`，不是任意广播；
- softmax 是在历史维 `L_b` 上做，而不是在 head 维或特征维上做。

## 参数说明

* `query_ptr`：输入 query 指针（bfloat16），shape $(\text{batch_size}, \text{num_qo_heads}, \text{head_dim})$，行优先连续存储，只读
* `kv_cache_ptr`：KV 缓存指针（bfloat16），shape $(\text{total_pages}, 2, \text{num_kv_heads}, \text{page_size}, \text{head_dim})$，行优先连续存储，只读
* `block_tables_ptr`：页表指针（int32），shape $(\text{batch_size}, \text{max_num_pages})$，存储每个序列使用的 page id，GPU 内存
* `seq_lens_ptr`：KV 序列长度指针（int32），shape $(\text{batch_size},)$，存储每个序列的 kv 长度（包含当前 step），GPU 内存
* `out_ptr`：输出指针（bfloat16），shape $(\text{batch_size}, \text{num_qo_heads}, \text{head_dim})$，行优先连续存储，需写入计算结果
* `batch_size`：batch 大小（int64）
* `num_qo_heads`：query/output 注意力头数（int64）
* `num_kv_heads`：KV 注意力头数（int64）
* `head_dim`：每个头的维度（int64）
* `page_size`：KV 缓存页大小（int64）
* `max_num_pages`：每个序列最大页数（int64）
* `max_seq_len`：最大序列长度（int64）

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成带 KV 缓存的解码阶段注意力计算

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 trtllm batch decode with kv cache

    Args:
        query: BF16 tensor of shape (batch_size, num_qo_heads, head_dim) - query
        kv_cache: BF16 tensor of shape (total_pages, 2, num_kv_heads, page_size, head_dim) - key/value cache
        block_tables: int32 tensor of shape (batch_size, max_num_pages) - block tables
        seq_lens: int32 tensor of shape (batch_size,) - sequence lengths
        out: BF16 tensor of shape (batch_size, num_qo_heads, head_dim) - output (will be modified inplace)
        batch_size: int - batch size
        num_qo_heads: int - number of query/output heads
        num_kv_heads: int - number of key/value heads
        head_dim: int - head dimension
        page_size: int - page size
        max_num_pages: int - max pages per sequence
        max_seq_len: int - max sequence length

    Returns:
        List containing modified out tensor
    """
    query, kv_cache, block_tables, seq_lens, out, batch_size, num_qo_heads, num_kv_heads, head_dim, page_size, max_num_pages, max_seq_len = inputs

    assert torch.is_tensor(query) and torch.is_tensor(kv_cache) and torch.is_tensor(block_tables) and torch.is_tensor(seq_lens) and torch.is_tensor(out)
    assert isinstance(batch_size, int) and isinstance(num_qo_heads, int) and isinstance(num_kv_heads, int) and isinstance(head_dim, int) and isinstance(page_size, int) and isinstance(max_num_pages, int) and isinstance(max_seq_len, int)
    assert query.shape == (batch_size, num_qo_heads, head_dim)
    assert kv_cache.shape[1:] == (2, num_kv_heads, page_size, head_dim)
    assert block_tables.shape == (batch_size, max_num_pages)
    assert seq_lens.shape == (batch_size,)
    assert out.shape == query.shape

    out_list = []
    scale = 1.0 / math.sqrt(head_dim)

    for i in range(batch_size):
        cur_seq_len = int(seq_lens[i].item())
        cur_block_table = block_tables[i]

        num_pages = (cur_seq_len + page_size - 1) // page_size
        keys = []
        values = []

        for p_idx in range(num_pages):
            block_idx = int(cur_block_table[p_idx].item())
            block = kv_cache[block_idx]
            k_block = block[0].permute(1, 0, 2)
            v_block = block[1].permute(1, 0, 2)
            keys.append(k_block)
            values.append(v_block)

        k_full = torch.cat(keys, dim=0)[:cur_seq_len]
        v_full = torch.cat(values, dim=0)[:cur_seq_len]

        k_curr = k_full.permute(1, 0, 2).unsqueeze(0)
        v_curr = v_full.permute(1, 0, 2).unsqueeze(0)
        q_curr = query[i].unsqueeze(0).unsqueeze(2)

        if num_qo_heads != num_kv_heads:
            num_rep = num_qo_heads // num_kv_heads
            k_curr = k_curr.repeat_interleave(num_rep, dim=1)
            v_curr = v_curr.repeat_interleave(num_rep, dim=1)

        scores = torch.matmul(q_curr.to(torch.float32), k_curr.to(torch.float32).transpose(-2, -1)) * scale
        attn = torch.softmax(scores, dim=-1)
        out_curr = torch.matmul(attn, v_curr.to(torch.float32)).to(q_curr.dtype)
        out_list.append(out_curr.squeeze(0).squeeze(1))

    result = torch.stack(out_list, dim=0)
    out.copy_(result.to(out.dtype))
    return list(inputs)```
