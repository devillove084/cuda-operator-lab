# Triplet Loss

原题 https://xpuoj.com/p/106

## 题目描述

你需要实现一个 `Triplet Loss` 算子：

> **loss = mean(max(0, dist(anchor, positive) - dist(anchor, negative) + margin))**

给定输入矩阵 `anchor`、`positive`、`negative`（shape 均为 $(N, D)$）以及一个标量 `margin`，你需要先分别计算 `anchor` 与 `positive` 的逐行欧氏距离，以及 `anchor` 与 `negative` 的逐行欧氏距离，然后根据 triplet loss 公式计算每一行的损失，最后对所有行取平均，得到一个标量输出 `loss`。

对于任意行 $i$，定义：

$$
d^{pos}_i = \sqrt{\sum_{j=0}^{D-1}(anchor_{i,j} - positive_{i,j})^2}
$$

$$
d^{neg}_i = \sqrt{\sum_{j=0}^{D-1}(anchor_{i,j} - negative_{i,j})^2}
$$

则该行的 triplet loss 为：

$$
l_i = \max(0, d^{pos}_i - d^{neg}_i + margin)
$$

最终输出为：

$$
loss = \frac{1}{N} \sum_{i=0}^{N-1} l_i
$$

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成逐行距离计算、逐行损失计算以及最终均值归约。

如何提交代码详见[评测指南](/d/2)。

## 计算过程说明

先计算逐行距离：

* 第 0 行：
  * $d^{pos}_0 = \sqrt{(0.0 - 1.0)^2 + (0.0 - 0.0)^2} = 1.0$
  * $d^{neg}_0 = \sqrt{(0.0 - 0.5)^2 + (0.0 - 0.0)^2} = 0.5$
  * $l_0 = \max(0, 1.0 - 0.5 + 1.0) = 1.5$
* 第 1 行：
  * $d^{pos}_1 = \sqrt{(1.0 - 2.0)^2 + (1.0 - 1.0)^2} = 1.0$
  * $d^{neg}_1 = \sqrt{(1.0 - 1.0)^2 + (1.0 - 3.0)^2} = 2.0$
  * $l_1 = \max(0, 1.0 - 2.0 + 1.0) = 0.0$

最终取平均：

$$
loss = (1.5 + 0.0) / 2 = 0.75
$$

## PyTorch 参考实现

```python
def baseline(anchor, positive, negative, loss, margin, N, D):
    dist_pos = torch.sqrt(torch.sum((anchor - positive) ** 2, dim=-1))
    dist_neg = torch.sqrt(torch.sum((anchor - negative) ** 2, dim=-1))
    pointwise = torch.clamp(dist_pos - dist_neg + margin, min=0.0)
    loss.copy_(pointwise.mean())
```
