# Index First Axis

原题 https://xpuoj.com/p/23

## 题目描述

你需要实现一个沿第 0 维的 gather 算子：

> **output = input[indices]**

给定输入张量 `input` 和一维索引张量 `indices`，你需要按照 `indices` 指定的顺序，从 `input` 的第 0 维取出若干行，写入输出张量 `output`。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成沿第 0 维的 gather 计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* input,
    const int64_t* indices,
    __nv_bfloat16* output,
    int64_t N,
    int64_t M,
    int64_t H
);
```

### 参数说明

* `input`：输入指针（bfloat16），shape `(N, H)`，行优先连续存储，只读
* `indices`：输入指针（int64），shape `(M,)`，只读
* `output`：输出指针（bfloat16），shape `(M, H)`，行优先连续存储，需写入结果
* `N`：输入第 0 维大小
* `M`：索引长度
* `H`：每行元素数

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成沿第 0 维的 gather

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `input`：bfloat16 tensor，shape `(N, H)`，行优先连续存储
* `indices`：int64 tensor，shape `(M,)`
* `output`：bfloat16 tensor，shape `(M, H)`，作为输出缓冲区

* `M`：int64 标量
* `H`：int64 标量

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，满足：

```text
output[i, j] = input[indices[i], j]
```
