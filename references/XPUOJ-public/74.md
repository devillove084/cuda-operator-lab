# Syr2k TF32 F32

原题 https://xpuoj.com/p/74

## 题目描述

你需要实现一个对称秩-2k 更新算子：

> **D = alpha * (A @ B.T + B @ A.T) + beta * C**

给定输入矩阵 $A$（shape 为 $(N, K)$）、$B$（shape 为 $(N, K)$）、$C$（shape 为 $(N, N)$）以及两个标量 `alpha` 和 `beta`，计算输出矩阵 $D$（shape 为 $(N, N)$）。具体计算方式为：

$$
D_{i,j} = \alpha \cdot \left( \sum_{k=0}^{K-1} A_{i,k} \cdot B_{j,k} + \sum_{k=0}^{K-1} B_{i,k} \cdot A_{j,k} \right) + \beta \cdot C_{i,j}
$$

其中 $i, j \in [0, N)$。

该运算是 SYR2K（symmetric rank-2k update）的一个常见形式。输出矩阵在数学上应当是对称的，但评测会直接比较完整输出矩阵的数值正确性。

本题名称中的 TF32 表示该算子常见于 Tensor Core / TF32 场景，但评测只检查最终 `float32` 结果是否正确，不要求必须使用特定硬件特性。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const float* A,
    const float* B,
    const float* C,
    float* D,
    float alpha,
    float beta,
    int64_t N,
    int64_t K
```

### 参数说明

* `A`：输入指针（float32），shape $(N, K)$，行优先连续存储，只读

* `beta`：输入标量（float32）
* `N`：矩阵 `A`、`B` 的行数，也是 `C`、`D` 的边长（int64）
* `K`：矩阵 `A`、`B` 的列数（int64）

`run_kernel` 内部需要完成以下工作：

* 根据矩阵尺寸计算合适的 launch 配置
* launch 你实现的 CUDA `__global__` kernel，完成 $D = alpha * (A @ B^T + B @ A^T) + beta * C$

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `A`：float32 tensor，shape $(N, K)$，行优先连续存储
* `B`：float32 tensor，shape $(N, K)$，行优先连续存储
* `C`：float32 tensor，shape $(N, N)$，行优先连续存储
* `D`：float32 tensor，shape $(N, N)$，作为输出缓冲区，初始值未定义
* `alpha`：float32 标量
* `beta`：float32 标量
* `N`：int64 标量，表示 `A`、`B` 的行数，也是 `C`、`D` 的边长
* `K`：int64 标量，表示 `A`、`B` 的列数

## 输出格式

你需要将计算结果写入 `D` 指向的缓冲区，得到一个 shape 为 $(N, N)$ 的 float32 矩阵，满足：

$$
D = \alpha \cdot (A @ B^T + B @ A^T) + \beta \cdot C
$$

其中 `B.T` 表示矩阵 `B` 的转置，`A.T` 表示矩阵 `A` 的转置。

## 计算过程说明

先计算：

```text
A @ B.T =
[
  [17, 23],
  [39, 53]
]

B @ A.T =
[
  [17, 39],
  [23, 53]
]
```

所以：

```text
A @ B.T + B @ A.T =
[
  [34, 62],
  [62, 106]
]
```

再代入 `alpha = 0.5` 和 `beta = 2.0`：

```text
0.5 * (A @ B.T + B @ A.T) =
[
  [17.0, 31.0],
  [31.0, 53.0]
]

2.0 * C =
[
  [2.0, 0.0],
  [0.0, 2.0]
]
```

最终得到：

```text
D =
[
  [19.0, 31.0],
  [31.0, 55.0]
]
```

## 数据范围与提示

## 数据范围

* `A`、`B`、`C`、`D` 的数据类型均为 `torch.float32`
* `A.shape == (N, K)`
* `B.shape == (N, K)`
* `C.shape == (N, N)`
* `D.shape == (N, N)`
* 所有矩阵均为连续存储（contiguous）
* $1 \le N \le 4608$
* $1 \le K \le 2049$

## 正确性要求

* 必须正确实现 $D = alpha * (A @ B^T + B @ A^T) + beta * C$
* 必须将结果写入 `D`
* 不允许修改输入 `A`、`B` 和 `C`

## 提示

* 虽然结果在数学上是对称矩阵，但评测会直接比较完整输出，不能只写半边三角区域
* 评测数据包含不同的 `alpha`、`beta` 组合，不能假设 `beta = 0`
* 评测数据包含奇数维度和长宽不均衡的 `K`，不能假设尺寸是 tile size 的整数倍

## PyTorch 参考实现

```python
def baseline(A, B, C, D, alpha, beta, N, K):
    """
    PyTorch 参考实现：D = alpha * (A @ B.T + B @ A.T) + beta * C

    参数说明：
    * A: 输入张量（float32），shape (N, K)，行优先连续存储，只读
    * B: 输入张量（float32），shape (N, K)，行优先连续存储，只读
    * C: 输入张量（float32），shape (N, N)，行优先连续存储，只读
    * D: 输出张量（float32），shape (N, N)，行优先连续存储，需写入结果
    * alpha: float32 标量
    * beta: float32 标量
    * N: 方阵边长（int64）
    * K: A、B 的列数（int64）
    """
    D_ref = alpha * (torch.matmul(A, B.T) + torch.matmul(B, A.T)) + beta * C
    D.copy_(D_ref)
```
