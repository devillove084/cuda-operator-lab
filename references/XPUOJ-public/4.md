# Top k Renorm Probs

原题 https://xpuoj.com/p/4

## 题目描述

你需要实现一个 Top-k 重归一化算子。该算子对概率分布的每一行进行处理，保留每行中概率值最大的前 $k$ 个元素，将其余元素置零，然后对保留下来的概率进行重归一化，使其总和为 1。

具体来说，对于每一行，算法流程如下：

1. 找出该行的 top-$k$ 个最大概率值，记为集合 $\mathcal{K}$
2. 将不属于 top-$k$ 的概率值置零
3. 对保留下来的概率值重新归一化，使其总和为 1
4. 结果保持原始索引顺序，不进行排序

形式化描述：设该行原始概率为 $\mathbf{p} = (p_1, p_2, \ldots, p_N)$，令 $\mathcal{K} = \{i \mid p_i \text{ 属于前 } k \text{ 大值}\}$，则输出为：

$$
\hat{p}_i = \begin{cases}
\displaystyle \frac{p_i}{\sum_{j \in \mathcal{K}} p_j} & \text{若 } i \in \mathcal{K} \\[8pt]
0 & \text{否则}
\end{cases}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述 Top-k 重归一化操作。

## 计算过程说明

**第 1 行**（`top_k = 2`）：

该行的概率值为 `[0.1, 0.2, 0.4, 0.3]`，其中最大的两个值是 `0.4`（索引 2）和 `0.3`（索引 3）。将其他位置置零后得到 `[0.0, 0.0, 0.4, 0.3]`，保留的概率之和为 `0.7`，重归一化后得到 `[0.0, 0.0, 0.4/0.7 ≈ 0.5714, 0.3/0.7 ≈ 0.4286]`。

**第 2 行**（`top_k = 3`）：

该行的概率值均为 `0.25`，最大的三个值是前三个 `0.25`（索引 0、1、2）。将索引 3 置零后得到 `[0.25, 0.25, 0.25, 0.0]`，保留的概率之和为 `0.75`，重归一化后每个保留的概率变为 `0.25/0.75 ≈ 0.3333`，结果为 `[0.3333, 0.3333, 0.3333, 0.0]`。

## PyTorch 参考实现

```python
def baseline(probs, top_k, renorm_probs, batch_size, num_classes):
    """
    PyTorch 参考实现：Top-k 重归一化
    
    参数说明：
    * probs: 输入张量（float32），shape (batch_size, num_classes)，行优先连续存储，只读
    * top_k: 输入张量（int32），shape (batch_size,)，连续存储，每个样本的 top-k 值
    * renorm_probs: 输出张量（float32），shape (batch_size, num_classes)，行优先连续存储，需写入结果
    * batch_size: 批次大小（int64）
    * num_classes: 类别数量（int64）
    """
    B, C = probs.shape
    k = top_k.reshape(B, 1).to(device=probs.device)
    k = k.clamp(min=0, max=C).to(dtype=torch.long)
    
    Kmax = int(k.max().item())
    renorm_probs.zero_()
    if Kmax == 0:
        return
    
    # 取每行 top-Kmax
    topv, topi = torch.topk(probs, k=Kmax, dim=-1, largest=True, sorted=True)
    
    # 构造 mask：只保留前 k[i] 个
    arange = torch.arange(Kmax, device=probs.device).view(1, Kmax)
    mask = arange < k
    
    # 过滤并计算归一化分母
    topv_masked = topv * mask.to(topv.dtype)
    denom = topv_masked.sum(dim=-1, keepdim=True)
    
    # 重归一化
    topv_renorm = torch.where(
        denom > 0,
        topv_masked / denom,
        torch.zeros_like(topv_masked)
    )
    
    # scatter 回原位置
    renorm_probs.scatter_(dim=-1, index=topi, src=topv_renorm)
```
