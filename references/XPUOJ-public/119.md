# Cutlass W4A8 MoE MM

原题 https://xpuoj.com/p/119

## 题目描述

你需要实现 W4A8 的分专家 GEMM。输入激活 `a` 以 `float8_e4m3fn` 存储，专家权重 `b` 则以“每个 `int8` 打包两个 `int4` 权重”的形式给出。你需要先把激活和权重分别解量化到浮点，再对每个 expert 独立完成矩阵乘法，最后把每个 expert 的结果写回全局输出矩阵 `out` 中对应的行区间。

设总激活矩阵满足：

$$
A \in \mathbb{R}^{M_{\text{total}} \times K}
$$

其中 $M_{\text{total}}$ 是所有 token 总数，$K$ 是输入维度。它在输入中以 `float8_e4m3fn` 存储，并带有全局缩放因子 `a_scales`。baseline 中只有一个标量缩放，因此激活解量化为：

$$
A^{\text{fp32}} = \operatorname{decode\_fp8}(A) \cdot s_a
$$

其中

$$
s_a = \text{a\_scales}[0]
$$

对第 $e$ 个 expert，`problem_sizes[e] = [N_e, M_e, K_e]` 给出了该 expert 的输出维度、负责的 token 数和输入维度；`experts_offsets[e]` 给出了它在全局输出中的起始行偏移，记为：

$$
o_e = \text{experts\_offsets}[e]
$$

因此第 $e$ 个 expert 实际处理的激活子块为：

$$
A_e = A^{\text{fp32}}[o_e : o_e + M_e,\; :K_e] \in \mathbb{R}^{M_e \times K_e}
$$

权重 `b` 的 shape 为 $(E, N, K/2)$，因为每个 `int8` 打包了两个 `int4`。对某个 expert 的某个权重字节 $p$，记低四位和高四位分别为：

$$
\ell = p \;\&\; 0x0F, \quad h = (p \gg 4) \;\&\; 0x0F
$$

它们表示两个 4-bit 有符号整数的补码形式。baseline 会把它们恢复到区间 $[-8, 7]$：

$$
\operatorname{int4}(u) =
\begin{cases}
u, & u \le 7 \\
u - 16, & u > 7
\end{cases}
$$

从而解包后的整型权重矩阵为：

$$
W^{\text{int4}}_e \in \mathbb{R}^{N_e \times K_e}
$$

接下来还要结合 `b_scales` 做分块解量化。设 `chunk_size = C`，则输入维会被切成

$$
K_e / C
$$

个连续块。对第 $g$ 个块，对应的列范围为：

$$
[gC,\; (g+1)C)
$$

baseline 会为每个 expert、每个块、每个输出通道取一个缩放因子。记第 $e$ 个 expert 在第 $g$ 块、输出通道 $n$ 上的缩放为 $s_{e,g,n}$，则解量化后的权重为：

$$
W^{\text{fp32}}_e[n, k] = W^{\text{int4}}_e[n, k] \cdot s_{e,g,n},
\quad g = \left\lfloor \frac{k}{C} \right\rfloor
$$

于是，对第 $e$ 个 expert 的矩阵乘法结果为：

$$
D_e = A_e (W^{\text{fp32}}_e)^T \in \mathbb{R}^{M_e \times N_e}
$$

按元素展开后：

$$
D_e[i,n] = \sum_{k=0}^{K_e-1} A_e[i,k] \, W^{\text{fp32}}_e[n,k]
$$

最后把结果写回全局输出矩阵 `out` 的对应行区间和前 `N_e` 列：

$$
\text{out}[o_e : o_e + M_e,\; :N_e] = D_e
$$

对于没有被某个 expert 覆盖到的输出位置，baseline 保持为零。

因此，本题需要同时正确处理三件事：`float8` 激活解量化、打包 `int4` 权重的解包与分块 scale 解量化、以及按照 `experts_offsets` 和 `problem_sizes` 对各个 expert 分块做独立 GEMM 并回填全局输出。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## PyTorch 参考实现

```python
def baseline(*inputs):
    a, b, a_scales, b_scales, experts_offsets, problem_sizes, a_strides, b_strides, d_strides, s_strides, out, M_total, K, N, E, chunk_size = inputs
    # Inline reference implementation (no direct torch_ref import).
    # Matches torch_ref.Model.forward for our generated shapes.
    assert torch.is_tensor(a) and torch.is_tensor(b)
    assert torch.is_tensor(a_scales) and torch.is_tensor(b_scales)
    assert torch.is_tensor(experts_offsets) and torch.is_tensor(problem_sizes)
    assert torch.is_tensor(out)

    M_total_i = int(M_total)
    K_i = int(K)
    E_i = int(E)
    chunk = int(chunk_size)

    # Determine N from problem_sizes (N, M, K) per expert.
    if problem_sizes.numel() == 0:
        out.zero_()
        return [a, b, a_scales, b_scales, experts_offsets, problem_sizes, a_strides, b_strides, d_strides, s_strides, out, M_total, K, N, E, chunk_size]

    # Dequantize activations
    a_dequant = a.to(torch.float32) * float(a_scales.item())

    # Unpack/dequant weights per expert and do grouped GEMM
    d_ref = torch.zeros(M_total_i, int(problem_sizes[0, 0].item()), dtype=torch.bfloat16, device=a.device)

    alignment = 4 if (K_i % 512 == 0) else 1
    for expert_id in range(int(problem_sizes.shape[0])):
        N_e = int(problem_sizes[expert_id, 0].item())
        M_e = int(problem_sizes[expert_id, 1].item())
        K_e = int(problem_sizes[expert_id, 2].item())
        if M_e == 0:
            continue

        offset = int(experts_offsets[expert_id].item()) if expert_id < experts_offsets.numel() else 0
        if offset >= M_total_i:
            continue

        a_expert = a_dequant[offset:min(offset + M_e, M_total_i), :K_e]  # [M_e, K_e]

        # b is packed int4 into int8: shape [E, N, K/2]
        b_packed = b[expert_id, :N_e, :K_e // 2]  # [N_e, K_e/2]
        low_bits = (b_packed & 0x0F).to(torch.int8)
        high_bits = ((b_packed >> 4) & 0x0F).to(torch.int8)
        b_unpacked = torch.stack([low_bits, high_bits], dim=2).reshape(N_e, K_e)
        b_unpacked = torch.where(b_unpacked > 7, b_unpacked - 16, b_unpacked).to(torch.float32)

        K_blocks = K_e // chunk
        b_dequant = torch.zeros_like(b_unpacked, dtype=torch.float32)
        for k_block in range(K_blocks):
            k_start = k_block * chunk
            k_end = k_start + chunk
            k_block_group = k_block // alignment
            k_block_in_group = k_block % alignment

            # b_scales may be [E, K_blocks, N] (our generated data),
            # or [E, K_blocks//alignment, N*alignment] (torch_ref general case).
            if b_scales.shape[-1] == N_e and b_scales.shape[1] >= (k_block_group + 1):
                scales = b_scales[expert_id, k_block_group, :N_e].to(torch.float32)
            else:
                scale_row = b_scales[expert_id, k_block_group, :]
                scales = scale_row[k_block_in_group::alignment][:N_e].to(torch.float32)

            b_dequant[:, k_start:k_end] = b_unpacked[:, k_start:k_end] * scales.unsqueeze(1)

        result = torch.matmul(a_expert, b_dequant.t())  # [M_e, N_e]
        d_ref[offset:min(offset + M_e, M_total_i), :N_e] = result.to(torch.bfloat16)

    out.copy_(d_ref)
    return [a, b, a_scales, b_scales, experts_offsets, problem_sizes, a_strides, b_strides, d_strides, s_strides, out, M_total, K, N, E, chunk_size]
```
