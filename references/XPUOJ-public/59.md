# Symm F32

原题 https://xpuoj.com/p/59

## 题目描述

你需要实现一个单精度的对称矩阵乘法算子：

> **output = alpha * A @ B + beta * C**

给定输入矩阵 `A`、`B`、`C`，其中：

* `A` 的 shape 为 `(M, M)`，并保证是对称矩阵
* `B` 的 shape 为 `(M, N)`
* `C` 的 shape 为 `(M, N)`
* `output` 的 shape 为 `(M, N)`

具体计算方式为：

$$
output_{i,j} = \alpha \cdot \sum_{k=0}^{M-1} A_{i,k} \cdot B_{k,j} + \beta \cdot C_{i,j}
$$

其中 $i \in [0, M)$，$j \in [0, N)$。

本题对应 BLAS 中的 `symm` 计算形式。虽然 `A` 是对称矩阵，但评测只关心最终结果是否正确，参考语义可以直接理解为：

$$
output = \alpha \cdot (A @ B) + \beta \cdot C
$$

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](/d/2)。

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，得到一个 shape 为 `(M, N)` 的 float32 矩阵，满足：

$$
output_{i,j} = \alpha \cdot \sum_{k=0}^{M-1} A_{i,k} \cdot B_{k,j} + \beta \cdot C_{i,j}
$$

即：

$$
output = \alpha \cdot (A @ B) + \beta \cdot C
$$

## 数据范围与提示

## 数据范围

* `A`、`B`、`C`、`output` 的数据类型均为 `torch.float32`
* `A` 的 shape 为 `(M, M)`
* `B`、`C`、`output` 的 shape 为 `(M, N)`
* 所有矩阵均为连续存储（contiguous）

## 正确性要求

* 必须将结果正确写入 `output`
* 不允许修改输入矩阵 `A`、`B`、`C`
* 必须正确处理系数 `alpha`
* 必须正确处理系数 `beta`

## 提示

* 本题中的 `A` 是对称矩阵，但参考实现仍按普通矩阵乘法 `A @ B` 计算
* 当 `beta = 0` 时，`C` 仍会传入，但结果中不应包含它的贡献
* 评测使用 `alpha * torch.matmul(A, B) + beta * C` 作为参考实现

## PyTorch 参考实现

```python
def baseline(A, B, C, output, alpha, beta, M, N):
    """
    PyTorch 参考实现：output = alpha * (A @ B) + beta * C

    参数说明：
    * A: 输入张量（float32），shape (M, M)，保证为对称矩阵
    * B: 输入张量（float32），shape (M, N)
    * C: 输入张量（float32），shape (M, N)
    * output: 输出张量（float32），shape (M, N)
    * alpha: float 标量
    * beta: float 标量
    * M: 矩阵维度（int64）
    * N: 输出列数（int64）
    """
    output.copy_(alpha * torch.matmul(A, B) + beta * C)
```
