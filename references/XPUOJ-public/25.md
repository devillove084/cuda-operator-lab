# Index Put First Axis

原题 https://xpuoj.com/p/25

## 题目描述

你需要提交一份代码，实现一个沿第 0 维的 scatter 写入算子：

> **output = zeros(first_axis_dim, H); output[indices] = values**

本题对应 `index_put_first_axis`。给定二维张量 `values`、一维张量 `indices` 和输出第 0 维大小 `first_axis_dim`，你需要把 `values` 的每一行写入 `output[indices[i]]`。

评测程序会将你的源码编译为 **动态链接库（.so）**，并在 GPU 上通过 FFI 调用你导出的函数：

* `run_kernel`：由你在函数内部计算合适的 launch 配置并完成 scatter

评测同时会进行：

* **性能计时**
* **正确性校验**

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const void* values,
    const int64_t* indices,
    void* output,
    int64_t first_axis_dim,
    int64_t M,
    int64_t H,
    int64_t dtype_code
);
```

### 参数说明

* `values`：输入指针，shape `(M, H)`
* `indices`：输入指针，shape `(M,)`，类型为 INT64
* `output`：输出指针，shape `(first_axis_dim, H)`
* `first_axis_dim`：输出第 0 维大小
* `M`：待写入的行数
* `H`：每行元素数
* `dtype_code`：数据类型编码
  - `0` 表示 `bfloat16`
  - `1` 表示 `float16`
  - `2` 表示 `float32`

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成沿第 0 维的 scatter 写入

## 输入格式

本题的“输入”由评测程序在 GPU 上构造并传入 `run_kernel`。

评测会生成以下参数并按顺序传入 `run_kernel`：

1. `values`：CUDA tensor，shape `(M, H)`
2. `indices`：INT64 CUDA tensor，shape `(M,)`
3. `output`：CUDA tensor，shape `(first_axis_dim, H)`，输出缓冲区
4. `first_axis_dim`：int64 标量
5. `M`：int64 标量
6. `H`：int64 标量
7. `dtype_code`：int64 标量

## 输出格式

输出 `output` 的 shape 为 `(first_axis_dim, H)`，满足：

```text
output 先全部置 0
output[indices[i], j] = values[i, j]
```

## 数据范围与提示

## 数据范围

* `values.dtype` 可能为 `torch.bfloat16`、`torch.float16` 或 `torch.float32`
* `indices.dtype == torch.int64`
* `output.shape == (first_axis_dim, H)`

## 正确性要求

* **必须先将 `output` 全部置 0**
* **必须按 `indices` 沿第 0 维 scatter**
* **必须完整复制每一行的所有列**

## 提示

* 可以先把整个输出张量清零，再根据 `indices` 逐行写入 `values`
* 评测中的 `indices` 保证互不重复，因此无需处理重复写入冲突

## PyTorch 参考实现

```python
def baseline(values, indices, output, first_axis_dim, M, H, dtype_code):
    """
    PyTorch 参考实现：Index Put First Axis

    参数说明：
    * values: 输入张量，shape (M, H)
```
