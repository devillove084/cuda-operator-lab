# Conv2d Dgrad F16

原题 https://xpuoj.com/p/55

## 题目描述

你需要实现一个 2D 卷积对输入的梯度计算算子（conv2d dgrad）：

> **grad_input = conv2d_dgrad(grad_output, weight, stride, padding)**

给定输出梯度张量 `grad_output`、前向卷积核 `weight`、步长 `stride` 和填充 `padding`，你需要计算标准 `conv2d` 对输入张量的梯度 `grad_input`。

对无分组、无 dilation 的普通卷积而言，这个运算在数学上等价于指定输出尺寸的转置卷积：

> **grad_input = conv_transpose2d(grad_output, weight, None, stride, padding, output_size=(N, C_in, H_in, W_in))**

为了适配 OJ，本题不传入原始输入 `x`，而是直接要求你根据 `grad_output` 和 `weight` 计算 `grad_input`。评测使用 PyTorch 的 `torch.nn.grad.conv2d_input` 作为参考语义。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 `conv2d dgrad` 的计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_fp16.h>

extern "C" void run_kernel(
    const half* grad_output,
    const half* weight,
    half* grad_input,
    int64_t N,
    int64_t C_in,
    int64_t C_out,
    int64_t H_in,
    int64_t W_in,
    int64_t R,
    int64_t S,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `grad_output`：输入指针，shape `(N, C_out, H_out, W_out)`，类型为 float16
* `weight`：输入指针，shape `(C_out, C_in, R, S)`，类型为 float16
* `grad_input`：输出指针，shape `(N, C_in, H_in, W_in)`，类型为 float16
* `N`：batch size
* `C_in`：输入通道数
* `C_out`：输出通道数
* `H_in`、`W_in`：待求输入梯度的高度、宽度
* `R`、`S`：卷积核高度、宽度
* `stride`：步长
* `padding`：零填充大小

`run_kernel` 内部需要完成以下工作：

* 根据输入尺寸与卷积参数理解 `grad_output` 的空间布局
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成 `grad_input` 的计算

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `grad_output`：float16 tensor，shape `(N, C_out, H_out, W_out)`
* `weight`：float16 tensor，shape `(C_out, C_in, R, S)`
* `grad_input`：float16 tensor，shape `(N, C_in, H_in, W_in)`，作为输出缓冲区
* `N, C_in, C_out, H_in, W_in, R, S, stride, padding`：int64 标量

其中输出梯度空间大小满足：

```text
H_out = floor((H_in + 2 * padding - R) / stride + 1)
W_out = floor((W_in + 2 * padding - S) / stride + 1)
```

## 输出格式

你需要将计算结果写入 `grad_input`，满足：

```text
grad_input = conv2d_input_backward(grad_output, weight)
```

等价地，也可以理解为：

```text
grad_input = conv_transpose2d(
    grad_output,
    weight,
    stride=stride,
    padding=padding,
    output_size=(N, C_in, H_in, W_in)
)
```

更具体地，对于每个位置 `grad_input[n, c_in, h, w]`：

```text
grad_input[n, c_in, h, w] =
    sum_{c_out, k_h, k_w}
        grad_output[n, c_out, h_out, w_out] * weight[c_out, c_in, k_h, k_w]
```

其中索引需要满足：

```text
h = h_out * stride - padding + k_h
w = w_out * stride - padding + k_w
```
