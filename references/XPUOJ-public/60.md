# Trmm CF64

原题 https://xpuoj.com/p/60

## 题目描述

你需要实现一个复数双精度的三角矩阵乘法算子：

> **output = alpha * A_tri @ B**

给定输入矩阵 `A` 和 `B`，其中 `A` 的 shape 为 `(M, M)`，`B` 的 shape 为 `(M, N)`。`A` 是一个普通复数矩阵，但计算时只使用它的某个三角部分：

$$
A_{tri} =
\begin{cases}
\mathrm{triu}(A), & \text{if } upper\_flag = 1 \\
\mathrm{tril}(A), & \text{if } upper\_flag = 0
\end{cases}
$$

然后计算：

$$
output = \alpha \cdot (A_{tri} @ B)
$$

其中 `alpha` 是实数标量，`output` 的 shape 为 `(M, N)`。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述三角矩阵乘法。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_runtime.h>

extern "C" void run_kernel(
    const double2* A,
    const double2* B,
    double2* output,
    float alpha,
    int64_t upper_flag,
    int64_t M,
    int64_t N
);
```

### 参数说明

* `A`：输入指针（complex128），shape `(M, M)`，行优先连续存储，只读
* `B`：输入指针（complex128），shape `(M, N)`，行优先连续存储，只读
* `output`：输出指针（complex128），shape `(M, N)`，行优先连续存储，需写入计算结果
* `alpha`：float32 标量
* `upper_flag`：int64 标量，`1` 表示取上三角，`0` 表示取下三角
* `M`：`A` 的行数和列数，也是 `B/output` 的行数（int64）
* `N`：`B/output` 的列数（int64）

`run_kernel` 内部需要完成以下工作：

* 根据 `upper_flag` 正确选择 `A` 的上三角或下三角部分
* 根据矩阵尺寸计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 `output = alpha * (A_tri @ B)`

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `A`：shape `(M, M)` 的 complex128 矩阵
* `B`：shape `(M, N)` 的 complex128 矩阵
* `output`：shape `(M, N)` 的 complex128 输出缓冲区，初始值未定义
* `alpha`：float 标量
* `upper_flag`：int64 标量
* `M`：int64 标量，表示三角矩阵 `A` 的维度
* `N`：int64 标量，表示输出列数

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，得到一个 shape 为 `(M, N)` 的 complex128 矩阵。对于每个位置 `(i, j)`，输出应满足：

$$
output_{i,j} = \alpha \cdot \sum_{k=0}^{M-1} A_{tri}[i,k] \cdot B[k,j]
$$

其中：

$$
A_{tri} =
\begin{cases}
\mathrm{triu}(A), & \text{if } upper\_flag = 1 \\
\mathrm{tril}(A), & \text{if } upper\_flag = 0
\end{cases}
$$

所有乘法和加法都在复数域上进行。

* 必须根据 `upper` 正确选择 `a` 的上三角或下三角部分
* 必须正确实现 $result = alpha \cdot a_{tri} @ b$

* 不允许修改输入 `a` 和 `b`

* complex128 元素对应两个 float64 分量，CUDA 中可使用 `cuDoubleComplex`

## PyTorch 参考实现

```python
def baseline(A, B, output, alpha, upper_flag, M, N):
    """
    PyTorch 参考实现：output = alpha * (A_tri @ B)

    参数说明：
    * A: 输入张量（complex128），shape (M, M)
    * B: 输入张量（complex128），shape (M, N)
    * output: 输出张量（complex128），shape (M, N)
    * alpha: float 标量
    * upper_flag: int 标量
    * M: 矩阵维度（int64）
    * N: 输出列数（int64）
    """
    A_tri = torch.triu(A) if upper_flag else torch.tril(A)
    output.copy_(alpha * torch.matmul(A_tri, B))
```
