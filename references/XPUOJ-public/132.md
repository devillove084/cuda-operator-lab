# Dynamic Quantize GeMM

原题 https://xpuoj.com/p/132

## 题目描述

你需要实现一个 `dynamic_quantize_gemm` 算子。

给定输入矩阵 `a` 和 `b`，你需要先分别对两张矩阵做动态对称量化，再完成矩阵乘法，并将结果反量化为 `bfloat16` 输出。

各张量的 shape 与 dtype 如下：

* `a`：shape `(M, K)`，dtype `bfloat16`
* `b`：shape `(K, N)`，dtype `bfloat16`
* `out`：shape `(M, N)`，dtype `bfloat16`

设：

* `qmax = 2^(num_bits - 1) - 1`
* `scale_a = max(abs(a)) / qmax`
* `scale_b = max(abs(b)) / qmax`

则量化与计算过程为：

$$
a_q[i, t] = clamp(round(a[i, t] / scale_a), -qmax, qmax)
$$

$$
b_q[t, j] = clamp(round(b[t, j] / scale_b), -qmax, qmax)
$$

$$
out[i, j] = \left( \sum_{t=0}^{K-1} a_q[i, t] \cdot b_q[t, j] \right) \cdot (scale_a \cdot scale_b)
$$

其中：

* `max(abs(a))` 和 `max(abs(b))` 分别是对整张矩阵取绝对值后的全局最大值
* `round` 与 `PyTorch` 中 `torch.round` 的语义一致
* `clamp` 表示截断到 `[-qmax, qmax]`

注意，本题对 `a` 和 `b` 分别使用各自的**全局 scale**，而不是按行、按列或按通道量化。

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据数据规模计算合适的 launch 配置，并完成全局归约、量化和矩阵乘法。

如何提交代码详见[评测指南](/d/2)。

## 输出格式

你需要将结果写入 `out`，满足：

```text
qmax = 2^(num_bits - 1) - 1
scale_a = max(abs(a)) / qmax
scale_b = max(abs(b)) / qmax

for i in [0, M):
    for j in [0, N):
        acc = 0
        for t in [0, K):
            a_q = clamp(round(a[i, t] / scale_a), -qmax, qmax)
            b_q = clamp(round(b[t, j] / scale_b), -qmax, qmax)
            acc += a_q * b_q
        out[i, j] = acc * (scale_a * scale_b)
```

## 计算过程说明

先分别求两张矩阵的全局最大绝对值：

* `max(abs(a)) = 3.1`
* `max(abs(b)) = 3.4`

对于 `num_bits = 4`：

* `qmax = 7`
* `scale_a = 3.1 / 7 = 0.4428571`
* `scale_b = 3.4 / 7 = 0.4857143`

量化后：

* `a_q[0] = [3, -5, 1]`
* `b_q[:, 0] = [4, 1, -5]`
* `b_q[:, 1] = [-3, 7, 2]`

于是：

* `out[0, 0] = (3 * 4 + (-5) * 1 + 1 * (-5)) * (scale_a * scale_b) = 2 * (scale_a * scale_b) ≈ 0.4302041`
* `out[0, 1] = (3 * (-3) + (-5) * 7 + 1 * 2) * (scale_a * scale_b) = -42 * (scale_a * scale_b) ≈ -9.0342860`

其余元素同理。

## PyTorch 参考实现

```python
import torch


def baseline(a, b, out, M, K, N, num_bits):
    qmax = (2 ** (num_bits - 1)) - 1
    a_f = a.float()
    b_f = b.float()
    scale_a = a_f.abs().max() / float(qmax)
    scale_b = b_f.abs().max() / float(qmax)
    a_q = torch.clamp(torch.round(a_f / scale_a), -qmax, qmax)
    b_q = torch.clamp(torch.round(b_f / scale_b), -qmax, qmax)
    y = torch.matmul(a_q, b_q) * (scale_a * scale_b)
    out.copy_(y.to(torch.bfloat16))
```
