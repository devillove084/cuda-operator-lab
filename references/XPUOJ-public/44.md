# FMHA

原题 https://xpuoj.com/p/44

## 题目描述

你需要实现一个支持变长序列的 Flash Multi-Head Attention（FMHA）前向算子。输入中的 `qkv` 已经把所有样本的 token 首尾拼接到一起，同时把每个 token 的 `Q`、`K`、`V` 也打包在同一行中；评测程序再通过 `cu_seqlens` 告诉你每个样本在这个大张量里的起止位置。你需要先拆出 `Q/K/V`，再对每个样本自己的序列分别计算多头自注意力。

设隐藏维度满足：

$$
\text{hidden\_size} = H \times D
$$

其中 $H$ 是注意力头数，$D$ 是单头维度。输入张量为：

$$
\text{QKV} \in \mathbb{R}^{T \times 3HD}
$$

其中 $T$ 是所有样本的 token 总数。对每个 token，对应行需要先拆成三段，再重排为：

$$
Q \in \mathbb{R}^{T \times H \times D}, \quad
K \in \mathbb{R}^{T \times H \times D}, \quad
V \in \mathbb{R}^{T \times H \times D}
$$

`cu_seqlens` 是长度为 `batch_size + 1` 的累积前缀和数组。对第 $b$ 个样本，它的 token 区间为：

$$
s_b = \text{cu\_seqlens}[b], \quad e_b = \text{cu\_seqlens}[b+1]
$$

$$
Q_b = Q[s_b:e_b], \quad K_b = K[s_b:e_b], \quad V_b = V[s_b:e_b]
$$

其中

$$
L_b = e_b - s_b
$$

表示该样本自己的序列长度。为了进行多头注意力计算，baseline 会把它们重排成按 head 优先的布局：

$$
Q_b^{\top}, K_b^{\top}, V_b^{\top} \in \mathbb{R}^{H \times L_b \times D}
$$

对任意一个样本 $b$、任意一个 head $h$，其注意力分数矩阵为：

$$
S_b^{(h)}[u, v] = \frac{\left\langle Q_b^{\top}[h, u, :], K_b^{\top}[h, v, :] \right\rangle}{\sqrt{D}}, 
\quad 0 \le u, v < L_b
$$

然后在 key 维度上做 softmax：

$$
P_b^{(h)}[u, v] = \frac{\exp(S_b^{(h)}[u, v])}{\sum_{t=0}^{L_b-1} \exp(S_b^{(h)}[u, t])}
$$

最后得到该 head 的输出：

$$
O_b^{(h)}[u, :] = \sum_{v=0}^{L_b-1} P_b^{(h)}[u, v] \, V_b^{\top}[h, v, :]
$$

把所有 heads 的结果重新拼回 token 优先布局后，得到该样本输出 $O_b \in \mathbb{R}^{L_b \times H \times D}$；再把所有样本按原顺序首尾拼接，并 reshape 成：

$$
\text{out} \in \mathbb{R}^{T \times HD}
$$

因此，本题的关键不是只写一个 `softmax(QK^T/\sqrt{D})V` 总公式，而是要正确处理三件事：从打包的 `qkv` 拆出三路张量、利用 `cu_seqlens` 切出每个变长样本、以及对每个样本独立完成多头自注意力并重新拼回总输出。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成注意力计算。

如何提交代码详见[评测指南](/d/2)。

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 Flash Multi-Head Attention 计算

    Args:
        qkv: BF16 tensor of shape (total_tokens, 3 * hidden_size) - qkv input
        cu_seqlens: int32 tensor of shape (batch_size + 1,) - cumulative sequence lengths
        max_seqlen: int - max sequence length
        num_heads: int - number of attention heads
        head_dim: int - head dimension
        out: BF16 tensor of shape (total_tokens, hidden_size) - output (will be modified inplace)
        batch_size: int - batch size

    Returns:
        List containing modified out tensor
    """
    qkv, cu_seqlens, max_s, num_heads, head_dim, out, batch_size = inputs

    assert torch.is_tensor(qkv) and torch.is_tensor(cu_seqlens) and torch.is_tensor(out)
    assert isinstance(max_s, int) and isinstance(num_heads, int) and isinstance(head_dim, int) and isinstance(batch_size, int)
    hidden_size = num_heads * head_dim
    assert qkv.shape[1] == 3 * hidden_size
    assert cu_seqlens.shape == (batch_size + 1,)
    assert out.shape == (qkv.shape[0], hidden_size)

    # 计算注意力
    qkv_reshaped = qkv.view(-1, 3, num_heads, head_dim)
    q = qkv_reshaped[:, 0]
    k = qkv_reshaped[:, 1]
    v = qkv_reshaped[:, 2]

    out_list = []
    scale = 1.0 / math.sqrt(head_dim)

    for i in range(batch_size):
        start = cu_seqlens[i]
        end = cu_seqlens[i + 1]

        q_seq = q[start:end]
        k_seq = k[start:end]
        v_seq = v[start:end]

        q_in = q_seq.permute(1, 0, 2).unsqueeze(0)
        k_in = k_seq.permute(1, 0, 2).unsqueeze(0)
        v_in = v_seq.permute(1, 0, 2).unsqueeze(0)

        q_f32 = q_in.to(torch.float32)
        k_f32 = k_in.to(torch.float32)
        v_f32 = v_in.to(torch.float32)

        scores = torch.matmul(q_f32, k_f32.transpose(-2, -1)) * scale
        attn = torch.softmax(scores, dim=-1)
        out_curr = torch.matmul(attn, v_f32)
        out_curr = out_curr.to(q_in.dtype)

        out_list.append(out_curr.squeeze(0).permute(1, 0, 2))

    out_cat = torch.cat(out_list, dim=0)
    result = out_cat.reshape(-1, hidden_size)
    out.copy_(result)

    return list(inputs)```
