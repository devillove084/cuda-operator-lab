# Dense GeMM (bf16)

原题 https://xpuoj.com/p/2

## 题目描述

你需要实现一个 bfloat16 精度的矩阵乘法算子：

> **C = A @ B.T**

给定输入矩阵 $A$（shape 为 $(M, K)$）和 $B$（shape 为 $(N, K)$），计算输出矩阵 $C = A \times B^T$，其中 $C$ 的 shape 为 $(M, N)$。具体计算方式为：

$$
C_{i,j} = \sum_{k=0}^{K-1} A_{i,k} \cdot B_{j,k}
$$

其中 $i \in [0, M)$，$j \in [0, N)$，$\cdot$ 表示逐元素乘法。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述矩阵乘法。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* A,
    const __nv_bfloat16* B,
    __nv_bfloat16* C,
    int64_t M,
    int64_t N,
    int64_t K
);
```

### 参数说明

* `A`：输入指针（bfloat16），shape $(M, K)$，行优先连续存储，只读
* `B`：输入指针（bfloat16），shape $(N, K)$，行优先连续存储，只读
* `C`：输出指针（bfloat16），shape $(M, N)$，行优先连续存储，需写入计算结果
* `M`：A 的行数，也是 C 的行数（int64）
* `N`：B 的行数，也是 C 的列数（int64）
* `K`：A 的列数，也是 B 的列数（int64）

`run_kernel` 内部需要完成以下工作：

* 根据矩阵尺寸计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 $C = A \times B^T$ 的计算

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

首先是三个 bfloat16 类型的矩阵，均采用行优先连续存储：

* `A`：shape $(M, K)$ 的输入矩阵
* `B`：shape $(N, K)$ 的输入矩阵，计算时会被转置
* `C$：shape $(M, N)$ 的输出矩阵缓冲区，初始值未定义

然后是三个整型参数：

* `M`：int64 标量，表示 A 的行数
* `N`：int64 标量，表示 B 的行数（也是 C 的列数）
* `K`：int64 标量，表示 A 的列数（也是 B 的列数）

注意本题计算的是 $A \times B^T$ 而非 $A \times B$，即 B 在参与运算时会被转置。

## 输出格式

你需要将计算结果写入 $C$ 指向的缓冲区，得到一个 shape 为 $(M, N)$ 的 bfloat16 矩阵，满足：

$$
C_{i,j} = \sum_{k=0}^{K-1} A_{i,k} \cdot B_{j,k}
$$

即 $C$ 是 $A$ 与 $B^T$ 的矩阵乘积，其中 $B^T$ 表示矩阵 $B$ 的转置。

## 样例

## 输入

```
A: [[1, 2, 3],
    [4, 5, 6]]        # shape (2, 3)

B: [[7, 8, 9],
    [10, 11, 12]]    # shape (2, 3)

M: 2
N: 2
K: 3
```

## 输出

```
C: [[50, 68],
    [122, 167]]      # shape (2, 2)
```

## 计算过程

本题计算 $C = A @ B^T$。首先将 $B$ 转置得到：

```
B^T: [[7, 10],
     [8, 11],
     [9, 12]]       # shape (3, 2)
```

然后计算矩阵乘法：

$C_{0,0} = 1 \times 7 + 2 \times 8 + 3 \times 9 = 7 + 16 + 27 = 50$

$C_{0,1} = 1 \times 10 + 2 \times 11 + 3 \times 12 = 10 + 22 + 36 = 68$

$C_{1,0} = 4 \times 7 + 5 \times 8 + 6 \times 9 = 28 + 40 + 54 = 122$

$C_{1,1} = 4 \times 10 + 5 \times 11 + 6 \times 12 = 40 + 55 + 72 = 167$

def baseline(A, B, C, M, N, K):
    """
    PyTorch 参考实现：C = A @ B.T
    
    参数说明：
    * A: 输入张量（bfloat16），shape (M, K)，行优先连续存储，只读
    * B: 输入张量（bfloat16），shape (N, K)，行优先连续存储，只读

    * N: B 的行数，也是 C 的列数（int64）
    * K: A 的列数，也是 B 的列数（int64）
