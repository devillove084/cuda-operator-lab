# CrossEntropy

原题 https://xpuoj.com/p/9

## 题目描述

你需要实现一个交叉熵损失（Cross Entropy Loss）算子。交叉熵损失是多分类问题中最常用的损失函数之一，用于衡量模型预测的概率分布与真实标签之间的差异。

对于每个样本 $i$，给定 logits 向量 $\mathbf{z}^{(i)} = (z_1^{(i)}, z_2^{(i)}, \ldots, z_N^{(i)})$ 和标签 $y^{(i)} \in \{0, 1, \ldots, N-1\}$，损失计算方式为：

$$
\text{loss}[i] = -\log\left( \frac{\exp\left(z_{y^{(i)}}^{(i)}\right)}{\sum_{j=0}^{N-1} \exp\left(z_j^{(i)}\right)} \right)
$$

这等价于先对 logits 进行 softmax 归一化得到概率分布，然后取对应标签位置的负对数：

$$
\text{loss}[i] = -\log\, p_{y^{(i)}}^{(i)}
$$

其中 $p_j^{(i)} = \dfrac{\exp(z_j^{(i)})}{\sum_{t=0}^{N-1} \exp(z_t^{(i)})}$ 是 softmax 概率。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成交叉熵计算。

如何提交代码详见[评测指南](/d/2)。

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `logits`：float32 tensor，shape $(M, N)$，行优先连续存储，表示 $M$ 个样本、每个样本 $N$ 个类别的未归一化分数
* `labels`：int64 tensor，shape $(M,)$，连续存储，每个元素表示对应样本的真实类别标签，取值范围 $[0, N)$
* `loss`：float32 tensor，shape $(M,)$，连续存储，作为输出缓冲区，初始值未定义
* `M`：int64 标量，表示样本数量
* `N`：int64 标量，表示类别数量

## 输出格式

你需要将计算结果写入 $\text{loss}$ 指向的缓冲区，得到一个 shape 为 $(M,)$ 的 float32 向量。对于每个样本 $i$，输出应满足：

$$
\text{loss}[i] = -\log\left( \frac{\exp\left(\text{logits}[i, \text{labels}[i]]\right)}{\sum_{j=0}^{N-1} \exp\left(\text{logits}[i, j]\right)} \right)
$$

等价地，可写为：

$$
\text{loss}[i] = -\text{logits}[i, \text{labels}[i]] + \log\left( \sum_{j=0}^{N-1} \exp\left(\text{logits}[i, j]\right) \right)
$$

即对每个样本的 logits 进行 softmax 归一化，然后取对应标签位置的负对数似然。

## 样例

## 输入

$M = 2$，$N = 3$

`logits`：

```
[[1.0, 2.0, 3.0],
 [0.5, 1.5, 0.0]]
```

`labels`：

```
[2, 0]
```

## 输出

`loss`：

```
[0.4076, 1.4076]
```

## 计算过程说明

**样本 0**（标签为 2）：

首先对 logits $[1.0, 2.0, 3.0]$ 进行 softmax：
* $\exp([1.0, 2.0, 3.0]) \approx [2.718, 7.389, 20.086]$
* 求和 $\approx 30.193$
* softmax 结果 $\approx [0.0900, 0.2447, 0.6652]$

取标签 2 位置的概率 $0.6652$，计算负对数：
* $\text{loss}[0] = -\log(0.6652) \approx 0.4076$

**样本 1**（标签为 0）：

对 logits $[0.5, 1.5, 0.0]$ 进行 softmax：
* $\exp([0.5, 1.5, 0.0]) \approx [1.649, 4.482, 1.000]$
* 求和 $\approx 7.131$
* softmax 结果 $\approx [0.2315, 0.6285, 0.1400]$

取标签 0 位置的概率 $0.2315$，计算负对数：
* $\text{loss}[1] = -\log(0.2315) \approx 1.4076$
