# Dropout

原题 https://xpuoj.com/p/91

## 题目描述

你需要实现一个 Dropout 算子。给定输入矩阵 $x$（shape 为 $(M, N)$），你需要按位置生成保留掩码，并输出缩放后的结果矩阵 $y$（shape 同为 $(M, N)$）。

对于每个元素位置 $(i, j)$，定义线性下标：

$$
linear\_index = i \cdot N + j
$$

然后按以下规则计算该位置的随机值（`state` 与 `random_val`）：

$$
seed31 = dropout\_seed \,\&\, 0x7FFFFFFF
$$

$$
idx31 = linear\_index \,\&\, 0x7FFFFFFF
$$

$$
state = \left(seed31 \oplus \left((idx31 \cdot 1103515245 + 12345)\,\&\,0x7FFFFFFF\right)\right)\,\&\,0x7FFFFFFF
$$

$$
random\_val = \frac{state}{2^{31}}
$$

若 `random_val >= dropout_rate`，则该位置保留并乘缩放因子 $\frac{1}{1-dropout\_rate}$；否则输出 `0`：

$$
y[i, j] =
\begin{cases}
x[i, j] \cdot \frac{1}{1 - dropout\_rate}, & random\_val \ge dropout\_rate \\
0, & random\_val < dropout\_rate
\end{cases}
$$

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp

#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* x,
    __nv_bfloat16* y,
    int64_t M,

    int64_t dropout_seed
```

* `x`：输入指针（bfloat16），shape $(M, N)$，行优先连续存储，只读

## 计算过程说明

缩放因子为：

$$
\frac{1}{1 - 0.25} = \frac{4}{3}
$$

对每个位置计算 `linear_index = i * N + j`，再计算 `state` 与 `random_val`：

* 位置 $(0,0)$：`linear_index=0`
  * `idx31=0`
  * `state=(12345 ^ ((0*1103515245+12345)&0x7FFFFFFF))&0x7FFFFFFF = 0`
  * `random_val=0/2^31=0.0 < 0.25`，丢弃，$y_{0,0}=0$
* 位置 $(0,1)$：`linear_index=1`
  * `idx31=1`
  * `state=(12345 ^ ((1*1103515245+12345)&0x7FFFFFFF))&0x7FFFFFFF = 1103515295`
  * `random_val \approx 0.513864 \ge 0.25`，保留，$y_{0,1}=2\times\frac{4}{3}=2.666667$
* 位置 $(0,2)$：`linear_index=2`
  * `state=59571498`
  * `random_val \approx 0.027740 < 0.25`，丢弃，$y_{0,2}=0$
* 位置 $(0,3)$：`linear_index=3`
  * `state=1163078585`
  * `random_val \approx 0.541601 \ge 0.25`，保留，$y_{0,3}=4\times\frac{4}{3}=5.333333$
* 位置 $(1,0)$：`linear_index=4`
  * `state=119101908`
  * `random_val \approx 0.055461 < 0.25`，丢弃，$y_{1,0}=0$
* 位置 $(1,1)$：`linear_index=5`
  * `state=1222608995`
  * `random_val \approx 0.569322 \ge 0.25`，保留，$y_{1,1}=6\times\frac{4}{3}=8.0$
* 位置 $(1,2)$：`linear_index=6`

## PyTorch 参考实现

```python
def baseline(x, y, M, N, dropout_rate, dropout_seed):
    rate32 = float(torch.tensor(float(dropout_rate), dtype=torch.float32).item())
    scale = 1.0 / (1.0 - rate32)
    linear = torch.arange(M * N, device=x.device, dtype=torch.int64)
    seed31 = int(dropout_seed) & 0x7FFFFFFF
    idx31 = linear & 0x7FFFFFFF
    state = (seed31 ^ ((idx31 * 1103515245 + 12345) & 0x7FFFFFFF)) & 0x7FFFFFFF
    random_val = (state.to(torch.float64) / float(1 << 31)).view(M, N)
    keep = random_val >= rate32
    y.copy_(torch.where(keep, x.float() * scale, torch.zeros_like(x, dtype=torch.float32)).to(torch.bfloat16))
```
