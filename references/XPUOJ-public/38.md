# TRTLLM Batch Context with KV Cache

原题 https://xpuoj.com/p/38

## 题目描述

你需要实现带 paged KV cache 的 batch context attention。与单步 decode 不同，这一题中每个请求会同时带入一段 query 序列，因此输入的 `query` 不是 `(batch, 1, ...)`，而是把整个 batch 的所有 query token 沿时间维首尾拼接后的大张量：

$$
Q \in \mathbb{R}^{T_q \times H \times D},
$$

其中 `T_q = total_tokens_q`，`H = num_heads`，`D = head_dim`。

对第 `b` 个请求，`cum_seq_lens_q` 给出它在全局 query 张量中的左右边界：

$$
s_b^{(q)} = \mathrm{cum\_seq\_lens\_q}[b], \qquad
e_b^{(q)} = \mathrm{cum\_seq\_lens\_q}[b+1].
$$

于是该请求自己的 query 片段为

$$
Q_b = Q[s_b^{(q)} : e_b^{(q)}] \in \mathbb{R}^{L_q^{(b)} \times H \times D},
\qquad
L_q^{(b)} = e_b^{(q)} - s_b^{(q)}.
$$

这一步只解决“全局 query 索引如何切回每个请求”的问题。与此同时，每个请求实际可见的历史 KV 长度并不是由 `cum_seq_lens_q` 决定，而是由

$$
L_{kv}^{(b)} = \mathrm{seq\_lens}[b]
$$

决定。也就是说，本题里 query 长度和 KV 长度是两套不同的索引系统：前者由 `cum_seq_lens_q` 切分，后者由 `seq_lens` 决定。

题目还额外传入了 `cum_seq_lens_kv`，但当前 `baseline()` 实际没有用它恢复 KV；KV 的真实恢复逻辑完全由 `seq_lens + block_tables + page_size` 决定，题面描述必须以这一点为准。

设 page 大小为

$$
P = \mathrm{page\_size}.
$$

则第 `b` 个请求需要访问的缓存页数为

$$
N_b = \left\lceil \frac{L_{kv}^{(b)}}{P} \right\rceil.
$$

在 baseline 中，`kv_cache` 的 shape 为

$$
(\mathrm{total\_pages}, 2, H, P, D).
$$

其中第二维的第 `0` 个切片存放 key page，第 `1` 个切片存放 value page。`block_tables[b,p]` 给出第 `b` 个请求第 `p` 个逻辑页对应的物理页编号，记为

$$
\pi_b(p) = \mathrm{block\_tables}[b,p], \qquad 0 \le p < N_b.
$$

对该请求历史上的任意时间步 `t`，其逻辑页号与页内偏移为

$$
p(t) = \left\lfloor \frac{t}{P} \right\rfloor, \qquad
o(t) = t \bmod P.
$$

于是恢复出来的连续 K/V 序列可写成

$$
K_b[h,t,:] = \mathrm{kv\_cache}[\pi_b(p(t)), 0, h, o(t), :],
$$

$$
V_b[h,t,:] = \mathrm{kv\_cache}[\pi_b(p(t)), 1, h, o(t), :],
$$

其中

$$
0 \le h < H,\qquad 0 \le t < L_{kv}^{(b)}.
$$

这正对应着 baseline 里的“先按 block table 逐页取出，再在时间维拼接，最后截断到真实 `seq_lens[b]`”。

对第 `b` 个请求，恢复出

$$
Q_b \in \mathbb{R}^{L_q^{(b)} \times H \times D},\qquad
K_b, V_b \in \mathbb{R}^{H \times L_{kv}^{(b)} \times D}
$$

之后，注意力分数定义为

$$
S_b[q,h,t]
=
\left\langle Q_b[q,h,:], K_b[h,t,:] \right\rangle \cdot \mathrm{bmm1\_scale},
\qquad
0 \le q < L_q^{(b)}.
$$

在当前测试配置中，

$$
\mathrm{bmm1\_scale} = \frac{1}{\sqrt{D}},
\qquad
\mathrm{bmm2\_scale} = 1.
$$

然后在历史长度维 `t` 上做 softmax，并乘上输出缩放：

$$
A_b[q,h,t]
=
\operatorname{softmax}(S_b[q,h,:])_t \cdot \mathrm{bmm2\_scale}.
$$

最终输出为

$$
O_b[q,h,:]
=
\sum_{t=0}^{L_{kv}^{(b)}-1}
A_b[q,h,t]\,V_b[h,t,:].
$$

所有请求的 `O_b` 再按 batch 顺序重新首尾拼接，写回总输出

$$
\mathrm{out} \in \mathbb{R}^{T_q \times H \times D}.
$$

因此，本题需要你严格实现下面这条完整映射链：

$$
\text{global query index}
\to
\text{request-local query segment}
\to
\text{paged KV reconstruction}
\to
\text{scaled attention}
\to
\text{output concat}.
$$

最容易混淆的点有三个：

- `cum_seq_lens_q` 只负责切分 query；
- `seq_lens[b]` 才决定该请求可见的 KV 历史长度；
- `block_tables` 决定逻辑页到物理页的映射，恢复 K/V 时必须先按页再按页内偏移访问。

如何提交代码详见[评测指南](/d/2)。

```

## 参数说明

* `query_ptr`：输入 query 指针（bfloat16），shape $(\text{total_tokens_q}, \text{num_heads}, \text{head_dim})$，行优先连续存储，只读
* `kv_cache_ptr`：KV 缓存指针（bfloat16），shape $(\text{total_pages}, 2, \text{num_heads}, \text{page_size}, \text{head_dim})$，行优先连续存储，只读
* `workspace_buffer_ptr`：工作空间指针，预留参数，当前未使用
* `block_tables_ptr`：页表指针（int32），shape $(\text{batch_size}, \text{max_pages_per_seq})$，存储每个序列使用的 page id，GPU 内存
* `seq_lens_ptr`：KV 序列长度指针（int32），shape $(\text{batch_size},)$，存储每个序列的 kv 长度，GPU 内存
* `cum_seq_lens_q_ptr`：query 累积长度指针（int32），shape $(\text{batch_size} + 1,)$，存储 query 的累积偏移，GPU 内存
* `cum_seq_lens_kv_ptr`：KV 累积长度指针（int32），shape $(\text{batch_size} + 1,)$，存储 KV 的累积偏移，GPU 内存
* `out_ptr`：输出指针（bfloat16），shape $(\text{total_tokens_q}, \text{num_heads}, \text{head_dim})$，行优先连续存储，需写入计算结果
* `bmm1_scale`：Q@K 缩放因子（float），通常为 $1/\sqrt{\text{head_dim}}$
* `bmm2_scale`：输出缩放因子（float），通常为 1.0
* `batch_size`：batch 大小（int64）
* `num_heads`：注意力头数（int64）
* `head_dim`：每个头的维度（int64）
* `page_size`：KV 缓存页大小（int64）
* `max_pages_per_seq`：每个序列最大页数（int64）
* `total_tokens_q`：query 总 token 数（int64）
* `max_q_len`：query 最大序列长度（int64）
* `max_kv_len`：KV 最大序列长度（int64）
* `window_left`：滑动窗口左大小（int64），-1 表示无窗口限制

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成带 KV 缓存的上下文注意力计算

* $\text{page_size}$ 取值范围：16 ~ 64

* 不允许修改输入 tensor

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 trtllm batch context with kv cache

    Args:
        query: BF16 tensor of shape (total_tokens_q, num_heads, head_dim) - query
        kv_cache: BF16 tensor of shape (total_pages, 2, num_heads, page_size, head_dim) - key/value cache
        workspace_buffer: uint8 tensor of shape (1024 * 1024,) - workspace buffer
        block_tables: int32 tensor of shape (batch_size, max_pages_per_seq) - block tables
        seq_lens: int32 tensor of shape (batch_size,) - sequence lengths
        cum_seq_lens_q: int32 tensor of shape (batch_size + 1,) - cumulative sequence lengths for query
        cum_seq_lens_kv: int32 tensor of shape (batch_size + 1,) - cumulative sequence lengths for key/value
        out: BF16 tensor of shape (total_tokens_q, num_heads, head_dim) - output (will be modified inplace)
        bmm1_scale: float - softmax scale factor
        bmm2_scale: float - output scale factor
        batch_size: int - batch size
        num_heads: int - number of heads
        head_dim: int - head dimension
        page_size: int - page size
        max_pages_per_seq: int - max pages per sequence
        total_tokens_q: int - total number of query tokens
        max_q_len: int - max query length
        max_kv_len: int - max key/value length
        window_left: int - window left size

    Returns:
        List containing modified out tensor
    """
    query, kv_cache, workspace_buffer, block_tables, seq_lens, cum_seq_lens_q, cum_seq_lens_kv, out, bmm1_scale, bmm2_scale, batch_size, num_heads, head_dim, page_size, max_pages_per_seq, total_tokens_q, max_q_len, max_kv_len, window_left = inputs

    assert torch.is_tensor(query) and torch.is_tensor(kv_cache) and torch.is_tensor(workspace_buffer) and torch.is_tensor(block_tables) and torch.is_tensor(seq_lens) and torch.is_tensor(cum_seq_lens_q) and torch.is_tensor(cum_seq_lens_kv) and torch.is_tensor(out)
    assert isinstance(bmm1_scale, float) and isinstance(bmm2_scale, float) and isinstance(batch_size, int) and isinstance(num_heads, int) and isinstance(head_dim, int) and isinstance(page_size, int) and isinstance(max_pages_per_seq, int) and isinstance(total_tokens_q, int) and isinstance(max_q_len, int) and isinstance(max_kv_len, int) and isinstance(window_left, int)
    assert query.shape == (total_tokens_q, num_heads, head_dim)
    assert kv_cache.shape[2:] == (num_heads, page_size, head_dim)
    assert out.shape == query.shape
    assert block_tables.shape == (batch_size, max_pages_per_seq)
    assert seq_lens.shape == (batch_size,)
    assert cum_seq_lens_q.shape == (batch_size + 1,)
    assert cum_seq_lens_kv.shape == (batch_size + 1,)

    k_cache = kv_cache[:, 0]
    v_cache = kv_cache[:, 1]

    output_list = []
    for batch_idx in range(batch_size):
        start_q = int(cum_seq_lens_q[batch_idx].item())
        end_q = int(cum_seq_lens_q[batch_idx + 1].item())
        q_batch = query[start_q:end_q]
        seq_len_q = q_batch.shape[0]
        seq_len_kv = int(seq_lens[batch_idx].item())

        num_pages = (seq_len_kv + page_size - 1) // page_size
        k_list = []
        v_list = []
        for page_idx in range(num_pages):
            if page_idx < block_tables.shape[1] and block_tables[batch_idx, page_idx] >= 0:
                page_id = int(block_tables[batch_idx, page_idx].item())
                k_list.append(k_cache[page_id])
                v_list.append(v_cache[page_id])

        if not k_list:
            output_list.append(torch.zeros(seq_len_q, num_heads, head_dim, device=query.device, dtype=query.dtype))
            continue

        k_batch = torch.cat(k_list, dim=1)[:, :seq_len_kv, :]
        v_batch = torch.cat(v_list, dim=1)[:, :seq_len_kv, :]

        scores = torch.einsum("qhd,hkd->qhk", q_batch, k_batch) * bmm1_scale
        attn = torch.softmax(scores.float(), dim=-1).to(scores.dtype) * bmm2_scale
        out_batch = torch.einsum("qhk,hkd->qhd", attn, v_batch)
        output_list.append(out_batch)

    result = torch.cat(output_list, dim=0)
    out.copy_(result.to(out.dtype))
    return list(inputs)```
