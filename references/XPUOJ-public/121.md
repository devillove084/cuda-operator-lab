# FMHA Varlen Forward Ampere

原题 https://xpuoj.com/p/121

## 题目描述

你需要实现变长序列的 FMHA 前向。输入中的 `q`、`k`、`v` 把整个 batch 的所有 token 首尾拼接在一起，而 `cu_q` 和 `cu_k` 给出了每个请求在这些拼接张量中的起止位置。你需要先按请求拆分出各自的 `Q/K/V`，再分别计算注意力并把结果重新拼接回输出。

设输入满足：

$$
Q \in \mathbb{R}^{T_q \times H_q \times D}, \quad
K \in \mathbb{R}^{T_k \times H_{kv} \times D}, \quad
V \in \mathbb{R}^{T_k \times H_{kv} \times D}
$$

其中 $T_q$ 和 $T_k$ 是拼接后 query 和 KV 的总 token 数，$H_q$ 是 query 头数，$H_{kv}$ 是 KV 头数，$D$ 是单头维度。

`cu_q` 和 `cu_k` 都是长度为 `batch_size + 1` 的前缀和数组。对第 $b$ 个请求，定义：

$$
s_q^{(b)} = \text{cu\_q}[b], \quad e_q^{(b)} = \text{cu\_q}[b+1]
$$

$$
s_k^{(b)} = \text{cu\_k}[b], \quad e_k^{(b)} = \text{cu\_k}[b+1]
$$

则该请求自己的 query 和 KV 片段分别为：

$$
Q_b = Q[s_q^{(b)} : e_q^{(b)}] \in \mathbb{R}^{L_q^{(b)} \times H_q \times D}
$$

$$
K_b = K[s_k^{(b)} : e_k^{(b)}] \in \mathbb{R}^{L_k^{(b)} \times H_{kv} \times D}
$$

$$
V_b = V[s_k^{(b)} : e_k^{(b)}] \in \mathbb{R}^{L_k^{(b)} \times H_{kv} \times D}
$$

其中

$$
L_q^{(b)} = e_q^{(b)} - s_q^{(b)}, \quad
L_k^{(b)} = e_k^{(b)} - s_k^{(b)}
$$

为了做按 head 的注意力计算，baseline 会先把它们转成：

$$
Q_b^{\top} \in \mathbb{R}^{H_q \times L_q^{(b)} \times D}
$$

$$
K_b^{\top}, V_b^{\top} \in \mathbb{R}^{H_{kv} \times L_k^{(b)} \times D}
$$

如果 $H_q \neq H_{kv}$，则按 GQA 的语义把 KV heads 在 head 维上重复。令

$$
g = \frac{H_q}{H_{kv}}
$$

则扩展后得到：

$$
\widehat{K}_b, \widehat{V}_b \in \mathbb{R}^{H_q \times L_k^{(b)} \times D}
$$

对任意 head $h$、query 位置 $u$、key 位置 $v$，注意力分数为：

$$
S_b[h,u,v] =
\left\langle Q_b^{\top}[h,u,:], \widehat{K}_b[h,v,:] \right\rangle \cdot \frac{1}{\sqrt{D}}
$$

如果 `causal = 1`，则需要施加因果掩码。也就是说，当 $v > u$ 时，这个 query 位置不能看到未来 key 位置，于是：

$$
\widetilde{S}_b[h,u,v] =
\begin{cases}
S_b[h,u,v], & v \le u \\
-\infty, & v > u
\end{cases}
$$

如果 `causal = 0`，则直接令 $\widetilde{S}_b = S_b$。

然后在 key 维度上做 softmax：

$$
P_b[h,u,v] = \frac{\exp(\widetilde{S}_b[h,u,v])}{\sum_{t=0}^{L_k^{(b)}-1} \exp(\widetilde{S}_b[h,u,t])}
$$

最终输出为：

$$
O_b[h,u,:] = \sum_{v=0}^{L_k^{(b)}-1} P_b[h,u,v] \, \widehat{V}_b[h,v,:]
$$

再把它从 $(H_q, L_q^{(b)}, D)$ 转回 $(L_q^{(b)}, H_q, D)$，并按 batch 顺序首尾拼接，得到总输出：

$$
\text{out} \in \mathbb{R}^{T_q \times H_q \times D}
$$

因此，本题需要同时正确处理四件事：用 `cu_q/cu_k` 切分变长样本、把张量转到 head 优先布局、按 GQA 扩展 KV 头、以及按可选 causal mask 完成 `softmax(QK^T/\sqrt{D})V`。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## PyTorch 参考实现

```python
def baseline(*inputs):
    q, k, v, cu_q, cu_k, out, total_tokens, num_heads, num_kv_heads, head_dim, max_seqlen, causal = inputs
    # Inline reference implementation (no direct torch_ref import).
    # Matches torch_ref.Model.forward exactly (dropout_p=0, softmax_scale=None):
    #   - split by cu_seqlens
    #   - transpose to (heads, seqlen, dim)
    #   - GQA: repeat_interleave heads if needed
    #   - scores = q @ k^T * scale
    #   - causal mask
    #   - softmax + matmul with v
    #   - concat outputs
    _ = total_tokens
    _ = num_heads
    _ = num_kv_heads
    _ = max_seqlen

    total_q, h_q, d = q.shape
    _, h_kv, _ = k.shape
    batch_size = cu_q.shape[0] - 1

    softmax_scale = 1.0 / math.sqrt(d)
    outputs = []
    for b in range(batch_size):
        start_q = int(cu_q[b].item())
        end_q = int(cu_q[b + 1].item())
        start_k = int(cu_k[b].item())
        end_k = int(cu_k[b + 1].item())

        q_b = q[start_q:end_q]  # (seqlen_q, h_q, d)
        k_b = k[start_k:end_k]  # (seqlen_k, h_kv, d)
        v_b = v[start_k:end_k]  # (seqlen_k, h_kv, d)

        seqlen_q = end_q - start_q
        seqlen_k = end_k - start_k

        q_b = q_b.transpose(0, 1)  # (h_q, seqlen_q, d)
        k_b = k_b.transpose(0, 1)  # (h_kv, seqlen_k, d)
        v_b = v_b.transpose(0, 1)  # (h_kv, seqlen_k, d)

        if h_q != h_kv:
            num_groups = h_q // h_kv
            k_b = k_b.repeat_interleave(num_groups, dim=0)
            v_b = v_b.repeat_interleave(num_groups, dim=0)

        scores = torch.matmul(q_b, k_b.transpose(-2, -1)) * softmax_scale
        if bool(causal):
            mask = torch.triu(torch.ones(seqlen_q, seqlen_k, device=q.device, dtype=torch.bool), diagonal=1)
            scores = scores.masked_fill(mask, float("-inf"))

        attn_weights = F.softmax(scores, dim=-1)
        output_b = torch.matmul(attn_weights, v_b).transpose(0, 1)  # (seqlen_q, h_q, d)
        outputs.append(output_b)

    ref = torch.cat(outputs, dim=0) if outputs else torch.empty((0, h_q, d), dtype=q.dtype, device=q.device)
    out.copy_(ref)
    return [q, k, v, cu_q, cu_k, out, total_tokens, num_heads, num_kv_heads, head_dim, max_seqlen, causal]
```
