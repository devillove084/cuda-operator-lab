# Top P Sampling from Logits

原题 https://xpuoj.com/p/125

## 题目描述

你需要实现当前题目定义下的 Top-p from logits。这里的 `top_p` **不是**标准意义上“按 softmax 累计概率截断”的 nucleus sampling；按照当前 `baseline()` 的真实语义，它是先把一整行 logits 按从大到小排序，再取长度为

$$
\text{prefix} = \left\lceil \text{top\_p} \cdot \text{vocab\_size} \right\rceil
$$

的前缀候选集合，最后再按固定哈希规则从这个前缀里选出一个下标。

设输入满足：

$$
\text{logits} \in \mathbb{R}^{B \times V}, \quad
\text{top\_p} \in \mathbb{R}^{B}
$$

其中 $B$ 是 batch size，$V$ 是词表大小。对第 $r$ 行，记：

$$
\ell_r \in \mathbb{R}^{V}, \quad p_r = \text{top\_p}[r]
$$

第一步，对该行做稳定降序排序，得到下标序列：

$$
I_r = \operatorname{Argsort}_{\downarrow,\text{stable}}(\ell_r)
$$

其中 `stable=True` 表示当两个 logits 相等时，要保持它们在原始词表中的先后顺序。

第二步，根据 `top_p` 计算保留前缀长度：

$$
n_r = \max\left(1,\; \min\left(V,\; \left\lceil p_r \cdot V \right\rceil\right)\right)
$$

于是该行真正保留的候选前缀为：

$$
C_r = [I_r[0], I_r[1], \dots, I_r[n_r-1]]
$$

第三步，同样不做随机采样，而是计算固定哈希：

$$
h_r = \operatorname{row\_hash}(r, n_r)
$$

`row_hash` 的定义如下，所有乘法和加法都按 32-bit unsigned 整数截断：

```python
def row_hash(row: int, count: int) -> int:
    x = ((row + 1) * 747796405 + (count + 1) * 2891336453) & 0xFFFFFFFF
    x ^= x >> 16
    x = (x * 2246822519) & 0xFFFFFFFF
    x ^= x >> 13
    x = (x * 3266489917) & 0xFFFFFFFF
    x ^= x >> 16
    return int(x)
```

并取模得到最终选中的前缀位置：

$$
j_r = h_r \bmod n_r
$$

于是输出为：

$$
\text{out}[r,0] = C_r[j_r]
$$

因此，本题可以总结为：

$$
\text{排序 logits} \to \text{截断固定长度前缀} \to \text{固定哈希选一个}
$$

而不是：

$$
\text{softmax} \to \text{累计概率超过 top\_p} \to \text{随机采样}
$$

这也是本题最容易与常见 Top-p / nucleus sampling 混淆的地方。你必须严格按当前 `baseline()` 的“排序 + 前缀长度 `ceil(top_p \cdot V)` + 确定性哈希”语义实现。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## PyTorch 参考实现

```python
def _row_hash(row: int, count: int) -> int:
    x = ((row + 1) * 747796405 + (count + 1) * 2891336453) & 0xFFFFFFFF
    x ^= x >> 16
    x = (x * 2246822519) & 0xFFFFFFFF
    x ^= x >> 13
    x = (x * 3266489917) & 0xFFFFFFFF
    x ^= x >> 16
    return int(x)


def baseline(*inputs):
    logits, top_p, out, batch_size, vocab_size = inputs
    for row in range(batch_size):
        row_vals = logits[row]
        sorted_idx = torch.argsort(row_vals, descending=True, stable=True)
        prefix = max(1, min(vocab_size, int(torch.ceil(top_p[row] * vocab_size).item())))
        pick = _row_hash(row, prefix) % prefix
        out[row, 0] = sorted_idx[pick].to(torch.int32)
    return [logits, top_p, out, batch_size, vocab_size]
```
