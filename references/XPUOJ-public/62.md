# GeMM Bias Softsign

原题 https://xpuoj.com/p/62

## 题目描述

你需要实现一个融合算子：

> **output = softsign(A @ B + bias)**

给定输入矩阵 `A` 和 `B`，其中 `A` 的 shape 为 `(M, K)`，`B` 的 shape 为 `(K, N)`，`bias` 的 shape 为 `(N,)`。

首先计算矩阵乘法：

$$
X = A @ B
$$

然后将 `bias` 按最后一维广播到每一行：

$$
Y_{i,j} = X_{i,j} + bias_j
$$

最后对每个元素施加 `softsign` 激活函数：

$$
output_{i,j} = \mathrm{softsign}(Y_{i,j}) = \frac{Y_{i,j}}{1 + |Y_{i,j}|}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述融合计算。

如何提交代码详见[评测指南](/d/2)。

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `A`：shape `(M, K)` 的 float32 矩阵
* `B`：shape `(K, N)` 的 float32 矩阵
* `bias`：shape `(N,)` 的 float32 向量
* `output`：shape `(M, N)` 的 float32 输出缓冲区，初始值未定义
* `M`：int64 标量，表示输出行数
* `K`：int64 标量，表示约简维度
* `N`：int64 标量，表示输出列数

## 输出格式

你需要将计算结果写入 `output` 指向的缓冲区，得到一个 shape 为 `(M, N)` 的 float32 矩阵。对于每个位置 `(i, j)`，输出应满足：

$$
output_{i,j} = \mathrm{softsign}\left(\sum_{t=0}^{K-1} A_{i,t} \cdot B_{t,j} + bias_j\right)
$$

其中：

$$
\mathrm{softsign}(x) = \frac{x}{1 + |x|}
$$

## 提示

* `bias` 的 shape 是 `(N,)`，会广播到输出矩阵的每一行
* 本题不是单纯的 GEMM，不能漏掉 `bias` 或 `softsign`
* 评测使用 `(torch.matmul(A, B) + bias) / (1 + abs(torch.matmul(A, B) + bias))` 作为参考实现

## PyTorch 参考实现

```python
def baseline(A, B, bias, output, M, K, N):
    """
    PyTorch 参考实现：output = softsign(A @ B + bias)

    参数说明：
    * A: 输入张量（float32），shape (M, K)
    * B: 输入张量（float32），shape (K, N)
    * bias: 输入张量（float32），shape (N,)
    * output: 输出张量（float32），shape (M, N)
    * M: 输出行数（int64）
    * K: 约简维度（int64）
    * N: 输出列数（int64）
    """
    tmp = torch.matmul(A, B) + bias
    output.copy_(tmp / (1.0 + tmp.abs()))
```
