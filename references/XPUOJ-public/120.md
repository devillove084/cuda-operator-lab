# MoE  Scatter Up GEMM

原题 https://xpuoj.com/p/120

## 题目描述

你需要实现 MoE 中的 `scatter + up GEMM`。输入给出了每个 token 被分配到的多个 expert 编号，你需要先把这些 `(token, topk_slot)` 对展开并按 expert 编号做稳定排序，再按 expert 批量收集对应 token，分别执行上投影矩阵乘法，最后把所有 expert 的结果按照这种排序后的顺序拼接到输出张量中。

设输入满足：

$$
X \in \mathbb{R}^{T \times H}, \quad
W \in \mathbb{R}^{E \times U \times H}, \quad
\text{expert\_indices} \in \{0,1,\dots,E-1\}^{T \times K}
$$

其中 $T$ 是 token 总数，$H$ 是输入隐藏维度，$U$ 是 up projection 的输出维度，$E$ 是 expert 数量，$K$ 是每个 token 选中的 expert 数，也就是 `topk`。

第一步是把 `expert_indices` 展平成长度为 $T \cdot K$ 的一维数组：

$$
f[r] = \text{expert\_indices}[t, k], \quad r = tK + k
$$

然后对这个一维数组做稳定排序，得到排序后的位置序列 `sorted_indices`。设：

$$
\pi(0), \pi(1), \dots, \pi(TK-1)
$$

表示这些排序后的一维下标，则对应的 expert 编号满足非降序排列：

$$
f[\pi(0)] \le f[\pi(1)] \le \dots \le f[\pi(TK-1)]
$$

并且当两个位置的 expert 编号相同时，稳定排序会保持它们在原始展平数组中的先后顺序。

对任意排序后位置 $\pi(r)$，它对应的 token 编号为：

$$
t_r = \left\lfloor \frac{\pi(r)}{K} \right\rfloor
$$

这正是 baseline 中

$$
\text{token\_indices} = \text{sorted\_indices} // \text{topk}
$$

的含义。

接下来，对每个 expert $e$，统计它在展平分配表中出现的次数：

$$
c_e = \#\{r \mid f[r] = e\}
$$

于是第 $e$ 个 expert 对应的 token 子块长度就是 $c_e$。设这些 token 在排序后序列中的连续区间为：

$$
\left[\sum_{j<e} c_j,\; \sum_{j\le e} c_j\right)
$$

则第 $e$ 个 expert 实际收集到的 token 子块为：

$$
X_e \in \mathbb{R}^{c_e \times H}
$$

其中第 $r$ 行对应原始输入中的某个 token：

$$
X_e[r,:] = X[t_r,:]
$$

第 $e$ 个 expert 的权重为：

$$
W_e \in \mathbb{R}^{U \times H}
$$

然后执行上投影矩阵乘法：

$$
Y_e = X_e W_e^T \in \mathbb{R}^{c_e \times U}
$$

按元素展开后：

$$
Y_e[i,u] = \sum_{h=0}^{H-1} X_e[i,h] \, W_e[u,h]
$$

所有 expert 的输出块最后按 expert 编号从小到大依次拼接：

$$
\text{output} = \operatorname{concat}(Y_0, Y_1, \dots, Y_{E-1}) \in \mathbb{R}^{T K \times U}
$$

因此，本题的关键不是简单做若干次 GEMM，而是要严格对齐 baseline 的 scatter 规则：先把 `(token, topk_slot)` 展平，再按 expert 编号稳定排序，再按排序结果批量收集 token，并按每个 expert 的顺序把 GEMM 结果拼回输出。

评测程序会调用你实现的 `run_kernel` 函数；你需要围绕上述数学定义组织计算，并把结果写回接口约定中的输出参数。

## PyTorch 参考实现

```python
def baseline(*inputs):
    input_tokens, expert_weights, expert_indices, output, total_tokens, hidden_dim, up_hidden_dim, num_experts, topk = inputs
    # Inline reference implementation (no direct torch_ref import).
    # Matches torch_ref.Model.forward exactly:
    #   - stable sort by flat expert indices
    #   - gather tokens by sorted_indices // topk
    #   - per-expert matmul and cat
    assert input_tokens.shape == (total_tokens, hidden_dim)
    assert expert_weights.shape == (num_experts, up_hidden_dim, hidden_dim)
    assert expert_indices.shape == (total_tokens, topk)

    flat_experts = expert_indices.reshape(-1)
    sorted_indices = torch.argsort(flat_experts, stable=True)
    token_indices = sorted_indices // topk
    counts = torch.bincount(flat_experts.to(torch.int64), minlength=int(num_experts))

    outs = []
    offset = 0
    for expert_idx in range(int(num_experts)):
        count = int(counts[expert_idx].item())
        if count > 0:
            expert_token_indices = token_indices[offset:offset + count]
            current_state = input_tokens[expert_token_indices]
            current_out = torch.matmul(current_state, expert_weights[expert_idx].transpose(0, 1))
            outs.append(current_out)
        else:
            outs.append(torch.empty(0, up_hidden_dim, dtype=input_tokens.dtype, device=input_tokens.device))
        offset += count

    ref = torch.cat(outs, dim=0)
    output.copy_(ref)
    return [input_tokens, expert_weights, expert_indices, output, total_tokens, hidden_dim, up_hidden_dim, num_experts, topk]
```
