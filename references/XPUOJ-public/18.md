# Fused SiLU and Mul

原题 https://xpuoj.com/p/18

## 题目描述

你需要实现一个融合 SiLU（Swish）和逐元素乘法的激活函数算子。该算子将输入沿最后一维切分为两半，对第一半应用 SiLU 激活函数，然后与第二半逐元素相乘。

具体来说，给定输入矩阵 $x$（shape 为 $(B, 2H)$，其中 $B$ 是 batch size，$2H$ 是特征维度），将其在最后一维上平均分成两半：

$$
x_1 = x[:, :H], \quad x_2 = x[:, H:]
$$

然后计算输出：

$$
y = \text{SiLU}(x_1) \odot x_2
$$

其中 $\odot$ 表示逐元素乘法（Hadamard 积），SiLU（Sigmoid Linear Unit）激活函数定义为：

$$
\text{SiLU}(z) = z \cdot \sigma(z) = \frac{z}{1 + e^{-z}}
$$

这里 $\sigma(\cdot)$ 是 sigmoid 函数：

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成融合 SiLU + Mul 计算。

如何提交代码详见[评测指南](/d/2)。

$$
y_{i,j} = \text{SiLU}(x_{i,j}) \cdot x_{i,j+H}

其中 $H = \text{hidden_size}$，$x_{i,j}$ 来自输入矩阵前半部分，$x_{i,j+H}$ 来自后半部分。

$$

## 样例

## 输入

`input`（shape $(2, 4)$，其中 $\text{batch_size}=2$，$\text{hidden_size}=2$）：

```
[[1.0, 2.0, 3.0, 4.0],
 [0.5, 1.5, 2.5, 3.5]]
```

该输入将在最后一维被分为两部分：
* $x_1$（前半部分）：`[[1.0, 2.0], [0.5, 1.5]]`
* $x_2$（后半部分）：`[[3.0, 4.0], [2.5, 3.5]]`

## 输出

`out`（shape $(2, 2)$）：

**计算过程**：

对于位置 $(0, 0)$：
* $\text{SiLU}(1.0) = 1.0 / (1 + e^{-1.0}) \approx 0.731$
* $y_{0,0} = 0.731 \times 3.0 \approx 2.193$

对于位置 $(0, 1)$：
* $\text{SiLU}(2.0) = 2.0 / (1 + e^{-2.0}) \approx 1.762$
* $y_{0,1} = 1.762 \times 4.0 \approx 7.048$

对于位置 $(1, 0)$：
* $\text{SiLU}(0.5) = 0.5 / (1 + e^{-0.5}) \approx 0.311$
* $y_{1,0} = 0.311 \times 2.5 \approx 0.778$

对于位置 $(1, 1)$：
* $\text{SiLU}(1.5) = 1.5 / (1 + e^{-1.5}) \approx 1.154$
* $y_{1,1} = 1.154 \times 3.5 \approx 4.039$

**输出结果**：

```
[[2.193, 7.048],
 [0.778, 4.039]]
```
（实际输出为 bfloat16，数值可能有精度差异）

## PyTorch 参考实现

```python
def baseline(input, out, batch_size, hidden_size):
    """
    PyTorch 参考实现：Fused SiLU and Mul
    
    参数说明：
    * input: 输入张量（bfloat16），shape (batch_size, 2*hidden_size)，行优先连续存储，只读
    * out: 输出张量（bfloat16），shape (batch_size, hidden_size)，行优先连续存储，需写入结果
    * batch_size: 第一维大小（int64）
    * hidden_size: 隐藏层大小（int64）
    """
    first_half = input[..., :hidden_size]
    second_half = input[..., hidden_size:]
    
    silu_result = torch.nn.functional.silu(first_half)
    result = silu_result * second_half
    
    out.copy_(result)
```
