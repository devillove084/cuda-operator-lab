# Conv3d Bias Relu

原题 https://xpuoj.com/p/67

## 题目描述

你需要实现一个 Conv3d + Bias + ReLU 融合算子。给定输入张量 `x`、三维卷积权重 `weight` 和偏置 `bias`，先执行三维卷积：

$$
conv\_out = conv3d(x, weight, bias, stride, padding)
$$

然后对卷积输出的每个元素施加 ReLU 激活，得到输出 `y`：

$$
y = \max(conv\_out, 0)
$$

本题中张量采用 NCDHW 连续存储。`weight` 的 shape 为 `(C_out, C_in, Kd, Kh, Kw)`。

卷积输出空间尺寸为：

$$
D_{out} = \left\lfloor \frac{D + 2 \cdot padding - K_d}{stride} \right\rfloor + 1
$$

$$
H_{out} = \left\lfloor \frac{H + 2 \cdot padding - K_h}{stride} \right\rfloor + 1
$$

$$
W_{out} = \left\lfloor \frac{W + 2 \cdot padding - K_w}{stride} \right\rfloor + 1
$$

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据数据规模计算合适的 launch 配置，并完成三维卷积、偏置加法和 ReLU。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* x,
    const __nv_bfloat16* weight,
    const __nv_bfloat16* bias,
    __nv_bfloat16* y,
    int64_t N,
    int64_t C_in,
    int64_t C_out,
    int64_t D,
    int64_t H,
    int64_t W,
    int64_t Kd,
    int64_t Kh,
    int64_t Kw,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `x`：输入指针（bfloat16），shape `(N, C_in, D, H, W)`，按 NCDHW 连续存储，只读
* `weight`：输入指针（bfloat16），shape `(C_out, C_in, Kd, Kh, Kw)`，只读
* `bias`：输入指针（bfloat16），shape `(C_out,)`，只读
* `y`：输出指针（bfloat16），shape `(N, C_out, D_out, H_out, W_out)`，按 NCDHW 连续存储，需写入结果
* `N`：batch 大小（int64）
* `C_in`：输入通道数（int64）
* `C_out`：输出通道数（int64）
* `D`、`H`、`W`：输入深度、高度、宽度（int64）
* `Kd`、`Kh`、`Kw`：卷积核深度、高度、宽度（int64）
* `stride`：卷积步长（int64）
* `padding`：零填充大小（int64）

`run_kernel` 内部需要完成以下工作：

* 根据 `D`、`H`、`W`、`Kd`、`Kh`、`Kw`、`stride`、`padding` 计算输出范围
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成融合计算

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：bfloat16 tensor，shape `(N, C_in, D, H, W)`
* `weight`：bfloat16 tensor，shape `(C_out, C_in, Kd, Kh, Kw)`
* `bias`：bfloat16 tensor，shape `(C_out,)`
* `y`：bfloat16 tensor，shape `(N, C_out, D_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, D, H, W, Kd, Kh, Kw, stride, padding`：int64 标量

其中输出空间大小满足：

```text
D_out = floor((D + 2 * padding - Kd) / stride + 1)
H_out = floor((H + 2 * padding - Kh) / stride + 1)
W_out = floor((W + 2 * padding - Kw) / stride + 1)
```

## 输出格式

你需要将计算结果写入 `y`，满足：

```text
tmp[n, c_out, d, h, w] = bias[c_out] + sum_{c_in, k_d, k_h, k_w}
    x[n, c_in, d * stride - padding + k_d,
      h * stride - padding + k_h,
      w * stride - padding + k_w]
    * weight[c_out, c_in, k_d, k_h, k_w]

y[n, c_out, d, h, w] = max(tmp[n, c_out, d, h, w], 0)
```

卷积累加使用 FP32 语义，最终输出为 bfloat16。

## 样例

## 输入

```text
N = 1
C_in = 2
C_out = 3
D = H = W = 4
Kd = Kh = Kw = 3
stride = 1
padding = 1
```

此时：

```text
D_out = (4 + 2 * 1 - 3) / 1 + 1 = 4
H_out = (4 + 2 * 1 - 3) / 1 + 1 = 4
W_out = (4 + 2 * 1 - 3) / 1 + 1 = 4
```

所以：

```text
x.shape = (1, 2, 4, 4, 4)
weight.shape = (3, 2, 3, 3, 3)
bias.shape = (3,)
y.shape = (1, 3, 4, 4, 4)
```

## 数据范围与提示

## 数据范围

* `x`、`weight`、`bias`、`y` 的数据类型均为 `torch.bfloat16`
* `x` 的 shape 为 `(N, C_in, D, H, W)`
* `weight` 的 shape 为 `(C_out, C_in, Kd, Kh, Kw)`
* `bias` 的 shape 为 `(C_out,)`
* `y` 的 shape 为 `(N, C_out, D_out, H_out, W_out)`
* 所有 tensor 均为连续存储（contiguous）
* $1 \le N \le 3$
* $C_{in} = 32$
* $C_{out} = 64$
* $20 \le D \le 48$
* $40 \le H \le 80$
* $40 \le W \le 80$
* $K_d = K_h = K_w = 3$
* `stride = 1`
* `padding = 1`

## 正确性要求

* 必须正确处理三维卷积计算
* 必须正确加上 `bias`
* 必须正确处理 `stride`
* 必须正确处理 `padding`
* 必须正确施加 ReLU
* 必须将结果写入 `y`
* 不允许修改 `x`、`weight` 和 `bias`

## 提示

* 本题不是单纯的 `conv3d`，不能漏掉 `bias` 或 ReLU
* 评测使用 `torch.nn.functional.relu(torch.nn.functional.conv3d(...))` 作为参考实现
* 输入输出均为 bfloat16，但卷积累加应按 FP32 处理

## PyTorch 参考实现

```python
def baseline(x, weight, bias, y, N, C_in, C_out, D, H, W, Kd, Kh, Kw, stride, padding):
    out = torch.nn.functional.conv3d(x.float(), weight.float(), bias.float(), stride, padding)
    y.copy_(torch.nn.functional.relu(out).to(torch.bfloat16))
```
