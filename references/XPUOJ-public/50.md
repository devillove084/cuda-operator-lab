# Depthwise Conv2d F16

原题 https://xpuoj.com/p/50

## 题目描述

你需要实现一个 FP16 精度的二维 depthwise convolution 前向传播算子：

> **output = depthwise_conv2d(x, weight, bias, stride, padding)**

给定输入张量 $x$（shape 为 $(N, C, H, W)$）、卷积核 $weight$（shape 为 $(C, 1, R, S)$）和偏置 $bias$（shape 为 $(C,)$），计算输出张量 $output$。本题中每个输入通道独立卷积，等价于 PyTorch `torch.nn.functional.conv2d(..., groups=C)`。

输出空间尺寸为：

$$
H_{out} = \left\lfloor\frac{H + 2 \times padding - R}{stride}\right\rfloor + 1
$$

$$
W_{out} = \left\lfloor\frac{W + 2 \times padding - S}{stride}\right\rfloor + 1
$$

对于输出位置 $(n, c, h, w)$，计算方式为：

$$
output_{n,c,h,w} = bias_c + \sum_{r=0}^{R-1}\sum_{s=0}^{S-1} x_{n,c,h \times stride - padding + r,w \times stride - padding + s} \cdot weight_{c,0,r,s}
$$

其中只有落在输入范围内的位置才参与累加。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述 depthwise convolution 计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_fp16.h>

extern "C" void run_kernel(
    const half* x,
    const half* weight,
    const half* bias,
    half* output,
    int64_t N,
    int64_t C,
    int64_t H,
    int64_t W,
    int64_t R,
    int64_t S,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `x`：输入指针（float16），shape $(N, C, H, W)$，行优先连续存储，只读
* `weight`：输入指针（float16），shape $(C, 1, R, S)$，行优先连续存储，只读
* `bias`：输入指针（float16），shape $(C,)$，连续存储，只读
* `output`：输出指针（float16），shape $(N, C, H_{out}, W_{out})$，行优先连续存储，需写入计算结果
* `N`：batch size（int64）
* `C`：通道数，也是 depthwise convolution 的 groups 数量（int64）
* `H`：输入高度（int64）
* `W`：输入宽度（int64）
* `R`：卷积核高度（int64）
* `S`：卷积核宽度（int64）
* `stride`：步长（int64）
* `padding`：填充大小（int64）

`run_kernel` 内部需要完成以下工作：

* 根据输入尺寸计算 $H_{out}$ 和 $W_{out}$
* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 depthwise convolution 计算

## 计算过程说明

本题固定为 depthwise convolution，因此第 $c$ 个输入通道只与 `weight[c, 0, :, :]` 做二维卷积，并写入第 $c$ 个输出通道。不同通道之间不会互相累加。

## 数据范围与提示

## 数据范围

* `x`、`weight`、`bias`、`output` 的数据类型均为 `torch.float16`
* `x` 的 shape 为 $(N, C, H, W)$
* `weight` 的 shape 为 $(C, 1, R, S)$
* `bias` 的 shape 为 $(C,)$
* `output` 的 shape 为 $(N, C, H_{out}, W_{out})$
* 所有 tensor 均为连续存储（contiguous）
* $8 \le N \le 32$
* $64 \le C \le 384$
* $128 \le H \le 320$
* $128 \le W \le 320$
* $1 \le R,S \le 5$
* $stride \in \{1, 2, 3\}$
* $0 \le padding \le 2$

## 正确性要求

* 必须正确计算 $H_{out}$ 和 $W_{out}$
* 必须正确处理 `stride` 和 `padding`
* 必须固定以 `groups = C` 执行 depthwise convolution
* 必须正确按通道独立卷积
* 必须正确加上 `bias`
* 必须将结果写入 `output`
* 不允许修改 `x`、`weight` 和 `bias`

## 提示

* `weight` 的第二维固定为 1
* depthwise convolution 等价于 `torch.nn.functional.conv2d(x, weight, bias, stride, padding, groups=C)`
* 建议使用 float32 累加后再写回 float16 输出

## PyTorch 参考实现

# PyTorch 参考实现

```python
import torch.nn.functional as F


def baseline(x, weight, bias, output, N, C, H, W, R, S, stride, padding):
    """
    PyTorch 参考实现：FP16 depthwise conv2d

    参数说明：
    * x: 输入张量（float16），shape (N, C, H, W)，行优先连续存储，只读
    * weight: 输入张量（float16），shape (C, 1, R, S)，行优先连续存储，只读
    * bias: 输入张量（float16），shape (C)，连续存储，只读
    * output: 输出张量（float16），shape (N, C, H_out, W_out)，行优先连续存储，需写入结果
    * N, C, H, W, R, S, stride, padding: 维度参数（int64）
    """
    output.copy_(F.conv2d(x.half(), weight.half(), bias.half(), stride, padding, groups=C))
```
