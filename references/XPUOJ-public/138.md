# Einsum Bmm

原题 https://xpuoj.com/p/138

## 题目描述

你需要实现一个 bfloat16 精度的批量矩阵乘法算子，对应 einsum 表达式：

> **out = torch.einsum('bik,bkj->bij', a, b)**

给定输入张量 `a`（shape 为 $(B, I, K)$）和 `b`（shape 为 $(B, K, J)$），对每个 batch 独立计算矩阵乘法，得到输出张量 `out`（shape 为 $(B, I, J)$）。具体计算方式为：

$$
out_{batch,i,j} = \sum_{k=0}^{K-1} a_{batch,i,k} \cdot b_{batch,k,j}
$$

其中 $batch \in [0, B)$，$i \in [0, I)$，$j \in [0, J)$，$\cdot$ 表示逐元素乘法。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述批量矩阵乘法。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* a,
    const __nv_bfloat16* b,
    __nv_bfloat16* out,
    int64_t B,
    int64_t I,
    int64_t K,
    int64_t J
);
```

### 参数说明

* `a`：输入指针（bfloat16），shape $(B, I, K)$，连续存储，只读
* `b`：输入指针（bfloat16），shape $(B, K, J)$，连续存储，只读
* `out`：输出指针（bfloat16），shape $(B, I, J)$，连续存储，需写入计算结果
* `B`：batch 数量（int64）
* `I`：`a` 的第 2 维，也是 `out` 的第 2 维（int64）
* `K`：规约维度，`a` 的第 3 维，也是 `b` 的第 2 维（int64）
* `J`：`b` 的第 3 维，也是 `out` 的第 3 维（int64）

`run_kernel` 内部需要完成以下工作：

* 根据张量尺寸计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 `bik,bkj->bij` 的计算

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `a`：bfloat16 tensor，shape $(B, I, K)$，连续存储
* `b`：bfloat16 tensor，shape $(B, K, J)$，连续存储
* `out`：bfloat16 tensor，shape $(B, I, J)$，作为输出缓冲区
* `B`：int64 标量，表示 batch 数量
* `I`：int64 标量，表示输出每个 batch 的行数
* `K`：int64 标量，表示规约维度
* `J`：int64 标量，表示输出每个 batch 的列数

## 输出格式

你需要将计算结果写入 `out` 指向的缓冲区，得到一个 shape 为 $(B, I, J)$ 的 bfloat16 张量，满足：

$$
out_{batch,i,j} = \sum_{k=0}^{K-1} a_{batch,i,k} \cdot b_{batch,k,j}
$$

## 计算过程说明

对每个 batch 独立执行矩阵乘法：

```text
out[batch] = a[batch] @ b[batch]
```

## 数据范围与提示

## 数据范围

* `a`、`b`、`out` 的数据类型均为 `torch.bfloat16`
* `a` 的 shape 为 $(B, I, K)$
* `b` 的 shape 为 $(B, K, J)$
* `out` 的 shape 为 $(B, I, J)$
* 所有 tensor 均为连续存储（contiguous）
* $1 \le B \le 16$
* $1 \le I \le 1537$
* $1 \le K \le 2049$
* $1 \le J \le 1536$

## 正确性要求

* 必须对每个 batch 独立计算矩阵乘法
* 必须正确沿 `K` 维度做规约求和
* 必须将最终结果写入 `out`
* 不允许修改 `a` 和 `b`

## 提示

* `a` 的布局是 $(B, I, K)$，`b` 的布局是 $(B, K, J)$
* 每个 batch 的计算互相独立，不需要跨 batch 规约
* 本题等价于 `torch.bmm(a, b)`
