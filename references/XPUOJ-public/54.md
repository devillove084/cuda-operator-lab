# Conv2d Fprop S4

原题 https://xpuoj.com/p/54

## 题目描述

你需要实现一个 2D 卷积前向传播算子，其输入和权重使用 `s4` 数值范围：

> **output = conv2d(x, weight, bias, stride, padding)**

给定输入张量 `x`、卷积核 `weight`、偏置 `bias`、步长 `stride` 和填充 `padding`，你需要计算一个标准的 `conv2d`。

原始算子的数学语义使用 `INT4` 输入与权重。为了适配 OJ，本题采用如下简化映射：

* `x` 的类型为 `int8`，但其数值范围限制在 `[-8, 7]`，用来模拟 `s4`
* `weight` 的类型为 `int8`，但其数值范围限制在 `[-8, 7]`，用来模拟 `s4`
* `bias` 的类型为 `float32`
* `output` 的类型为 `float32`

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 `s4` 风格 `conv2d` 的前向传播。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const int8_t* x,
    const int8_t* weight,
    const float* bias,
    float* output,
    int64_t N,
    int64_t C_in,
    int64_t C_out,
    int64_t H,
    int64_t W,
    int64_t R,
    int64_t S,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `x`：输入指针，shape `(N, C_in, H, W)`，类型为 int8，数值范围位于 `[-8, 7]`
* `weight`：输入指针，shape `(C_out, C_in, R, S)`，类型为 int8，数值范围位于 `[-8, 7]`
* `bias`：输入指针，shape `(C_out,)`，类型为 float32
* `output`：输出指针，shape `(N, C_out, H_out, W_out)`，类型为 float32
* `N`、`C_in`、`C_out`、`H`、`W`、`R`、`S`、`stride`、`padding`：对应的尺寸参数

`run_kernel` 内部需要完成以下工作：

* 根据输入尺寸计算输出形状
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成卷积前向传播

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：int8 tensor，shape `(N, C_in, H, W)`，数值范围 `[-8, 7]`
* `weight`：int8 tensor，shape `(C_out, C_in, R, S)`，数值范围 `[-8, 7]`
* `bias`：float32 tensor，shape `(C_out,)`
* `output`：float32 tensor，shape `(N, C_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, H, W, R, S, stride, padding`：int64 标量

## 输出格式

输出张量满足：

```text
H_out = floor((H + 2 * padding - R) / stride + 1)
W_out = floor((W + 2 * padding - S) / stride + 1)

output[n, c_out, h, w] =
    bias[c_out] +
    sum_{c_in, k_h, k_w}
        float(x[n, c_in, h * stride - padding + k_h, w * stride - padding + k_w])
        * float(weight[c_out, c_in, k_h, k_w])
```
