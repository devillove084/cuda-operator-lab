# GEMM Bias PReLU

原题 https://xpuoj.com/p/142

## 题目描述

你需要实现一个 GEMM + Bias + PReLU 融合算子。给定输入矩阵 `a`、权重矩阵 `b`、偏置向量 `bias` 和 PReLU 权重向量 `prelu_weight`，先计算矩阵乘法并加上偏置，再逐元素应用 PReLU 激活函数：

$$
C = a \times b + bias
$$

$$
out = \max(C, 0) + prelu\_weight \cdot \min(C, 0)
$$

其中 `a` 的 shape 为 $(M, K)$，`b` 的 shape 为 $(K, N)$，`bias` 和 `prelu_weight` 的 shape 均为 $(N,)$，会按列广播到输出矩阵，`out` 的 shape 为 $(M, N)$。

逐元素写为：

$$
C_{i,j} = \sum_{k=0}^{K-1} a_{i,k} \cdot b_{k,j} + bias_j
$$

$$
out_{i,j} = \begin{cases}
C_{i,j}, & C_{i,j} \ge 0 \\
prelu\_weight_j \cdot C_{i,j}, & C_{i,j} < 0
\end{cases}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](/d/2)。

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

* `M`：输入矩阵 `a` 的行数，也是 `out` 的行数（int64）

## 计算过程说明


## 数据范围与提示

## 数据范围

* `a`、`b`、`bias`、`out` 的数据类型均为 `torch.bfloat16`
* `prelu_weight` 的数据类型为 `torch.float32`
* `a` 的 shape 为 $(M, K)$
* `b` 的 shape 为 $(K, N)$
* `bias` 的 shape 为 $(N,)$
* `prelu_weight` 的 shape 为 $(N,)$

* $1 \le N \le 4096$

## 正确性要求

* 必须正确实现矩阵乘法 `a @ b`
* 必须正确按列广播 `bias` 和 `prelu_weight`
* 必须正确应用 PReLU 激活函数
* 必须将最终结果写入 `out`
* 不允许修改 `a`、`b`、`bias` 和 `prelu_weight`

## 提示

* `bias` 和 `prelu_weight` 都是长度为 $N$ 的一维向量，需要对所有 $M$ 行复用
* `b` 的布局是 $(K, N)$，本题计算的是标准矩阵乘法 `a @ b`

## PyTorch 参考实现

```python
def baseline(a, b, bias, prelu_weight, out, M, K, N):
    c = torch.matmul(a.float(), b.float()) + bias.float().view(1, N)
    y = torch.where(c >= 0, c, prelu_weight.float().view(1, N) * c)
    out.copy_(y.to(torch.bfloat16))
```
