# Smooth L1 Loss

原题 https://xpuoj.com/p/76

## 题目描述

你需要实现一个 `Smooth L1 Loss` 算子：

> **loss = mean(smooth_l1(pred, target, beta))**

给定输入矩阵 `pred`、`target`（shape 均为 $(M, N)$）以及一个标量 `beta`，你需要逐元素计算 Smooth L1 损失，并对所有元素取平均，得到一个标量输出 `loss`。

对于任意位置 $(i, j)$，令：

$$
d_{i,j} = |pred_{i,j} - target_{i,j}|
$$

则单个位置的 Smooth L1 损失定义为：

$$
l_{i,j} =
\begin{cases}
0.5 \cdot d_{i,j}^2 / \beta, & d_{i,j} < \beta \\
d_{i,j} - 0.5 \cdot \beta, & d_{i,j} \ge \beta
\end{cases}
$$

最终输出为：

$$
loss = \frac{1}{M \times N} \sum_{i=0}^{M-1} \sum_{j=0}^{N-1} l_{i,j}
$$

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成逐元素 Smooth L1 损失的计算以及最终均值归约。

如何提交代码详见[评测指南](/d/2)。

## 计算过程说明

先计算逐元素差值绝对值：

```text
diff =
[
  [0.5, 1.0],
  [1.0, 2.0]
]
```

由于 `beta = 1.0`，逐元素损失为：

* 对于 `0.5`：`0.5 * 0.5^2 / 1.0 = 0.125`
* 对于 `1.0`：`1.0 - 0.5 * 1.0 = 0.5`
* 对于 `1.0`：`1.0 - 0.5 * 1.0 = 0.5`
* 对于 `2.0`：`2.0 - 0.5 * 1.0 = 1.5`

所以：

```text
pointwise_loss =
[
  [0.125, 0.5],
  [0.5, 1.5]
]
```

最终取平均：

$$
loss = (0.125 + 0.5 + 0.5 + 1.5) / 4 = 0.65625
$$

## PyTorch 参考实现

```python
def baseline(pred, target, loss, beta, M, N):
    diff = (pred.float() - target.float()).abs()
    pointwise = torch.where(diff < beta, 0.5 * diff * diff / beta, diff - 0.5 * beta)
    loss.copy_(pointwise.mean())
```
