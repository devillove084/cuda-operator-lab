# Linear Cross Entropy

原题 https://xpuoj.com/p/81

## 题目描述

你需要实现融合的 Linear Cross Entropy。

输入 `x` 的 shape 为 `(B_L, d)`，权重 `weight` 的 shape 为 `(V, d)`，标签 `target` 的 shape 为 `(B_L,)`。输出 `loss` 是一个 `float32` 标量。

首先计算 logits：

$$
z = x weight^T
$$

然后对每一行做数值稳定的 log-softmax：

$$
\log p_i(c) = z_{i,c} - \max_j z_{i,j} - \log\sum_j \exp(z_{i,j} - \max_j z_{i,j})
$$

最后按标签取负对数似然并求平均：

$$
loss = \frac{1}{B_L}\sum_{i=0}^{B_L-1} -\log p_i(target_i)
$$

题目中传入的 `bias` 是占位张量，baseline 不使用它。你需要把平均损失写入标量输出 `loss`。如何提交代码详见[评测指南](/d/2)。

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    x, weight, bias, target, loss_out, B_L, d, V = inputs

    assert torch.is_tensor(x) and torch.is_tensor(weight) and torch.is_tensor(target)
    assert x.shape == (B_L, d)
    assert weight.shape == (V, d)
    assert target.shape == (B_L,)

    y = x @ weight.t()
    y = y.float()

    log_max = y.amax(dim=1, keepdim=True)
    y_exp = torch.exp(y - log_max)
    sum_y_exp = y_exp.sum(dim=1, keepdim=True)
    log_sum = torch.log(sum_y_exp)
    log_probs = y - log_max - log_sum

    loss = -log_probs.gather(1, target.unsqueeze(1)).squeeze(1)
    loss_mean = loss.mean()

    if loss_out is not None and torch.is_tensor(loss_out):
        loss_out.copy_(loss_mean)

    return [x, weight, bias, target, loss_out, B_L, d, V]
```
