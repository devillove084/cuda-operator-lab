# Conv3d Fprop Broadcast

原题 https://xpuoj.com/p/48

## 题目描述

你需要实现一个带 broadcast 逐元素加法的 3D 卷积前向传播算子：

> **output = conv3d(x, weight, bias, stride, padding) + broadcast**

给定输入张量 `x`、卷积核 `weight`、偏置 `bias`、额外输入 `broadcast`、步长 `stride` 和填充 `padding`，你需要计算一个标准的 3D convolution forward，再与 `broadcast` 做逐元素相加。

为了适配 OJ，本题固定要求传入 `bias` 和 `broadcast`，并使用 PyTorch 的 `torch.nn.functional.conv3d` 作为参考语义：

* 输入、权重、偏置、broadcast 都使用 `torch.bfloat16`
* 卷积内部按 `float32` 语义参考实现
* 输出写入 `torch.bfloat16` 张量
* 结果按 `allclose` 容差校验，不要求逐 bit 完全一致

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 3D 卷积前向传播与 broadcast 加法。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const __nv_bfloat16* x,
    const __nv_bfloat16* weight,
    const __nv_bfloat16* bias,
    const __nv_bfloat16* broadcast,
    __nv_bfloat16* output,

    int64_t S,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `x`：输入指针，shape `(N, C_in, D, H, W)`，类型为 bfloat16
* `weight`：输入指针，shape `(C_out, C_in, T, R, S)`，类型为 bfloat16
* `bias`：输入指针，shape `(C_out,)`，类型为 bfloat16
* `broadcast`：输入指针，shape `(N, C_out, D_out, H_out, W_out)`，类型为 bfloat16
* `output`：输出指针，shape `(N, C_out, D_out, H_out, W_out)`，类型为 bfloat16
* `N`：batch size
* `C_in`：输入通道数
* `C_out`：输出通道数
* `D`、`H`、`W`：输入深度、高度、宽度
* `T`、`R`、`S`：卷积核在深度、高度、宽度方向的大小
* `stride`：步长
* `padding`：零填充大小

`run_kernel` 内部需要完成以下工作：

* 根据输入尺寸计算输出形状
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成 3D 卷积前向传播与 broadcast 加法

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：bfloat16 tensor，shape `(N, C_in, D, H, W)`
* `weight`：bfloat16 tensor，shape `(C_out, C_in, T, R, S)`
* `bias`：bfloat16 tensor，shape `(C_out,)`
* `broadcast`：bfloat16 tensor，shape `(N, C_out, D_out, H_out, W_out)`
* `output`：bfloat16 tensor，shape `(N, C_out, D_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, D, H, W, T, R, S, stride, padding`：int64 标量

## 输出格式

输出张量满足：

```text
D_out = floor((D + 2 * padding - T) / stride + 1)
H_out = floor((H + 2 * padding - R) / stride + 1)
W_out = floor((W + 2 * padding - S) / stride + 1)

temp[n, c_out, d, h, w] =
    bias[c_out] +
    sum_{c_in, k_d, k_h, k_w}
        x[n, c_in, d * stride - padding + k_d, h * stride - padding + k_h, w * stride - padding + k_w]
        * weight[c_out, c_in, k_d, k_h, k_w]

output[n, c_out, d, h, w] = temp[n, c_out, d, h, w] + broadcast[n, c_out, d, h, w]
```

## 样例

## 输入

```text
N = 1
C_in = 1
C_out = 1
D = H = W = 3
T = R = S = 3
stride = 1
padding = 1
```

此时：

```text
D_out = (3 + 2 * 1 - 3) / 1 + 1 = 3
H_out = (3 + 2 * 1 - 3) / 1 + 1 = 3
W_out = (3 + 2 * 1 - 3) / 1 + 1 = 3
```

所以：

```text
temp.shape = (1, 1, 3, 3, 3)
broadcast.shape = (1, 1, 3, 3, 3)
output.shape = (1, 1, 3, 3, 3)
```

卷积先生成一个 `(1, 1, 3, 3, 3)` 的中间结果，然后再与同形状的 `broadcast` 逐元素相加，得到最终输出。

## PyTorch 参考实现

```python
def baseline(x, weight, bias, broadcast, output, N, C_in, C_out, D, H, W, T, R, S, stride, padding):
    temp = torch.nn.functional.conv3d(
        x.float(),
        weight.float(),
        bias.float(),
        stride,
        padding,
    ).to(output.dtype)
    output.copy_(temp + broadcast)
```
