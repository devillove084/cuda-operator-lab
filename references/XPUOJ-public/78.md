# Label Smoothing Loss

原题 https://xpuoj.com/p/78

## 题目描述

你需要实现一个 `Label Smoothing Loss` 算子：

> **loss = -mean(sum(smooth_target * log_softmax(input), dim=-1))**

给定输入矩阵 `input`（shape 为 $(N, C)$）、类别索引 `target`（shape 为 $(N,)$）以及一个标量 `smoothing`，你需要先根据 `target` 构造平滑标签分布 `smooth_target`，再与 `log_softmax(input)` 计算交叉熵，最后对所有样本取平均，得到一个标量输出 `loss`。

对第 `i` 个样本，平滑标签的构造方式为：

$$
smooth\_target_{i,j} =
\begin{cases}
1 - smoothing, & j = target_i \\
\frac{smoothing}{C - 1}, & j \ne target_i
\end{cases}
$$

然后计算：

$$
loss = -\frac{1}{N} \sum_{i=0}^{N-1} \sum_{j=0}^{C-1} smooth\_target_{i,j} \cdot \log\_softmax(input)_{i,j}
$$

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 `log_softmax`、label smoothing 以及最终均值归约。

如何提交代码详见[评测指南](/d/2)。



再对每一行计算 `log_softmax(input)`，然后与对应的平滑标签逐元素相乘并求和，最后对两个样本取平均，可得到约 `1.5468` 的结果。

## PyTorch 参考实现

```python
def baseline(input, target, loss, smoothing, N, C):
    log_preds = torch.nn.functional.log_softmax(input.float(), dim=-1)
    true_dist = torch.full_like(log_preds, smoothing / (C - 1))
    true_dist.scatter_(1, target.unsqueeze(1), 1.0 - smoothing)
    loss.copy_((-(true_dist * log_preds).sum(dim=-1)).mean())
```
