# Min-p Sampling from Logits

原题 https://xpuoj.com/p/127

## 题目描述

你需要实现当前题目定义下的 Min-p from logits。对每一行 logits，先找到该行最大值 `max_logit`，再根据

$$
\text{threshold} = \text{max\_logit} + \log(\text{min\_p})
$$

构造一个对数阈值，只保留满足 `logit >= threshold` 的候选下标。最后同样不是随机采样，而是按题目给定的固定哈希规则，从这些保留候选中确定性地选出一个索引写回输出。

设输入满足：

$$
\text{logits} \in \mathbb{R}^{B \times V}, \quad
\text{min\_p} \in \mathbb{R}^{B}
$$

其中 $B$ 是 batch size，$V$ 是词表大小。对第 $r$ 行，记：

$$
\ell_r \in \mathbb{R}^{V}, \quad p_r = \text{min\_p}[r]
$$

第一步，找到该行 logits 的最大值：

$$
m_r = \max_{0 \le j < V} \ell_r[j]
$$

第二步，构造对数阈值：

$$
\tau_r = m_r + \log(p_r)
$$

然后保留所有满足

$$
\ell_r[j] \ge \tau_r
$$

的词表下标。于是该行的候选集合为：

$$
C_r = \{\, j \mid \ell_r[j] \ge \tau_r \,\}
$$

baseline 中使用：

```python
indices = torch.nonzero(row_vals >= threshold).flatten()
```

因此这些下标会按照词表原始顺序从小到大排列，而不是按 logits 大小重新排序。

记候选数量为：

$$
n_r = |C_r|
$$

第三步，计算固定哈希：

$$
h_r = \operatorname{row\_hash}(r, n_r)
$$

`row_hash` 的定义如下，所有乘法和加法都按 32-bit unsigned 整数截断：

```python
def row_hash(row: int, count: int) -> int:
    x = ((row + 1) * 747796405 + (count + 1) * 2891336453) & 0xFFFFFFFF
    x ^= x >> 16
    x = (x * 2246822519) & 0xFFFFFFFF
    x ^= x >> 13
    x = (x * 3266489917) & 0xFFFFFFFF
    x ^= x >> 16
    return int(x)
```

再取模得到最终选择的位置：

$$
j_r = h_r \bmod n_r
$$

最终输出为：

$$
\text{out}[r,0] = C_r[j_r]
$$

因此，本题的真实语义是：

$$
\text{按 } \max(\text{logits}) + \log(\text{min\_p}) \text{ 构造阈值}
$$

$$
\to \text{保留所有未低于阈值的原始词表下标}
$$

$$
\to \text{按固定哈希在这些下标中选一个}
$$

它既不是 softmax 概率上的 min-p 采样，也不是随机采样；你必须严格对齐当前 `baseline()` 的“阈值过滤 + 原顺序候选集合 + 确定性哈希选择”规则。

## PyTorch 参考实现

```python
def _row_hash(row: int, count: int) -> int:
    x = ((row + 1) * 747796405 + (count + 1) * 2891336453) & 0xFFFFFFFF
    x ^= x >> 16
    x = (x * 2246822519) & 0xFFFFFFFF
    x ^= x >> 13
    x = (x * 3266489917) & 0xFFFFFFFF
    x ^= x >> 16
    return int(x)


def baseline(*inputs):
    logits, min_p, out, batch_size, vocab_size = inputs
    for row in range(batch_size):
        row_vals = logits[row]
        max_logit = row_vals.max()
        threshold = max_logit + torch.log(min_p[row])
        indices = torch.nonzero(row_vals >= threshold, as_tuple=False).flatten().to(torch.int32)
        count = int(indices.numel())
        pick = _row_hash(row, count) % count
        out[row, 0] = indices[pick]
    return [logits, min_p, out, batch_size, vocab_size]
```
