# Conv3d Fprop TF32 SM90

原题 https://xpuoj.com/p/30

## 题目描述

你需要实现一个 3D 卷积前向传播算子：

> **output = conv3d(x, weight, bias, stride, padding)**

给定输入张量 `x`、卷积核 `weight`、偏置 `bias`、步长 `stride` 和填充 `padding`，你需要计算一个标准的 3D convolution forward。

为了适配 OJ，评测时以普通 `float32` 数学语义为准，也就是说：

* 输入、权重、偏置都按 `float32` 参与计算
* 累加精度按 `float32` 处理
* 输出写入 `float32` 张量

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成 3D 卷积前向传播。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const float* x,
    const float* weight,
    const float* bias,
    float* output,
    int64_t N,
    int64_t C_in,
    int64_t C_out,
    int64_t D,
    int64_t H,
    int64_t W,
    int64_t T,
    int64_t R,
    int64_t S,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `x`：输入指针，shape `(N, C_in, D, H, W)`，类型为 float32
* `weight`：输入指针，shape `(C_out, C_in, T, R, S)`，类型为 float32
* `bias`：输入指针，shape `(C_out,)`，类型为 float32
* `output`：输出指针，shape `(N, C_out, D_out, H_out, W_out)`，类型为 float32
* `N`：batch size
* `C_in`：输入通道数
* `C_out`：输出通道数
* `D`、`H`、`W`：输入深度、高度、宽度
* `T`、`R`、`S`：卷积核在深度、高度、宽度方向的大小
* `stride`：步长
* `padding`：零填充大小

`run_kernel` 内部需要完成以下工作：

* 根据张量尺寸计算输出形状
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成 3D 卷积前向传播

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：float32 tensor，shape `(N, C_in, D, H, W)`
* `weight`：float32 tensor，shape `(C_out, C_in, T, R, S)`
* `bias`：float32 tensor，shape `(C_out,)`
* `output`：float32 tensor，shape `(N, C_out, D_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, D, H, W, T, R, S, stride, padding`：int64 标量

## 输出格式

输出张量满足：

```text
D_out = floor((D + 2 * padding - T) / stride + 1)
H_out = floor((H + 2 * padding - R) / stride + 1)
W_out = floor((W + 2 * padding - S) / stride + 1)

output[n, c_out, d, h, w] =
    sum_{c_in, k_d, k_h, k_w}
        x[n, c_in, d * stride - padding + k_d, h * stride - padding + k_h, w * stride - padding + k_w]
        * weight[c_out, c_in, k_d, k_h, k_w]
    + bias[c_out]
```

## 样例

## 输入

```text
N = 1
C_in = 1
C_out = 1
D = H = W = 3
T = R = S = 3
stride = 1
padding = 0
```

此时：

```text
D_out = (3 + 0 - 3) / 1 + 1 = 1
H_out = (3 + 0 - 3) / 1 + 1 = 1
W_out = (3 + 0 - 3) / 1 + 1 = 1
```

所以输出张量形状为：

```text
output.shape = (1, 1, 1, 1, 1)
```

该唯一位置的输出值，等于输入体与卷积核对应位置逐元素乘加后，再加上偏置：

```text
output[0, 0, 0, 0, 0] =
    sum_{k_d, k_h, k_w} x[0, 0, k_d, k_h, k_w] * weight[0, 0, k_d, k_h, k_w]
    + bias[0]
```

## 提示

* 可以先按输出坐标 `(n, c_out, d, h, w)` 遍历，再回溯输入窗口
* 对于越界的输入坐标，需要视为 padding 区域并跳过
* 即使题目背景提到 TF32，OJ 仍按 `float32` 数学语义校验结果
