# Top K Sampling from Logits

原题 https://xpuoj.com/p/124

## 题目描述

你需要实现基于 logits 的 Top-k 选样。对每一行 logits，先找出分数最高的 `k` 个候选索引，然后不是按概率随机采样，而是按照题目给定的**确定性哈希规则**，在这 `k` 个候选中固定选出 1 个索引写回输出。

设输入满足：

$$
\text{logits} \in \mathbb{R}^{B \times V}, \quad
\text{top\_k} \in \mathbb{Z}^{B}
$$

其中 $B$ 是 batch size，$V$ 是词表大小。对第 $r$ 行，记：

$$
\ell_r \in \mathbb{R}^{V}, \quad k_r = \text{top\_k}[r]
$$

第一步，在词表维上找出该行 logits 最大的前 $k_r$ 个候选。baseline 实际上先统一求出每一行前

$$
k_{\max} = \max_r k_r
$$

个下标：

$$
I_r = \operatorname{TopKIndices}(\ell_r, k_{\max})
$$

然后对第 $r$ 行只使用它的前 $k_r$ 个元素，也就是候选集合：

$$
C_r = [I_r[0], I_r[1], \dots, I_r[k_r-1]]
$$

这里的顺序是按 logits 从大到小的顺序排列。

第二步，不做随机采样，而是对行号 `row=r` 和候选数 `count=k_r` 计算一个固定哈希值：

$$
h_r = \operatorname{row\_hash}(r, k_r)
$$

`row_hash` 的定义如下，所有乘法和加法都按 32-bit unsigned 整数截断：

```python
def row_hash(row: int, count: int) -> int:
    x = ((row + 1) * 747796405 + (count + 1) * 2891336453) & 0xFFFFFFFF
    x ^= x >> 16
    x = (x * 2246822519) & 0xFFFFFFFF
    x ^= x >> 13
    x = (x * 3266489917) & 0xFFFFFFFF
    x ^= x >> 16
    return int(x)
```

然后取模得到要选的候选位置：

$$
p_r = h_r \bmod k_r
$$

最终输出为：

$$
\text{out}[r,0] = C_r[p_r]
$$

因此，本题可以概括为：

$$
\text{out}[r,0]
=
\operatorname{TopKIndices}(\ell_r, k_{\max})\left[\operatorname{row\_hash}(r, k_r) \bmod k_r\right]
$$

本题最关键的点有两个：

$$
\text{不是 softmax 采样，也不是随机采样}
$$

而是

$$
\text{Top-k 候选集合} + \text{固定哈希位置选择}
$$

并且 `top_k` 是逐行不同的，因此每一行真正参与选择的候选长度也不同，必须严格对齐 `baseline()` 的规则。

## PyTorch 参考实现

```python
def _row_hash(row: int, count: int) -> int:
    x = ((row + 1) * 747796405 + (count + 1) * 2891336453) & 0xFFFFFFFF
    x ^= x >> 16
    x = (x * 2246822519) & 0xFFFFFFFF
    x ^= x >> 13
    x = (x * 3266489917) & 0xFFFFFFFF
    x ^= x >> 16
    return int(x)


def baseline(*inputs):
    logits, top_k, out, batch_size, vocab_size = inputs
    topk_idx = torch.topk(logits, int(top_k.max().item()), dim=-1).indices
    for row in range(batch_size):
        k = int(top_k[row].item())
        pick = _row_hash(row, k) % k
        out[row, 0] = topk_idx[row, pick].to(torch.int32)
    return [logits, top_k, out, batch_size, vocab_size]
```
