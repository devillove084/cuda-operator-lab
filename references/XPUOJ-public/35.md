# Single Prefill with KV Cache

原题 https://xpuoj.com/p/35

## 题目描述

你需要实现单序列 Prefill 阶段的因果注意力算子。给定查询张量 $Q$、键张量 $K$、值张量 $V$，你需要计算带 causal mask 的缩放点积注意力输出，并写回结果张量。

具体来说，输入张量的 shape 分别为：

$$
Q \in \mathbb{R}^{L_q \times H_q \times D}, \quad
K \in \mathbb{R}^{L_k \times H_{kv} \times D}, \quad
V \in \mathbb{R}^{L_k \times H_{kv} \times D}
$$

其中 $L_q$ 表示 query 序列长度，$L_k$ 表示 key/value 序列长度，$H_q$ 表示 query 头数，$H_{kv}$ 表示 key/value 头数，$D$ 表示每个头的维度。

当 $H_q 
eq H_{kv}$ 时，本题按照 baseline 的语义采用分组查询注意力（GQA）的方式处理：将每个 KV head 复制到对应数量的 query heads，使其与 $Q$ 的头数对齐。对齐后，再对每个 head 计算：

$$
S = \dfrac{QK^T}{\sqrt{D}}
$$

随后施加因果掩码。也就是说，对于不允许访问的未来位置，需要把对应分数视为 $-\infty$，从而保证当前位置只能关注当前及之前的 token。然后计算：

$$
P = \operatorname{softmax}(S + M)
$$

其中 $M$ 表示因果掩码。最后输出为：

$$
O = PV
$$

因此，本题的关键在于三点：正确处理 GQA 头对齐、正确施加因果 mask、以及严格按照缩放点积注意力的顺序完成 $QK^\top \to \text{mask} \to \text{softmax} \to PV$ 的计算。输出张量 $O$ 的 shape 为 $(L_q, H_q, D)$。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成注意力计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* q_ptr,
    const __nv_bfloat16* k_ptr,
    const __nv_bfloat16* v_ptr,
    __nv_bfloat16* out_ptr,
    long qo_len,
    long kv_len,
    long num_qo_heads,
    long num_kv_heads,
    long head_dim
);
```

## 参数说明

* `q_ptr`：query 张量指针（bfloat16），shape $(\text{qo_len}, \text{num_qo_heads}, \text{head_dim})$，行优先连续存储，只读
* `k_ptr`：key 张量指针（bfloat16），shape $(\text{kv_len}, \text{num_kv_heads}, \text{head_dim})$，行优先连续存储，只读
* `v_ptr`：value 张量指针（bfloat16），shape $(\text{kv_len}, \text{num_kv_heads}, \text{head_dim})$，行优先连续存储，只读
* `out_ptr`：输出张量指针（bfloat16），shape $(\text{qo_len}, \text{num_qo_heads}, \text{head_dim})$，行优先连续存储，需写入计算结果
* `qo_len`：query 序列长度（int64）
* `kv_len`：key/value 序列长度（int64）
* `num_qo_heads`：query 注意力头数（int64）
* `num_kv_heads`：KV 注意力头数（int64）
* `head_dim`：每个头的维度（int64）

`run_kernel` 内部需要完成以下工作：

* 根据数据规模计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成单序列 Prefill 注意力计算

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成对应参数并按顺序传入，所有 tensor 均为连续存储（contiguous）。

## 输出格式

你需要将计算结果写入 `out` 指向的缓冲区，得到形状为 $(\text{qo_len}, \text{num_qo_heads}, \text{head_dim})$ 的 bfloat16 张量。

当启用因果掩码时，第 i 个 query 只能访问前 i 个 key/value 位置，输出与 PyTorch 参考实现完全一致。

## PyTorch 参考实现

```python
def baseline(*inputs: List[KernelArg]) -> List[KernelArg]:
    """
    baseline 用来算正确结果。
    实现 single prefill with kv cache

    Args:
        q: BF16 tensor of shape (qo_len, num_qo_heads, head_dim) - query
        k: BF16 tensor of shape (kv_len, num_kv_heads, head_dim) - key
        v: BF16 tensor of shape (kv_len, num_kv_heads, head_dim) - value
        o: BF16 tensor of shape (qo_len, num_qo_heads, head_dim) - output (will be modified inplace)
        qo_len: int - query sequence length
        kv_len: int - key/value sequence length
        num_qo_heads: int - number of query/output heads
        num_kv_heads: int - number of key/value heads
        head_dim: int - head dimension

    Returns:
        List containing modified o tensor
    """
    q, k, v, o, qo_len, kv_len, num_qo_heads, num_kv_heads, head_dim = inputs

    assert torch.is_tensor(q) and torch.is_tensor(k) and torch.is_tensor(v) and torch.is_tensor(o)
    assert isinstance(qo_len, int) and isinstance(kv_len, int) and isinstance(num_qo_heads, int) and isinstance(num_kv_heads, int) and isinstance(head_dim, int)
    assert q.shape == (qo_len, num_qo_heads, head_dim)
    assert k.shape == (kv_len, num_kv_heads, head_dim)
    assert v.shape == (kv_len, num_kv_heads, head_dim)
    assert o.shape == (qo_len, num_qo_heads, head_dim)

    sm_scale = 1.0 / (head_dim ** 0.5)

    if num_qo_heads != num_kv_heads:
        head_repeat = num_qo_heads // num_kv_heads
        k = k.unsqueeze(2).repeat(1, 1, head_repeat, 1).reshape(kv_len, num_qo_heads, head_dim)
        v = v.unsqueeze(2).repeat(1, 1, head_repeat, 1).reshape(kv_len, num_qo_heads, head_dim)

    scores = torch.einsum('qhd,khd->qhk', q, k) * sm_scale

    causal_mask = torch.triu(torch.ones(qo_len, kv_len, device=q.device, dtype=torch.bool), diagonal=kv_len - qo_len + 1)
    scores = scores.masked_fill(causal_mask.unsqueeze(1), float('-inf'))

    attn_weights = torch.softmax(scores.to(torch.float32), dim=-1).to(scores.dtype)
    output = torch.einsum('qhk,khd->qhd', attn_weights, v)

    o.copy_(output)

    return [q, k, v, o, qo_len, kv_len, num_qo_heads, num_kv_heads, head_dim]```
