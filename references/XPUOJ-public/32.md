# Conv2d Fprop S32

原题 https://xpuoj.com/p/32

## 题目描述

你需要实现一个 INT32 语义的二维卷积前向传播算子：

> **output = conv2d(x, weight, bias, stride, padding)**

为了适配 OJ，本题采用如下固定接口：

* `x`：形状 `(N, C_in, H, W)`，类型为 int32
* `weight`：形状 `(C_out, C_in, R, S)`，类型为 int32
* `bias`：形状 `(C_out,)`，类型为 int32
* `output`：形状 `(N, C_out, H_out, W_out)`，类型为 int32

数学语义等价于先按浮点完成卷积，再将结果转为 int32。

本题评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要完成二维卷积前向传播。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const int32_t* x,
    const int32_t* weight,
    const int32_t* bias,
    int32_t* output,
    int64_t N,
    int64_t C_in,
    int64_t C_out,
    int64_t H,
    int64_t W,
    int64_t R,
    int64_t S,
    int64_t stride,
    int64_t padding
);
```

### 参数说明

* `x`：输入指针，shape `(N, C_in, H, W)`，类型为 int32
* `weight`：输入指针，shape `(C_out, C_in, R, S)`，类型为 int32
* `bias`：输入指针，shape `(C_out,)`，类型为 int32
* `output`：输出指针，shape `(N, C_out, H_out, W_out)`，类型为 int32
* `N`：batch size
* `C_in`：输入通道数
* `C_out`：输出通道数
* `H`、`W`：输入高度、宽度
* `R`、`S`：卷积核高度、宽度
* `stride`：步长
* `padding`：零填充大小

`run_kernel` 内部需要完成以下工作：

* 根据输入尺寸计算输出形状
* 自行计算合适的 launch 配置
* launch 你实现的 CUDA kernel，完成二维卷积前向传播

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会生成以下参数并按顺序传入：

* `x`：int32 tensor，shape `(N, C_in, H, W)`
* `weight`：int32 tensor，shape `(C_out, C_in, R, S)`
* `bias`：int32 tensor，shape `(C_out,)`
* `output`：int32 tensor，shape `(N, C_out, H_out, W_out)`，作为输出缓冲区
* `N, C_in, C_out, H, W, R, S, stride, padding`：int64 标量

## 输出格式

你需要将计算结果写入 `output`，满足：

```text
H_out = floor((H + 2 * padding - R) / stride + 1)
W_out = floor((W + 2 * padding - S) / stride + 1)

output[n, c_out, h, w] =
    int32(
        sum_{c_in, k_h, k_w}
            x[n, c_in, h * stride - padding + k_h, w * stride - padding + k_w]
            * weight[c_out, c_in, k_h, k_w]
        + bias[c_out]
    )
```

## 样例

## 输入

```text
N = 1
C_in = 1
C_out = 1
H = W = 3
R = S = 3
stride = 1
padding = 0
```

此时：

```text
H_out = (3 + 0 - 3) / 1 + 1 = 1
W_out = (3 + 0 - 3) / 1 + 1 = 1
```

所以输出张量形状为：

```text
output.shape = (1, 1, 1, 1)
```

该唯一位置的输出值，等于输入窗口与卷积核逐元素乘加后再加上偏置，并最终转换为 int32。

## 数据范围与提示

## 数据范围

* `x.dtype == torch.int32`
* `weight.dtype == torch.int32`
* `bias.dtype == torch.int32`
* `output.dtype == torch.int32`

## 正确性要求

* 必须正确处理 `stride`
* 必须正确处理 `padding`
* 必须正确累加全部输入通道与卷积核空间维度
* 必须正确加上 `bias`
* 必须将结果按 int32 写入 `output`

## 提示

* 可以先在 `float32` 中完成卷积计算，再将结果转换成 `int32`
* 对于越界的输入坐标，需要视为 padding 区域并跳过
* 当输出类型为 int32 时，建议显式控制最终的类型转换位置

## PyTorch 参考实现

```python
def baseline(x, weight, bias, output, N, C_in, C_out, H, W, R, S, stride, padding):
    output.copy_(torch.nn.functional.conv2d(x.float(), weight.float(), bias.float(), stride, padding).to(output.dtype))
```
