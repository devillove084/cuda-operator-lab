# FFT

原题 https://xpuoj.com/p/96

## 题目描述

你需要实现一个一维复数 FFT 算子。给定输入复数矩阵 `X`，其 shape 为 `(batch, n)`，你需要沿最后一个维度对每一行做离散傅里叶变换，得到输出复数矩阵 `Y`，shape 同样为 `(batch, n)`。

为了便于 OJ 评测，本题将复数输入和输出拆成实部与虚部两部分：

* `X_real`：输入实部，shape `(batch, n)`
* `X_imag`：输入虚部，shape `(batch, n)`
* `Y_real`：输出实部，shape `(batch, n)`
* `Y_imag`：输出虚部，shape `(batch, n)`

定义复数输入：

$$
X_{b,t} = X\_{real,b,t} + i \cdot X\_{imag,b,t}
$$

对于每个 batch `b` 和频率位置 `k`，输出满足：

$$
Y_{b,k} = \sum_{t=0}^{n-1} X_{b,t} \cdot e^{-2\pi i k t / n}
$$

将其拆成实部和虚部后，可写为：

$$
W_{k,t} = \cos\left(\frac{2\pi k t}{n}\right) - i \sin\left(\frac{2\pi k t}{n}\right)
$$

$$
Y_{b,k} = \sum_{t=0}^{n-1} X_{b,t} \cdot W_{k,t}
$$

最终你需要把结果分别写入 `Y_real` 和 `Y_imag`。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 launch 配置并 launch kernel 来完成上述计算。

如何提交代码详见[评测指南](/d/2)。

## 输出格式

你需要将 FFT 结果写入 `Y_real` 和 `Y_imag` 指向的缓冲区，满足：

```text
Y[b, k] = sum_{t=0}^{n-1} X[b, t] * exp(-2πi k t / n)
```

其中：

```text
X[b, t] = X_real[b, t] + i * X_imag[b, t]
Y[b, k] = Y_real[b, k] + i * Y_imag[b, k]
```

## 样例

## 输入

```text
batch = 1
n = 4

X_real =
[
  [1, 0, -1, 0]
]

X_imag =
[
  [0, 1, 0, -1]
]
```

这表示输入复数序列为：

```text
[1 + 0i, 0 + 1i, -1 + 0i, 0 - 1i]
```

## 输出

```text
Y_real =
[
  [0, 4, 0, 0]
]

Y_imag =
[
  [0, 0, 0, 0]
]
```

## 计算过程说明

记输入序列为：

```text
x[0] = 1 + 0i
x[1] = 0 + 1i
x[2] = -1 + 0i
x[3] = 0 - 1i
```

对 `k = 0`：

$$
Y[0] = x[0] + x[1] + x[2] + x[3] = 0 + 0i
$$

对 `k = 1`，有：

$$
e^{-2\pi i \cdot 1 \cdot t / 4} = [1,\; -i,\; -1,\; i]
$$

因此：

$$
Y[1] = (1+0i)\cdot 1 + (0+1i)\cdot (-i) + (-1+0i)\cdot (-1) + (0-1i)\cdot i = 4 + 0i
$$

对 `k = 2`：

$$
e^{-2\pi i \cdot 2 \cdot t / 4} = [1,\; -1,\; 1,\; -1]
$$

所以：

$$
Y[2] = (1+0i) + (0+1i)\cdot (-1) + (-1+0i) + (0-1i)\cdot (-1) = 0 + 0i
$$

对 `k = 3` 可同理算得 `0 + 0i`。

因此最终输出为：

```text
Y = [0 + 0i, 4 + 0i, 0 + 0i, 0 + 0i]
```

## PyTorch 参考实现

```python
import torch

def baseline(X_real, X_imag, Y_real, Y_imag, batch, n):
    x = torch.complex(X_real, X_imag).to(torch.complex64)
    y = torch.fft.fft(x, dim=-1)
    Y_real.copy_(y.real.contiguous())
    Y_imag.copy_(y.imag.contiguous())
```
