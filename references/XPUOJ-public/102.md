# Cumsum

原题 https://xpuoj.com/p/102

## 题目描述

你需要实现一个前缀和算子 `cumsum`。

原始算子的输入张量逻辑 shape 为 `(..., N)`，输出张量 shape 与输入相同，且沿最后一维做前缀和：

$$
output[..., i] = \sum_{t=0}^i input[..., t]
$$

为了便于 OJ 评测，本题会把除最后一维外的所有前导维度展平成一个批量维 `rows`，把问题改写成对 shape `(rows, N)` 的二维张量按最后一维做前缀和。

也就是说，评测实际传入的 `input_flat` 和 `output_flat` 都是长度为 `rows * N` 的一维连续缓冲区，它们分别对应逻辑矩阵：

```text
input  = reshape(input_flat,  (rows, N))
output = reshape(output_flat, (rows, N))
```

对任意 `0 <= r < rows`、`0 <= c < N`，你需要满足：

$$
output[r, c] = \sum_{t=0}^c input[r, t]
$$

评测程序会调用你实现的 `run_kernel` 函数。在函数内部，你需要根据 `rows` 和 `N` 计算合适的 launch 配置，并完成逐行前缀和计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>

extern "C" void run_kernel(
    const float* input_flat,
    float* output_flat,
    int64_t rows,
    int64_t N
);
```

### 参数说明

* `input_flat`：输入指针（float32），shape `(rows * N,)`，按行优先连续存储，只读
* `output_flat`：输出指针（float32），shape `(rows * N,)`，按行优先连续存储，需写入前缀和结果
* `rows`：展平后的行数（int64），等于原始输入张量除最后一维外所有维度的乘积
* `N`：最后一维长度（int64）

`run_kernel` 内部需要完成以下工作：

* 根据 `rows` 和 `N` 计算合适的 launch 配置
* 对每一行独立完成前缀和计算
* 将结果按连续布局写入 `output_flat`

## 输入格式

本题的输入由评测程序在 GPU 上构造并传入 `run_kernel`。评测会按顺序传入：

* `input_flat`：float32 tensor，shape `(rows * N,)`
* `output_flat`：float32 tensor，shape `(rows * N,)`，作为输出缓冲区
* `rows`：int64 标量
* `N`：int64 标量

逻辑上，`input_flat` 对应某个原始 shape 为 `(..., N)` 的张量，只是前导维度已被展平。

## 输出格式

你需要将结果写入 `output_flat` 指向的缓冲区。若记：

```text
input  = reshape(input_flat,  (rows, N))
output = reshape(output_flat, (rows, N))
```

则必须满足：

```text
for r in [0, rows):
    output[r, 0] = input[r, 0]
    for c in [1, N):
        output[r, c] = output[r, c - 1] + input[r, c]
```

## 输入

```text

  [1.0, 2.0, -1.0, 3.0],
```

```text
output =
[
  [1.0, 3.0, 2.0, 5.0],
```

## 计算过程说明

第 0 行：

* `output[0, 0] = 1.0`
* `output[0, 1] = 1.0 + 2.0 = 3.0`
* `output[0, 2] = 3.0 + (-1.0) = 2.0`
* `output[0, 3] = 2.0 + 3.0 = 5.0`

第 1 行：

* `output[1, 0] = 0.5`
* `output[1, 1] = 0.5 + (-0.5) = 0.0`
* `output[1, 2] = 0.0 + 4.0 = 4.0`
* `output[1, 3] = 4.0 + 1.5 = 5.5`

## PyTorch 参考实现

```python
import torch


def baseline(input_flat, output_flat, rows, N):
    x = input_flat.view(rows, N)
    output_flat.copy_(torch.cumsum(x, dim=-1).reshape(-1))
```
