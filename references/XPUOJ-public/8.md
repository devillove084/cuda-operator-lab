# SiLU

原题 https://xpuoj.com/p/8

## 题目描述

你需要实现一个 SiLU（Sigmoid Linear Unit，也称为 Swish）激活函数算子。SiLU 是一种平滑的非线性激活函数，定义为输入与 sigmoid 函数的乘积。

数学表达式为：

$$
y_{i,j} = x_{i,j} \cdot \sigma(x_{i,j})
$$

其中 $\sigma(\cdot)$ 是 sigmoid 函数：

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

因此 SiLU 也可写为：

$$
y_{i,j} = \frac{x_{i,j}}{1 + e^{-x_{i,j}}}
$$

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成 SiLU 计算。

如何提交代码详见[评测指南](/d/2)。

## 输出格式

你需要将计算结果写入 $y$ 指向的缓冲区，得到一个 shape 为 $(T, H)$ 的 bfloat16 矩阵。对于每个位置 $(i, j)$，输出应满足：

$$
y_{i,j} = x_{i,j} \cdot \sigma(x_{i,j}) = \frac{x_{i,j}}{1 + e^{-x_{i,j}}}
$$

其中 $\sigma(z) = 1 / (1 + e^{-z})$ 是 sigmoid 函数。

## 样例

## 输入

`x`（shape 为 $(2, 2)$，其中 $T=2, H=2$）：

```
[[1.0, 2.0],
 [0.0, -1.0]]
```

## 输出

`y`（shape 为 $(2, 2)$）：

```
[[0.7311, 1.7616],
 [0.0, -0.2689]]
```

## 计算过程说明

SiLU 函数对输入矩阵的每个元素独立进行计算：

* $x_{0,0} = 1.0$：$\sigma(1.0) \approx 0.7311$，$y_{0,0} = 1.0 \times 0.7311 \approx 0.7311$
* $x_{0,1} = 2.0$：$\sigma(2.0) \approx 0.8808$，$y_{0,1} = 2.0 \times 0.8808 \approx 1.7616$
* $x_{1,0} = 0.0$：$\sigma(0.0) = 0.5$，$y_{1,0} = 0.0 \times 0.5 = 0.0$
* $x_{1,1} = -1.0$：$\sigma(-1.0) \approx 0.2689$，$y_{1,1} = -1.0 \times 0.2689 \approx -0.2689$
