# Einsum Contraction

原题 https://xpuoj.com/p/140

## 题目描述

你需要实现一个 bfloat16 精度的批量 einsum contraction 算子，对应 einsum 表达式：

> **out = torch.einsum('bijk,bjkl->bil', a, b)**

给定输入张量 `a`（shape 为 $(B, I, J, K)$）和 `b`（shape 为 $(B, J, K, L)$），对每个 batch 独立沿 $(J, K)$ 两个维度做规约，得到输出张量 `out`（shape 为 $(B, I, L)$）。具体计算方式为：

$$
out_{batch,i,l} = \sum_{j=0}^{J-1}\sum_{k=0}^{K-1} a_{batch,i,j,k} \cdot b_{batch,j,k,l}
$$

其中 $batch \in [0, B)$，$i \in [0, I)$，$l \in [0, L)$，$\cdot$ 表示逐元素乘法。

评测程序会调用你实现的 `run_kernel` 函数，在函数内部你需要计算合适的 grid/block 并 launch kernel 来完成上述批量 contraction 计算。

如何提交代码详见[评测指南](/d/2)。

## 接口约定

### cuda

你必须在提交的 CUDA 源码中提供如下 **C 符号**，函数名、参数类型、顺序必须完全一致，并使用 `extern "C"` 防止 name mangling：

```cpp
#include <stdint.h>
#include <cuda_bf16.h>

extern "C" void run_kernel(
    const __nv_bfloat16* a,
    const __nv_bfloat16* b,
    __nv_bfloat16* out,
    int64_t B,
    int64_t I,
    int64_t J,
    int64_t K,
    int64_t L
);
```

### 参数说明

* `a`：输入指针（bfloat16），shape $(B, I, J, K)$，连续存储，只读
* `b`：输入指针（bfloat16），shape $(B, J, K, L)$，连续存储，只读
* `out`：输出指针（bfloat16），shape $(B, I, L)$，连续存储，需写入计算结果
* `B`：batch 数量（int64）
* `I`：`a` 的第 2 维，也是 `out` 的第 2 维（int64）
* `J`：规约维度之一，`a` 的第 3 维，也是 `b` 的第 2 维（int64）
* `K`：规约维度之一，`a` 的第 4 维，也是 `b` 的第 3 维（int64）
* `L`：`b` 的第 4 维，也是 `out` 的第 3 维（int64）

`run_kernel` 内部需要完成以下工作：

* 根据张量尺寸计算合适的 grid 和 block 配置
* launch 你实现的 CUDA `__global__` kernel，完成 `bijk,bjkl->bil` 的计算

## 数据范围与提示

## 数据范围

* `a`、`b`、`out` 的数据类型均为 `torch.bfloat16`
* `a` 的 shape 为 $(B, I, J, K)$
* `b` 的 shape 为 $(B, J, K, L)$
* `out` 的 shape 为 $(B, I, L)$
* 所有 tensor 均为连续存储（contiguous）
* $1 \le B \le 8$
* $1 \le I \le 769$
* $1 \le J \le 128$
* $1 \le K \le 129$
* $1 \le L \le 768$

## 正确性要求

* 必须对每个 batch 独立计算 contraction
* 必须正确沿 `J` 和 `K` 两个维度做规约求和
* 必须将最终结果写入 `out`
* 不允许修改 `a` 和 `b`

## 提示

* `a` 的布局是 $(B, I, J, K)$，`b` 的布局是 $(B, J, K, L)$
* 每个 batch 的计算互相独立，不需要跨 batch 规约
* 可以将 $(J, K)$ 两个规约维度展平成一个长度为 $J \times K$ 的维度

## PyTorch 参考实现

```python
def baseline(a, b, out, B, I, J, K, L):
    a2 = a.float().reshape(B, I, J * K)
    b2 = b.float().reshape(B, J * K, L)
    out.copy_(torch.bmm(a2, b2).to(torch.bfloat16))
```
